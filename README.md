# 西部世界

让多个 AI 个体在 Survivalcraft 的世界里生活、生存、交流、合作与建造。世界中的动作由游戏规则结算，每个人依据自己能够感知的信息和经历做决定。先复用游戏底座，补充驱动力、个人记忆和分层自主执行，让分工与社会关系在实际互动中形成。项目的游戏内观察方式是以玩家身份进入世界并飞行查看。

## 仓库内容

- [游戏源码](game/README.md)采用社区插件版 SCAPI 1.9.5.1，包含引擎、实体系统、游戏逻辑、资源和上游文档。
- [项目文档](docs/README.md)提供代码导航、开发与验证、当前状态，以及人物、记忆、世界和社会演化等目标设计。
- [源码来源](game/UPSTREAM.md)记录上游版本、导入范围及签名文件处理。

## 当前状态

Windows 本机可创建 50 人生存世界或单人生产世界，冻结初态后可以重复导入。开局玩家可以飞行查看，正常退出后可重新打开同一个世界继续 AI 任务。[开局与飞行](docs/development/开发与验证.md#西部世界开局与飞行) · [单人生产](docs/development/开发与验证.md#单人生产) · [普通存档恢复](docs/development/开发与验证.md#西部世界普通存档恢复) · [当前状态](docs/development/当前状态.md)

修改前先查[代码导航](docs/development/代码导航.md)，Windows 构建、启动和检查步骤见[开发与验证](docs/development/开发与验证.md)。
