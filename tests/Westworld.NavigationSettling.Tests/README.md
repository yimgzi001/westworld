# 停止输入后的稳定驻留门槛

纯核心判定，不修改物理、不施加制动、不运行游戏。25 个断言通过。

调用：先撤销旧动作及其移动输入，创建 `NavigationSettling(startTime)`，逐帧传入真实 `NavigationSettlingSample`。时间必须使用同一个单调秒钟；不可混合游戏时间和墙钟。只有 `Settled` 才允许下一次陆地导航规划。

默认连续 .25 秒满足：活着、无父身体、落地、浸水≤.1、水平速≤.1、竖直速绝对值≤.1。采样间隔超过 .1 秒重新累计，3 秒未完成失败；这会把卡帧判为未证明稳定，而非推测期间静止。死亡/重新挂载立即失败。成功和失败均锁定，旧 gate 不可用于新动作；成功后若宿主延迟才规划，应重新检查当前实际身体状态。

测试覆盖零速度不是立即成功、驻留成功、采样缺口、空中/浸水/水平或竖直运动打断、死亡/挂载、截止边界、迟到轮询、非法及逆序输入无副作用、终态锁定。没有证明真实角色在取消后一定停下，原生集成还需实测。
