# Route projection checks

Run `work/dotnet/dotnet run --project tests/Westworld.RouteProjection.Tests/RouteProjection.Tests.csproj -c Release` from the cloud checkout.

Synthetic, trusted observation snapshots exercise only the conservative static corridor projection. No native world, graphics, model, or terrain querying is run. KnownSafe is scoped to the given observation, default player body, and stable full-cube terrain allowlist; it does not certify future conditions or dynamic entities. Unknown cells remain unknown, including an unseen start column. A real forward-facing snapshot can legitimately produce zero candidates. Native movement must remain bounded and must not silently pathfind outside the evidenced corridor. The caller must reobserve before execution.

`Project` defaults to `StrictStable`. A host can explicitly select `RouteGroundPolicy.ObservedFullCube` for natural sand/gravel terrain. This accepts only directly observed current full-cube geometry; it neither queries nor infers hidden supporting layers and does not guarantee the block will not fall. The projection includes its policy. Runtime drop/immersion monitoring and cancellation are reactive mitigation, not proof that a fall cannot occur. Unknown, air floor, fluids, and missing clearance remain rejected in both policies.

The projection now matches an ordinary native player's 0.5 m X/Z body width (half-width 0.25), retaining 1.9 m clearance for its 1.77 m height. The host must reject bodies outside this declared envelope. Swept X/Z voxel bounds use `floor(min + 1e-5)` through `floor(max - 1e-5)`, treating exact/tiny numerical boundary contact as zero-volume overlap, not wall penetration. The host must use the same contact convention for actual BoundingBox checks each tick and at completion, requiring occupied air cells to belong to the route's observed air evidence. Larger overlap, unknown start cells, and walls within the swept volume remain rejected. This fixes an artificial deadlock from the former 0.4 m half-width; it does not guarantee dynamic safety or available alternate routes.
