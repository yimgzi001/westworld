# 本地攻击就绪契约

纯计时提示，不改变原生攻击、冷却、模型目标或是否攻击的决策；不声称真实游戏验收。

宿主收到同一模型计划的下一次攻击时，保存真实 GameTime 为等待起点，截止为起点 + 4 秒。每帧读取真实 lastHitTime/HitInterval，传入上次采样时钟；不要每帧重置起点。Ready 后仍须重新验证实际可见引用并调用原生攻击。严格 `time - lastHitTime > interval`，等于时继续等。过期优先于 Ready；非有限值、非法期限、时间回退返回 Invalid。没有上次时钟时只能检测早于等待起点/最近攻击的回退。

这是游戏时间期限，暂停时不会推进；宿主保留现有墙钟总超时和取消。取消/换计划/角色或会话结束必须清队列和等待状态。Expired/Invalid 或原生拒绝须记录事实并返回规划器，不能无限重试。mod hook 可修改有效间隔或拒绝命中，所以 Ready 不是命中保证，不把未命中/被拒改写成成功。

运行：`dotnet run --project tests/Westworld.AttackReadiness.Tests`。直接链接单个源码，无游戏程序集、GUI、模型或共享构建依赖。
