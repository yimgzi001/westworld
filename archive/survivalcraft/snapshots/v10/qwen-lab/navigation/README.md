# 已知表面最小路径规划（离线）

本目录只做算法和协议测试，不调用游戏、模型或云API，不改变世界。

`grid_planner.py` 使用规范化Cell：x/z整数网格、脚底高度y、loaded、walkable、kind、headroom、observed_at。仅允许明确solid且2格头部空间、近期已观察的格；四邻接，不斜切角，最大相邻高差1。水/岩浆/树冠/危险/未知拒绝。BFS有32格半径、48步、4096节点上限。探索只到已知安全边界格，不把未知区域当可走。

`ProgressGuard`是执行器应调用的独立停止建议：30秒总期限、32格总位移界限、4秒没有朝当前航点进展、状态陈旧>2秒、health/air下降、路径失效时停止。它不实际发送stop，后续适配器必须负责发送并确认。

12项离线单测通过，包含断路、1格台阶/2格悬差、水/树冠、头部空间、陈旧、NaN、探索和失速。

待真实地图适配：surface预计提供{x,y=topHeight,z,value,type}，rotation为body quaternion。尚不可声称这些字段直接证明碰撞安全；需确认topHeight语义、当前脚底高度、目标头部空间、地表类型和动态障碍。路径只是候选，不保证可通行。上台阶需要跳跃技能，此规划器尚未控制跳跃；不应把“1格可选边”当作现有移动接口必然能走上去。

## 实际surface适配与候选草地路线
`surface_route.py`已读取真实food-scan.json：y为地表块坐标，脚底y+1，solid来自运行时IsCollidable，headroom为上方连续不碰撞最多2格。根据实际类型只放行普通地表白名单（本图实用SandBlock/GrassBlock），其余Water/Cactus/DryBush/海胆等拒绝。不猜数字ID。

从实际上岸位置(555.53,65,-150.56)得到5步路线：
(555.5,65,-150.5) → (554.5,65,-150.5) → (554.5,65,-149.5) → (554.5,66,-148.5) → (554.5,66,-147.5) → 草地(554.5,66,-146.5)。第三步有1格上台阶，需正常跳跃，失败应失速停止。

输出grass-route.json明确snapshot_only并保留源文件mtime。以地图捕获时刻进行离线候选分析，没有将读取旧文件当作新观察；不能声称当前实时安全。没有发任何动作。执行方应先刷新地图、检查脚下和下一格局部cells、健康/空气/新tick和限时，再逐个航点执行。

## 有界探索候选函数（只读）
`explore_surface.propose(data, position, visited)` 或 CLI：
`python explore_surface.py MAP --position X Y Z --visited VISITED_JSON --output ROUTE_JSON`

只放行实际SandBlock/GrassBlock、solid=true、headroom≥2，四邻接≤1格高差，单段最多8步。候选终点必须是未访问草地，评分结合路径新格、周围草地、距已见水距离和升降代价；水距离只是已观察范围内的内陆代理，不代表全世界海岸方向。任何found条目使函数返回停止探索并检查食源，不继续寻路。

visited由调用方用实际观察/确认走到的格更新，不能把计划但没走完的路线写入visited。函数不自动循环，不发送游戏动作，也不将文件读取时间当作新观察。执行方另外维护总段数/距离/现实时间预算（建议首轮≤6段/48格），每段刷新地图、每点验证局部安全与health/air，异常即停。

当前湿润图单段候选保存在wet-next-route.json，8个未访问路径格，终点距已见水由约1.41增到5.10格，一次上台阶。visited初始仅来自工作者确认完成的8+1路线。包括5个新探索函数用例，导航总17/17离线单测通过。尚不能称自动广域寻食成功。

## 已知天然食源定向接近
新增 `toward_food.propose(data, position, target_block_xyz, visited)` 与CLI `toward_food.py`。不同于探索，已有found不会阻止走向食源；仍只走已观测Sand/Grass、headroom2、四邻接≤1格高差、单段≤8步，永不进入食源方块格。到水平四邻且高度接近的安全格时停止，交给局部核验/采集技能。

若目标在surface覆盖范围外，不假造全程路线；只返回本段能改善目标距离的安全路径，或明确no_safe_progress。允许本段短绕行，终点需距离改善；visited防止反复回到已走终点。贪心分段不保证完整迷宫可达，阻塞时应停止并增加地图/规划能力，而非放宽未知或危险格。

整张已观测Sand/Grass安全图有1,634个可达格，存在90步绕到食源邻格(-139,69)的路径，但需暂时远离目标。诊断路线存canopy-blockage-analysis.json，明确不授权执行，也不自动扩展此前短测预算。

地图同时存在两类语义问题：非碰撞TallGrass/Flower顶点遮盖真正支撑面；树冠topHeight远高于可能可通行的林下地面。不能直接假设树冠下可走，也不能把solid=false当安全地面。

建议只读导航扫描枚举已加载列的真实Grass/Sand支撑面（从当前脚底高度邻近范围寻找），确认其上两格身体净空且无水/明显危险，记录支撑高度、上下方真实类型；树干和低树叶仍阻挡。有此真实观测后再更新路网，不能凭树冠形状推断隐藏地形。
