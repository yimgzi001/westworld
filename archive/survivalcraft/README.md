# 生存战争多智能体研究归档

**冻结日期：2026-11-08。状态：研究归档，不是可直接运行的产品。**

用户决定暂停自研 Survivalcraft 底层，评估以 Minecraft / Mindcraft 为新的群体模拟底座。本目录保存已归档研究的源码、测试代码、阶段报告与失败教训，不表示已经部署 Mindcraft。

## 核心结论

- 使用社区 SCNET X26.07.01.01 做实验；本仓库 `game/` 的基线为 SCAPI 1.9.5.1。两者不能默认兼容，本目录代码未移植到 `game/`。
- 同游戏进程支持多个受控角色。50 个集中、空闲、隐藏画面的角色，120 秒样本约 742 MiB RSS、0.92 个 CPU 核心，近实时。这不是 50 个自主 AI 的容量证明。
- 原生移动、普通挖掘/放置，以及限定场景内模型靠近、采集和进食已有阶段性验证；不等于开放世界长期自主生存。
- 本地模型推理和游戏动作需要解耦，动作预算、过期回复拒绝、停止确认、真实状态观测与失败证据必须保留。
- 较晚的原始视觉/镜像源码和旧世界未找回。11 月 8 日的实现是重建后的新实验，不能冒充原现场延续。
- 人工资源夹具不是自然发现；离线测试不是游戏内验证。存档绑定和跨帧光照就绪是恢复过程中发现的真实缺口。

## 安全与复用

不要把任一实验桥直接放入日常存档。旧桥可能自动添加角色，脚本中可能有旧 Linux 绝对路径；启动前须人工审查并使用隔离世界。此归档不自动安装、启动游戏或调用模型，不包含可用凭证。后续模型接入采用云端的方向已确定，但本归档没有配置或调用云端模型。

按仓库 AGENTS.md，本次 **不提交** 密钥、证书、模型权重、第三方游戏/SDK二进制、构建输出、运行世界存档、原始模型账本和逐帧日志。原始四份 ZIP、312 个展开文件及完整运行证据保留在用户电脑：`D:\code\human evolution\archive\survivalcraft`，同时有 Library 备份。

`PACKAGE-MANIFEST.json` 提供四包 SHA256，`FILE-MANIFEST.json` 列出各包文件哈希与是否选入 GitHub，便于与本地完整档案核对。不在此上传原 ZIP，避免把其中缓存、运行存档和构建物间接提交。

本次只增加研究归档和文档入口，不改变 main、game/ 或原设计。源文件原样保留；没有为本仓库已有代码重新指定许可证。
