# 生存策略知识

更新于 2026-11-11。本批只进行单人普通生存测试。策略供模型选择，行动端负责局部观察、连续执行、原生结算和紧急安全处理。十天是验收门槛，达标后世界继续运行。

## 模型怎样使用

- 每次比较饱食、可靠库存、体温、天色、已经见过的资源和上次实际结果。自行决定先补粮、制作、建家、巡猎或撤退。
- 一次安排一至四步，执行端依次完成。后续步骤可以依赖前面的材料；前提失效时停止后续步骤，重新评估。
- 维持尚未完成的长期意图。改计划要有新事实，例如猎物离开、材料不足、路线受阻、天黑或威胁变化。
- 普通探索只报告发现。模型选择定向巡猎后，才在发现射程内食用鸟时连续完成持矛、投掷和拾肉。
- `succeeded` 表示这一段动作已完成。长期目标是否达成，要结合实际收获、身体变化和后续供给判断。

代码会把本文件中的主要取舍整理为 `strategyNotes`，放进真实模型请求。固定部分解释目标延续、食物账本和时间成本；情境部分按本人实际背包、身体状态和已建工作站补充生肉处理、湿冷、用火与营地建议。它不向模型提供隐藏资源、动物追击目标或未来结果。

## 开局与每日安排

开局先评估当天还有多少可活动时间，以及最近能可靠得到哪种食物。眼前有成熟南瓜时可先采集维持制作的时间；已有木材或猎物时，可比较先备矛与先找现成食物的收益。没有一套适合所有地图的固定第一天顺序。

一个可行的计划要同时回答：本段结束会得到什么、现有食物能否撑到那时、天黑前是否有地方回。不要把“先造更高级工具”当成理由，让已经饥饿的角色空腹长途采料。日落、湿冷和新敌人出现时重新评估，但相同旧事实不应让任务反复从头开始。

次日醒来重新核对库存、天气、门外与工具。睡了一晚会消耗食物，也可能让外部动物换位置；不能把昨天安全当成今天安全。早晨还有体力和白天，通常应尽早启动下一轮补给，不等到傍晚才发现缺粮。

## 口粮与配方

下列数字来自当前游戏源码和原生配方。原生同类食物累积、疾病和腐败仍可能影响能否食用。

| 食物或物品 | 原生前提 | 用途与取舍 |
|---|---|---|
| 熟鸟肉 | 生鸟肉、熔炉、燃料 | 营养从 0.2 提高到 0.5，作为前期主食来源之一 |
| 烤肉 | 生肉、熔炉、燃料 | 营养从 0.3 提高到 0.8。先保留原料，烧熟后取回背包 |
| 熟鱼 | 生鱼、熔炉、燃料 | 营养从 0.25 提高到 0.7。当前烹饪动作支持，岸边捕捞完整技能仍需后续完善 |
| 成熟南瓜 | 采收后实际入包 | 生吃营养 0.15，用于救急；幼瓜不计作成熟口粮 |
| 南瓜种子 | 一只采收后的成熟南瓜 | 原生配方产生三粒种子。先保留应急食物，再考虑播种 |
| 熟蛋 | 可食用鸟蛋、水桶、熔炉、燃料 | 需要容器，前期专门发展金属来煮蛋的成本高。当前主食路线不依赖它 |
| 南瓜汤 | 成熟南瓜、水桶、熔炉、燃料 | 需要水桶，当前主食动作尚未接入这条连续链 |
| 面包 | 九粒成熟黑麦种子制面粉，面粉加水桶制面团，再入炉 | 长期农业路线，当前尚未接入完整种麦与制面包动作 |
| 石斧 | 工作台、一块圆石或石块、两根木棒 | 可明显加快采石和砍树。先采一块再制斧，或先取够炉料，由模型权衡 |
| 熔炉 | 工作台、八块圆石 | 制作后还要放置、补燃料和原料，并实际取出熟食 |
| 木耙 | 工作台、两块木板、两根木棒 | 草地先去草、再耕土。播种动作在持有木耙时完成实际耕土 |

生肉、生蛋、幼苗和已经不能安全吃下的同类食物，不冒充可靠储粮。每日参考库存由原生饥饿系数和一天时长估算，同时留出活动及冷病恢复的余量。它是模型的决策依据，不触发固定补粮脚本。

生肉仍优先留待烤制。饱食不超过百分之四、尚未患病且没有更安全食物时，可按原生规则应急吃一份生肉，保留其患病风险与同类食物限制；不会为了等待炉子而背着原料饿死。这是濒饿兜底，不能算稳定供食或正常肉食路线。

## 狩猎与机会拾肉

鸭、乌鸦和海鸥会掉落食用鸟肉。麻雀、鸽子不产肉，不为食物追逐。优先比较距离、遮挡、地面和附近危险；拥有武器后，模型可选择一条方向持续巡猎，减少网络决策空档。

原生木矛无需蓄力。投掷按当前可见猎物速度、自身速度、真实出手位置和阻力计算提前量，伤害和掉落仍由游戏决定。射中不等于已取得食物，必须继续看到掉落、沿实际地形接近并核对入包。

看到可达的生肉可考虑带回烤制，先检查周围猎食者。不得凭审计事件获取遮挡后的掉落坐标，也不把别的动物的死亡算作本人猎获。

不要一直追逐远处飞鸟。比较成功机会、投矛和取回掉落的路线、饱食余量及返程距离；同一猎物连续脱离视线或路线反复受阻时，可以换目标或换巡猎方向。已经得到生肉而缺炉时，模型应考虑转向加工准备，避免背着不能立即食用的原料不断消耗体力。

投矛后核对手中是否仍有武器。`recover_spear_*` 绑定本人实际看见的具体矛，模型可选择回收，节省反复采木与造矛的时间。沿路线接近和最终入包都核对原生来源，路上捡到另一根同类矛不能冒充指定目标完成。遮挡后不会读取私有坐标追踪，必须重新观察与评估。

## 怎样判断供食稳定

应同时看最近几天的实际可吃收获、实际消耗和剩余可靠库存。胃里还有食物不等于库存充足，仓里一堆生肉也不等于随时能吃。原生食物累积、疾病和腐败会进一步限制可用量。

一种来源暂时失效时应有替代：猎物少可采成熟南瓜、巡视新的安全方向；南瓜幼苗尚未成熟时继续狩猎；已有肉却缺燃料时先补燃料。建议把“未来一天可吃储备”和“之后仍能获得食物的办法”同时写入长期意图。

十天存活只证明该场达到了时间门槛。不同自然开局的重复成功、供食收支与缺粮时长还要单独统计，不能把一场十天结果称为稳定供食验收通过。

## 南瓜与固定营地

南瓜是应急补充。向阳、温暖的地面更适合生长；耕土、肥力和水分会影响生长与夭折概率。寒冷环境会减慢生长。播种后继续获取当天口粮，不能等着幼苗马上成熟。

营地应靠近可利用的木材、石料和水源，留出安全进出路线，并避开雪地、深水、悬崖和反复遇敌的地方。简易土屋内部二乘二，墙与顶共四十块；屋顶、门口和原生可睡条件都核对后才算完成。材料必须实际采集。

建屋、离开营地、回营封门是可选动作。工作台、熔炉与营火只记录本人实际放置的位置；返回时重新观察并核对交互距离，不能把记住位置当作已经抵达。整条路线尚被山脊遮住时，可以沿已经确认的落脚面逐段接近，每段继续观察。看到工作台边角也不代表能操作；返回还要核对可站立高度、距离和原生交互射线。

模型选择制作或烤肉后，技能可先接近四十格内本人已知的对应工作站，再执行原生操作。这属于已选动作的前置执行。是否制作、制作多少、是否重新建站或迁营，仍由 AI 安排。站点已变更或路线受阻时停止并报告实际原因。

明确选择返回时，可接近一百二十八格内本人已知的营地或工作站。远处坐标仅是过去的记忆；沿途每一步仍用当前局部观察核对落脚、净空、冷热与危险，不读取远方站点或未见地形。模型同时收到返程距离、按每秒两格估算的行走时间和“路线需要重查”，应另留制作、烤制、封门及绕路的时间。已有肉时，比较回旧炉与就地造炉的代价；猎物追远前先评估回家距离。

每段返程仍有时间和路程预算，只有确实走近、保持干地且未受伤才续接。预算恰好在原生台阶中到期时，最多留三秒完成当前一步并落稳；这不延迟睡眠、落水或受伤中断。没有新路线、站点已经变化或原地绕圈时报告失败。回工作站必须重新确认可以原生交互；回营必须实际入屋、封门并核对可睡掩护。

旧工作台超过四十格时，比较往返时间与就地补木造新台的成本。已经取得石样或生肉时，不必为旧台耽误当天口粮。背包已有一块原木或四块木板、且没有携带工作台时，就地制台会作为可立即执行的选项；只看到远处树木不等于前置材料已经齐备。新台依旧需要实际合成、放置及可操作站位，代码不会替模型决定迁站。

连续采集遇到一个掉落够不到时，可在相同任务时限与安全条件内排除该目标并有限重选，不丢弃之前入包的材料。材料数已够时仍须完成当前原生移动并落稳，再交给制作或放置；在下台阶半空捡到最后一块石头不算可开始下一步。

放置工作站时只清理真实挡住操作的小草、花和小枯灌木，不擅自挖掉农作物或其他建筑。本人浅探留下的阶梯、固定营地和南瓜耕地不作为批量采土采石目标，仍保留这些地形作为行走证据。

固定营地能减少重复造炉、重复挖坑和来回迷路的消耗，但建造前要留够食物与白天。住处只负责遮蔽和睡眠，不能凭空解决粮食；在缺粮地图里应允许模型迁营，而不是无论环境如何都固守原址。

当前技能会保留本人营地、已种南瓜和工作站的位置；完整箱子储物、畜牧、自动农场与所有食谱仍未接入，模型不得假定这些能力已经存在。

## 夜晚、保暖与遇敌

尽量在日落前选好安全过夜地点。临时土坑先检查周围地面和可见水体，窄岸不盲挖。露天等待不能产生屋顶；睡眠不满足原生条件时，重新安排建屋、换位置或其他有依据的动作。

湿冷时比较寻找干燥地点、回营、生火和补粮的成本。没有足够抗寒条件时避开已见雪地。已经存在的低温或夜色不应反复取消模型基于相同情况作出的决定；新出现或明显恶化的危险仍会中断。

可见危险和真实发出的原生声响提供预警。声音只表示大概方向和远近。不要向未证实安全的方向冲刺，也不能通过接口读取遮挡后动物的私有追击目标。

## 用火与受伤

营火取暖不需要踩到火上。放火要避开身体、通道、木墙、树叶与易燃物；靠近后观察体温、湿度和生命值。原生身体接触区比模型碰撞外形更大，路径不能贴着火焰穿过。

新放置的营火只有三档燃料，雨中每五秒减一档，干燥时约三十秒减一档。模型会收到已见营火的燃烧状态与燃料档位；没有重新看到的火势标为未知。仍在燃烧时可选择 `add_fuel_to_own_campfire` 添一份柴，库存减少与火势增加都核对后才算成功；熄灭后加柴不能复燃，满档时不继续消耗燃料。

持续淋雨时先比较屋顶遮雨与露天生火，体温已安全却仍湿透时不能靠反复添柴等干。湿冷时可先返回仍燃烧的旧火，视余量添柴，再选择 `warm_at_own_campfire` 连续恢复。只有体温至少八度且湿度低于三成才算这次充分晾干回暖完成；掉血、火灭、持续没有改善或超时会把实际原因交回模型。短时取暖不应冒充已经晾干，重复造新火也不等于完成恢复。

`onFire` 和 `touchingFire` 是本人原生身体状态。已经接触火时会由紧急动作先沿已观察的可落脚路线撤开，之后把状态和实际生命变化交回 AI。角色不会直接调用灭火或修改生命。

原生水中浸没超过一半能熄灭身上的火，但深水、寒冷和无法上岸可能造成新的危险。只有已经确认能够进出时才考虑入水。没有安全水体时，先离开火源，在安全位置观察原生燃烧消退。回暖期间掉血或体温持续恶化，不能靠重复等待掩盖问题。

## 无进展时怎样改计划

等待适用于明确的短过程，例如炉内加工、正在回暖或敌人暂时经过；每次等待都应有可复查的变化。露天反复等待、无法睡眠时反复睡、没有种下的作物等着收成，都没有产生收益的依据。

动作失败后区分原因：材料不足就保留已获得的材料再补前置；目标已消失就停止后续步骤；路受阻就根据新观察改路线；工具太远就先返回已知工作站。失败不应导致把整个长期目标和已完成部分全部忘掉。

## 采矿的进入条件

先稳定口粮、保暖和住处，再考虑深入矿洞。前期取裸露石料即可制作炉具和石斧；没有露头时，第一座炉子的石料准备也不能无限等待。

`quarry_1` 等编号绑定当前已看见的平坦土面。模型可选浅探：向前逐层挖阶梯，只采实际露出的泥土或草土，最多六格。初始地面须留足回跳净空，每一级下探前用同一份真实观察核对反向台阶，不能只证明能下去。遇水、缺少支撑、未知地层或工作上限就逐级沿阶梯返回。它不读取地下资源，也不保证有石头。见到石层后先清理站立与回跳所需空间，真实采得一块样本再回地面；剩余材料和后续顺序仍由 AI 安排。

一条可能的加工路线是浅探取样、回工作台制石斧、回矿口补足八块圆石、回工作台造炉、放炉烤肉，最后实际吃下熟食。`return_quarry_*` 绑定本人已经发现过石层的矿口；返回后重新观察，不能把记忆当作当前矿石库存。任一步失败都保留已经取得的材料与原因，重新评估饱食和日落；不将整条发展顺序写成自动策略。临饿时仍应优先比较眼前可吃食物。

后续深矿应准备照明、返程食物及安全退路，避免直挖脚下。当前浅探是首炉材料准备，不代表矿洞开发与完整农业已经验收。
