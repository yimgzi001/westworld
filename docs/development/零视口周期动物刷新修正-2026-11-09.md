# 零视口周期动物刷新修正

日期：2026-11-09。承接《零视口动物生成审计》，本步只解除周期随机补生的 GameWidget 依赖，不改变野猪规则、生成频率、食物策略或动物数量上限。

## 实施

修改：`game/Survivalcraft/Subsystem/SubsystemCreatureSpawn.cs`。

- `SpawnRandomCreature`：provider 已设置时从 `SubsystemSpawn.GetSimulationCenters()` 取中心；精确重复位置去重，非有限/超原生实验坐标边界的中心跳过，空集合不回退到相机。
- 无 provider 时仍遍历原 `GameWidgets` 并调用原 Camera 虚重载，保留普通玩家与依赖该重载的 mod 路径。
- 新增 `GetRandomSpawnPoint(Vector3, SpawnLocationType)`；原 Camera 重载默认委托位置版本。
- 仍使用原来的最多十次随机尝试，X/Z 各正负 24～48 格、Y 正负 30 并限制到 2～254，接原 `ProcessSpawnPoint`。
- 抽出共用 `TrySpawnRandomCreature`，保留区域饱和时 break、物种 RandomSpawn/location 过滤、生境权重、真实 SpawnFunction 与原有种群查询。

没有新增演员视锥过滤，也没有移除原有过滤：原随机补生本身没有“必须屏外”的视线判定。独立模拟中心只参与宿主生态更新，不向模型泄露动物或地形坐标。

已保留原生外层全局数量检查的时序。多个不同中心在一次调用中是否可能超过总上限是原有行为边界，本次未顺便重写；精确重复中心去重不等于对相近中心聚类。

## 已验证

`tests/Westworld.CreatureSpawn.Tests`：12/12 断言通过，构建 0 errors。使用原生类派生探针执行分支及随机点选择，地形处理和数量查询由确定性替身提供；不是实际动物生成证明。

覆盖 provider 零视口路径、空中心、重复中心、非法中心、偏移与重试次数、全局/区域限制、物种筛选、适宜度拒绝。没有运行 GUI、没有操作用户电脑、没有运行模型。

## 待真实验收

由整合线程安排独占原生运行：

1. 零 GameWidget、有一个有效模拟中心的 Living 世界，跨过实际周期事件；记录游戏时钟、中心数量与调用发生证据。
2. 比较调用前后宿主生成状态；合法候选可能因生境、种群或地形全部拒绝，不要求为了通过而强制出现动物。
3. 空中心不产生尝试；无 provider 的人类视口路径保留行为。
4. 仅宿主计数/事件作为诊断，模型仍只收到实际局部观察；不把全局种类数量当成已发现猎物。

当前不能称“自然猎物已充足”“野猪补生已支持”或“无视口长期生态已验证”。Wildboar.RandomSpawn=false 仍保持原样。
