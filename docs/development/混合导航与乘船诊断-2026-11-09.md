# 混合导航与乘船诊断（2026-11-09）

基线 `cjh/0ed4738e`。仅 dot 云电脑、隔离世界；未操作用户电脑和 Minecraft。并行任务分别处理 main065 恢复设计对照、原生乘船诊断、混合导航测试，主线程集成与真实批测。模型与 GUI 顺序执行。

## 本轮实现

- 平地、显式上/下一格台阶在同一 Survey 中作为观察证据候选，交给同一个角色私有前沿记忆排序。
- 平地仍 MoveTo；台阶显式 StepTo，不把普通移动偷偷改为自动跳跃。
- 原生台阶夹具与自然搜索共用 `ObservedStepGuard`，检查实际身体包络、已观察空气/限定支撑接触。3秒证据时效由调用宿主强制，保护器不是独立授权入口。
- 扫描交替仰视/俯视，补上台阶净空证据。最多64次短路线、150秒总截止。增加预算不是自然生存证明。
- 退出时取消本实验持有的在途动作并移除自己的 updateable。

## C 的确定根因

不是模型能力或普通坡地问题。原始隔离存档 `frontier-c-diagnostic/doc/Worlds/World/Project.xml` 的 MalePlayer Id2，Body.ParentBody 为 `id:1:Body`，Id1 是 Boat。原版 PlayerData 在水中出生时创建船并 StartMounting。陆地 FaceTowards 的 CanUseLocomotion 明确禁止 ParentBody 非空。

新实测直接报告 `navigation_mode_unavailable / mounted / parentTemplate=Boat`，不再反复无效转向，不调用模型来解决不可用动作，不无条件下船、不清空 parent、不瞬移。已有 Dismount 只保证原生下船过程，不保证水边落脚陆地，因此尚未自动启用。
