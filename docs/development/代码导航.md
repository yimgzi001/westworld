## 游戏代码分层

Windows 项目引用方向为 `Survivalcraft.Windows → EntitySystem.Windows → Engine.Windows`。平台项目导入共享源码和属性；修改共享代码会影响引用它的平台。

| 层 | 主要目录 | 内容 |
| --- | --- | --- |
| 引擎 | [Engine](../../game/Engine/) | 窗口、渲染、音频、输入、资源解码和序列化 |
| 实体框架 | [EntitySystem](../../game/EntitySystem/) | `Project`、`Entity`、`Component`、`Subsystem` 与模板数据 |
| 游戏逻辑 | [Survivalcraft](../../game/Survivalcraft/) | 管理器、人物组件、世界子系统、方块、界面、模组 |
| 本项目扩展 | [Westworld](../../game/Survivalcraft/Westworld/) | 自主行动相关的项目代码，目前从原子动作入口开始 |
| 平台适配 | [Engine.Windows](../../game/Engine.Windows/)、[EntitySystem.Windows](../../game/EntitySystem.Windows/)、[Survivalcraft.Windows](../../game/Survivalcraft.Windows/) | Windows 引用、原生库、启动与打包；其他平台有对应目录 |
| 构建配置 | [build](../../game/build/)、[Survivalcraft.props](../../game/Survivalcraft/Survivalcraft.props) | 框架、语言选项、共享源码纳入范围与包引用 |

`build/Common.props` 关闭默认源码收集，层内 `.props` 显式纳入共享 `.cs`。新增文件时检查它是否进入目标平台编译，修改项目配置直接编辑 `.csproj` / `.props`。跨平台要求与代码风格见[上游开发说明](../../game/docs/Development.md)。

## 启动和世界更新入口

1. [Program.cs](../../game/Survivalcraft/Game/Program.cs) 的 `Main` / `EntryPoint` 初始化存储、日志和窗口；窗口帧事件进入界面更新与绘制。
2. [LoadingScreen.cs](../../game/Survivalcraft/Screen/LoadingScreen.cs) 加载模组、资源和数据；界面导航由 [ScreensManager.cs](../../game/Survivalcraft/Managers/ScreensManager.cs) 管理。
3. [WorldsManager.cs](../../game/Survivalcraft/Managers/WorldsManager.cs) 管理世界目录、创建与导入导出；[GameManager.cs](../../game/Survivalcraft/Managers/GameManager.cs) 的 `LoadProject` 读取 `Project.xml`，结合模板数据库创建运行中的 `Project`。
4. [GameScreen.cs](../../game/Survivalcraft/Screen/GameScreen.cs) 调用 `GameManager.UpdateProject`，再进入 [SubsystemUpdate.cs](../../game/Survivalcraft/Subsystem/SubsystemUpdate.cs)。它推进 [SubsystemTime.cs](../../game/Survivalcraft/Subsystem/SubsystemTime.cs)，按更新顺序调用已注册的 `IUpdateable.Update(dt)`。
5. `GameManager.SaveProject` 收集 `Project.Save()` 的数据，再执行后台写入；世界实体及组件装配入口在 [Project.cs](../../game/EntitySystem/GameEntitySystem/Project.cs) 和 [DatabaseManager.cs](../../game/Survivalcraft/Managers/DatabaseManager.cs)。

## 开始接入 AI 时

自主人物接入从原子动作开始。先按[当前状态中的差距](当前状态.md)核对适配范围，再读[行动与模型交互](../design/AI个体行动与模型交互设计.md)、[时间与调度](../design/AI时间推进与调度设计.md)和[存档恢复](../design/AI存档恢复与历史回放设计.md)。

查代码时分别沿“个人可见信息、决定来源、游戏动作、实际反馈、个人持久状态”定位。`Project.Entities` 等全局查询用于实现和调试，不自动成为人物允许看到的信息。新增组件或子系统还要核对模板注册、更新次序和持久化；模型回应本身不能作为动作成功的证据。
