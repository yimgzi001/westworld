# 阶段47：多角色规模、故障恢复及生产能力

## 并行分工

规模驱动、障碍/重建驱动、资源采样批处理器、生产调度/健康功能包、独立源码审查并行推进，中央统一接线构建。复用既有AtomicActions、原生角色和调度器，不另造物理时钟。

## 批次

- 基线：2与10名真实ExternalActor独立串行运行，预热10墙秒后测30墙秒；游戏时间与CPU/RSS对齐同窗口。
- 压力：20角色、50角色、恢复场独立世界并行三路，按实测CPU/内存和失败继续调整，明确标争用，不能拿来冒充无争用单世界容量。
- 恢复组合场：人工障碍引发原生失败后恢复；同进程角色移除重建两轮，另一角色独立动作不受影响，旧身份不授权新角色。

初测机器9逻辑CPU、约9.7GiB总内存与6GiB可用，非专用独占保证。并发数量按实测余量调整，不设置主观固定小规模；原生外部角色配置上限50不等于50人实测可用。

资源采样跟踪每个独立进程树，保留分组/边界偏差，区分启动成本与稳态。真实人数、任务成功/失败、游戏速度、资源及恢复分别验收。无模型API，不改网络，不使用用户电脑；只提交源码、可复用测试与精简结果。
