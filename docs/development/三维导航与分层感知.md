# 三维导航与分层感知

更新于 2026-11-11，针对可见场中的“坑里反复上不去”和“站在地面上操作地下工作台”。

## 原来的缺口

原生观察包含方块和角色的三维坐标，但工作站摘要主要给出平面距离。返程在无法一次看清整条路时，直接朝旧站方向短走，没有先确定出坑或下层入口；局部绕路可能再次下到更深处。工作台就在脚下时，平面距离很小，也不足以代表已经走到可操作的楼层。

台阶另有一个执行交接问题：起跳指令可能恰好在原生接触标记短暂丢失的帧发出，原生物理并未起跳，技能却已经记成“跳过一次”；带着横向惯性转弯起跳也可能撞出走廊。这些不能靠给模型重复强调“自动跳”解决。

## 新的感知摘要

| 数据 | 含义 |
| --- | --- |
| 工作站 `position` | 本人记住的完整位置，当前可见与否另列 |
| `heightDifference` | 目标落脚层减本人脚底高度，正数在上层，负数在下层 |
| `sameLevel` | 当前是否已经处于工作站操作层 |
| `interactable` | 当前可见、同层且原生存储查询实际可用；营火按原生取暖距离单独核对 |
| `distance` / `spatialDistance` | 分别保留平面距离和空间距离 |
| `access` | 同层、需要上行或需要下行 |
| `surroundings.standingLevels` | 八格内实际看到的不同地面高度和最近距离，不保证路线连通 |
| `localLayers.confirmedSteps` | 本帧已同时证明落脚、身体净空和跳跃包络的一格上下台阶 |

不读取遮挡后的地图或地下资源。记住工作站的位置可以用于返程，只有当前可见、实际可达的部分进入执行；未知内容仍然未知。摘要最多列六个地面层和八个已证明台阶，不把全量体素逐格发送给模型。

## 三维返程

优先寻找通向目标同层操作站位的完整局部路径。只能看到一部分时，在当前已见连通地面里找中继点，把高差纳入剩余工作量，先缩小楼层差，再比较横向距离和代价。这样允许先朝远离工作台的方向走上楼梯，再从地面返台；目标在下层时，则先沿入口下行。

每个中继点实际到达并落稳后重新观察，不用一条直线猜整条远路。中继到达半径与原生上阶的实际终点兼容；到达后制动期间保持该状态，避免惯性移出半径又多跳一级。全景顶面与本人当前局部观察中已证实的支撑、两格净空合并为执行图，不因射线漏看脚下顶面而丢失起点。同层远行允许翻过中间山脊，不为维持原高度绕远。

中继到达不等于任务完成，最后仍须重新看到本人工作台、处于同层，并通过原生交互射线和距离检查。没有当前可证明路线时明确停止，不在坑内反复绕行。返程仍受距离、总时限、健康、危险和最多十六段限制。

工作站不在同层时，制作菜单不再把它作为已经就绪的操作条件。跟随画面也会显示“先沿已见台阶上到工作站所在层”或“先沿已见入口下到工作站所在层”，不会在接近途中一直显示已经在制作。

## 起跳交接

一格上阶先确认真实支撑，再在原生输入层制动侧向惯性并转向台阶。支撑标记短暂缺失时只等待恢复，不消耗唯一一次起跳；持续缺失仍中断。真正向上离开原高度才记录腾空，起跳后的受阻计时从实际发出跳跃开始。整个动作仍受原三秒上限、一格高差、身体包络和头顶净空约束，没有增加跳跃力、传送、填土或修改重力。

## 验证

- `worksite-pit-up`：四格深坑，楼梯朝工作台的反方向；须先出坑、返台，再原生制成木矛。
- `worksite-table-down`：站在地下工作台上方的完整地板，入口在旁边；须下到同层，原生交互确认后才制矛。
- `worksite-pit-blocked`：入口被封；须零绕行并报告没有已观察路线。
- `contact-step-flicker`：故障注入只清除一帧接触标记，随后恢复原标记；须真正跳上一格。
- `contact-step-persistent`：持续清除接触标记；须及时停止、零位移。
- `contact-step-corner`：初始朝向与台阶垂直并带侧向速度；须先稳住再跳上去。

夹具没有云模型调用。预置地形、工作台、制作原料以及明确标记的接触故障仅用于检查动作和信息边界；自然场的存活、进食、模型选择另记，不拿夹具代替十天验收。

最终 R93 十四项原生回归全部通过，包含上述六项、完整采石往返造炉并实际进食、长距离返炉烤肉及相关旧功能，原生更新异常为零。中间版本的失败、新可见自然场和源码哈希按版本保留在[单人普通生存开发记录](单人普通生存开发记录.md#坑内返程与地下工作站)。
