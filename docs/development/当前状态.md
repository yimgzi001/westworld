# 当前代码与验证状态

本页维护当前实现边界和未完成事项，代码位置见[代码导航](代码导航.md)，复现步骤见[开发与验证](开发与验证.md)。基线为仓库初始化提交 `5c645ae`，上游版本与导入处理以 [UPSTREAM.md](../../game/UPSTREAM.md) / [SOURCE.json](../../game/SOURCE.json) 为准。

当前在 Windows 本机已用验证脚本完成 50 人真实模型觅食短试，并用固定回包验证了 50 人世界的动作间恢复。正式实验尚未启动。下文分列代码能力、已跑过的场景和待验收项。Linux 服务器的历史配置及来源见[运行位置与服务器记录](开发与验证.md#运行位置与已有服务器记录)。
