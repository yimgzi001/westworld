# 阶段46：持续动作并行与取消隔离

沿用阶段45同一原生Project、2/4名无视口ExternalActor、独立session/action owner及当前能力菜单，不重新发明动作执行器。

## 本轮验收

1. 2/4条相隔的人工平地通道，各角色通过自己的当前菜单执行原生持续移动。
2. 两个不同runId共同running的实测跨度至少1游戏秒，至少3个同tick样本，相邻采样间隔不超过1秒；双方均须产生实际位移。采样只能证明观测点状态，不声称每一刻全覆盖。
3. 两角色最终各自成功，互不覆盖owner。
4. 第二组持续移动只取消A；A进入取消终态，B维持同runId并继续位移和成功。取消前后惯性与settle后漂移分别记录。
5. 全部角色均终态/idle后才恢复夹具并退出；记录整个游戏子进程树资源，而非推算单AI增量。

## 分工与边界

四路分别负责原生场景、冻结运行器及汇总、证据契约与规模恢复设计、独立审查；协调者负责中央接线与统一构建/真实运行。

人工场景不计自然生存，也不调用云端模型。同一冻结构建批量运行2人与4人两场，避免并发运行两个游戏污染资源对照。长期恢复和更大规模先形成可执行验收设计，不把尚未跑的10角色或多世界循环算完成。原始证据只留本地，提交源码、可复用测试和精简结果。
