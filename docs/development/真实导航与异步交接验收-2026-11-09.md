# 真实导航与异步交接验收

状态：8a54d664 之后的下一阶段，平地确定性异步交接已实测；台阶与真实4B运动重叠待验收。仅 dot 云电脑，不碰用户电脑或 Minecraft。

## 目标与边界

一个真实完整生存 Player、一套 AtomicActions/ActorTools、一套观察接口；AI 不建视口。模型选方向/目标，技能只执行有证据的局部段，不引入固定生存策略。受控地形夹具不等于自然地图成功。首先验证确定性延迟候选下的生命周期，再错峰运行真实4B，分别报告，不能拿延迟替身冒充模型推理。

## 权威所有权

- 宿主任何动作/任务写入都参与同一租约，取得前读取实际 AtomicActions.IsActionRunning 及原生任务状态。该新公开属性只是只读状态，非授权锁。
- 导航直接持有的 run 不属于 ActorTools.m_direct。导航停止必须调用 LocalNavigationSkill.Cancel 后逐帧 Update，直到稳定终态或明确隔离；普通 cancel_action 回执不能证明导航停止。
- 同理，交接只认该导航 RequestId 的 Arrived 且已稳定释放，不能借另一个 direct/action_status 的成功。
- 所有租约、技能和 AsyncDecisionHandoff 操作限游戏线程。后台只产不可变候选，不触游戏对象。
- 取消/失败先作废候选；旧控制者、旧计划、旧前序、晚到回复均不可复活。交接重新观察并核对局部可达证据，不凭上一轮候选承诺未来状态。

## 场景矩阵

1. 平地当前段真实 Moving 且原生动作在运行、产生位移时发出150ms延迟候选；早回先缓冲，前段成功+稳定+新证据才执行下一段。
2. 移动中取消，drain 到稳定；晚回复不能启动旧方向。
3. 人工加入真实障碍，记录原生失败/受阻与停稳，后续候选不得盲执行。
4. 前段已终结但候选仍在途，保持静止；请求期限结束后撤销，晚回仍拒绝。
5. 相同机制验证一个已观察台阶。生命周期先通过后再运行真实4B的决策与运动重叠，不暗示零延迟或永久不停。

每段20秒、总场景90秒，预算到即停止/清理，不延长移动掩盖模型等待；预算和人工故障均入日志。若场景因缺证据失败，保留失败而非注入全知路线。

## 度量

用单调时间记录请求、实际运行、回复、前序终态、停稳和后续实际运行；UTC只作标签。仅 Status=Moving 不足以证明动作开始，还须原生动作实际运行与位置证据。报告请求到动作、回复到动作、前后段停顿、在途决策与真实运动交叠时间、受控路径/净位移、健康、更新异常和清理状态。初始及段末稳定门至少约0.25秒，不能宣称零停顿。
