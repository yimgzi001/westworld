## 本批实现与边界

- P1 自然食物：实际来源、自动/显式拾取、食用事件、库存减少、饱食与统计增量联结。保留初始食物自保，但出生时已有同精确 value 的食物始终不能作为新获取成功；目前属于保守假阴性限制。动物和制作/烹饪转换归因尚不完整，不禁工具，也不把未知转换算成功。
- P2 连续计划：真实移动期间可预取，但原计划尾继续执行；每步保留原参数指纹、真实 receipt/run，完整成功并停稳后才重验候选。旧尾失败/取消/期限/身份变化会使候选作废。单步骤 Dig 预取尚未纳入。
- 请求归属：普通、本地模型和文件控制器发起前生成实际 DecisionId，步骤保留接纳计划的 ID 和请求/回包时间；新预取不得覆盖旧尾的来源或延迟统计。
- P3 感知：不可变地形帧、角色/世界范围、同次快照校验、未知与历史过期、差量合并纯契约。尚未接真实宿主 Capture/Prompt，不声称已解决两次扫描一致性；库存/实体沿既有事实链，不另造第二套记忆。
- P4 交付：领取幂等、准备后未决阻塞、原生双方库存与来源守恒、部分交付、世界检查点匹配恢复纯契约。未接真正双方库存转移钩子；现有掉落拾取事实不能冒充群体交付。
- P5 批测：独立食物验收器，不信 host 的“通过”字段；正常世界真实模型场与人工延时/失败/取消夹具分开，不把固定驱动当模型，不把单导航当多步尾。
