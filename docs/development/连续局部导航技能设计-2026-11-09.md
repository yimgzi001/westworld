# 连续局部导航技能：完整阶段设计

基线 cjh `8000bb11`。目的不是让模型每格发指令，也不是提高循环次数，而是把 `Survey/FindFood` 作为持续目标，由本地技能维护动作与真实证据。

## 单一控制者和阶段

1. **Observe**：同角色新观察更新≤3秒局部记忆；只以真实当前视觉发现食物，历史只辅助导航证据与排名。
2. **Select**：根据已知落脚格选择平走/上下台阶，持续向尚未探索的已观察前沿推进。
3. **Align**：当台阶要求轴向起跳而角色不居中时，在当前已观察完整支撑/净空里短距对齐。对齐是技能内部子阶段，不需要模型调用，不伪造探索到新格。
4. **Look**：针对脚底、背侧身体净空、前方落点和上方缺失证明格调整视线；有限循环，无进展则换目标或明确失败，不无限机械转圈。
5. **Execute**：只有一个原生动作持有运动输入，继承有界时间、对应proof与当前身体检查；正常平走接续不强制每步完全停稳。
6. **Stopping/Settling**：取消或失败后先停止输入，再等真实落地/速度连续稳定。取消不等于停止物理。死亡、挂载、持续浸水/失稳或超时单独报告，不在空中继续规划下一跳。
7. **Food handoff**：本次真实视觉发现可采食物后，模型选择ForageOne，资源引用重验，衔接采集→实际拾取→进食→生理与库存差。人工资源只作完整链正控，天然世界失败照实记录。

## 边界

只有普通完整Player陆地导航。乘船不解除挂载，不瞬移；需要单独观测安全岸边与原生Dismount验收。也不把游泳、危险食物、不可见落点或全图坐标默认为已支持。

观察、几何对齐、停止稳定性可以并行开发和离线测试；主线程只集成一个状态机，真实GUI/模型顺序运行。文件所有权隔离，最终固定构建统一回归、原生人工完整链与多天然种子，再中文提交cjh。
