# 感知、局部记忆与模型主导探索接口

状态：**设计交接，完整新增协议尚未接入宿主，未运行GUI/API。** 文末另列P3已实现的最小地形纯契约，不代表下述全协议完成。基于阶段32后的SC工作树，以及固定提交的MC公开源码只读复核。31/32固定驱动继续作为历史诊断，不再向其追加生存或找岸规则。本设计不修改Program、NativeToolOffers、动作执行器或旧证据。

## 1. 全局定位与依赖

方向、目标、是否探索、是否等待、是否换工具由模型决定。程序负责事实、动作条件、有限连续执行、停止与真实结果，不自动选择“最优资源”“岸边”或强制把空计划替换成走路。

```text
Game同次Capture：自身 / 眼睛姿态 / 扫描 / 对象 / 库存
    ↓ 原始可信事实，唯一角色和世界绑定
ActorLocalMemory：当前证据与历史位置分层
    ↓ 同一快照；历史不能生成当前交互权限
PerceptionChanges + LocalNavigationDiagnostics
    ↓ 事实变化、未知/受阻、有限可选目标与参数语义
最终ModelFacts → Prompt与Offers同源 → 模型选择
    ↓ 显式look / navigation / action / wait
既有唯一动作owner、原生run、期限与取消排空
    ↓ 新观察、原生终态、库存变化；回到事实层
```

没有新的物理tick、第二套动作控制器或后台全世界扫描。下列名字为建议协议名，不宣称已有类型：

|模块|输入/输出|已有地基|接入依赖|
|---|---|---|---|
|`PerceptionFrame`|同次捕获的不可变事实、姿态、覆盖与来源|Game `ActorWorldMemory.Capture`、`SharedVoxelScanner`|Game返回同次扫描的有界格证据；Adapter只转换DTO|
|`ActorLocalMemory`|frame → 当前/历史/未知分层视图|`LocalObservationMemory`、`ActorWorldMemory.ReadMap`|统一capture身份和时钟；不另建第二套持久地图|
|`PerceptionChanges`|相邻可比较frame → 有界变化条目|暂无通用变化日志；已有`outcomeFeedback`可复用结果字段|纯helper可先测；最终投影决定哪些事实可给模型|
|`LocalNavigationDiagnostics`|模型指定终点/方向 + 当前证据 → 可行/缺证据/能力不适用|`ObservedFlatRoutes.Inspect`、`NavigationLookPlan`、台阶/对齐投影|从现有内部原因生成结构化公开反馈；不选替代方向|
|模型工具适配|明确目标 → 现有动作|`FaceTowards`、`host_navigate_local`、`MoveTo`、Dismount等|Program/Offers所有者统一接线，保持现有幂等与handoff|

依赖方向保持Adapter → Game、Runtime；Game不能引用Adapter DTO。纯记忆/变化helper不读取Terrain/Entity，不持有可执行权限对象。

## 2. 同次观察合同

建议内部frame最少携带：

```text
scope: worldSessionId, actorId, bindingRevision
capture: snapshotId, sequence, gameTime, monotonicCapturedAt
pose: bodyPosition, bodyFacing, eyePosition, eyeForward
self: health, ...现有生理事实..., isMounted?, hasParentBody?, grounded?, immersion?
cells[]: cell, state(known|unknown), value?, visibleSample?, sourceSnapshotId
objects[]: 当前真实对象/掉落事实，sense(vision|proximity)，当前ref
inventory: 本次捕获的真实库存
coverage: window, radius, candidateCount, knownCount, unknownCount,
          sample/read budgets, scanComplete, outputOmitted, projectionOmitted
```

- 外部模型仍通过最终`ModelFacts`看有限事实；不必每轮发送几百格原始数组。保留当前可见非空气列表，额外提供有限已知空气/未知统计与当前目标的缺证据摘要。若以后提供按格分页，只能读取同一已捕获frame，不能借分页查询隐藏地形。
- 当前Game公开observe只返回非空气`visibleBlocks`；Adapter的`NativeActorSession.Observe`拥有known/unknown格网，包括已知空气，但这是另一条捕获链。**不能把前者缺项当空气，也不能从后者另一次Observe拼成“同次”快照。** 先统一内部frame身份，再扩展投影。
- `self.facing`是身体朝向，`coverage.forward`来自眼睛；上下看或头部偏航时两者不同。资源可见性比较用眼睛姿态，native相对转向参数按其身体Facing契约处理。
- `gameTime`用于世界事实顺序；单调墙钟用于超时、控制期限。现有`LocalObservationMemory`使用Adapter观察时钟，不能直接拿Game的gameTime与Stopwatch值相减。跨层转换须明确时钟来源和capture映射。
- `scanComplete`只表示声明格网未因扫描预算中断，不是360°看全、全部格已知或环境没有资源。输出裁剪、视野未知、未加载、历史过期是不同概念。
- 当前`SharedVoxelScanner`只有nullable Value与总预算数据，尚未输出逐格未知原因。第一版仅可说`unknown/unobserved`；只有生产者明确记录了原因，才能细分`outside_fov/occluded/unloaded/budget_exhausted`，不得事后猜测。
- 未知self字段可以省略或null，二者都不等于false。grounded仅证明本体支撑接触，不证明目标路线安全；immersion不是水深、氧气或安全游泳能力。

## 3. 局部记忆与引用

复用现有`LocalObservationMemory`默认1024格、半径5m、TTL≤3秒的短证据窗；复用`ActorWorldMemory`最多128个历史位置。不要用模型摘要替代这些结构化来源。

每格以`(worldSessionId, actorId, bindingRevision, cell)`为逻辑键，当前/历史分开：

```text
current: 本frame确实known；只有当前合法ref进入交互菜单
historical: lastKnownValue, lastSeenSnapshotId, lastSeenTime, age
unknown: 本frame没证明；不含伪造的当前value
```

本次unknown不能刷新lastSeenTime，也不能删除历史并声称世界方块消失。视角变化后可保留历史导航线索，但必须标历史；TTL过期/容量淘汰属于记忆变化，不是世界变化。已知空气必须由同一扫描器实际观察得到。

模型当前交互ref和内部格坐标不是同一种权限。旧ref失效、截断、世界重载、角色重绑后，不能自动换成相邻资源或用历史同坐标补权限；当前观察重新授予新ref。历史位置可以作为回访意图，不能授权Dig/PickUp/攻击。

局部导航可继续使用其明确时效内的历史格证明并标最大年龄，派发前刷新，执行中超龄取消。这里不把“3秒历史证据”宣传为“当前确定可走”。旧`LocalExploration.Select`会自动按前沿/访问次数排序；新模型接口可以展示访问/失败边事实，不应直接把该Select变成未经模型选择的生存方向策略。

## 4. 观察变化事件合同

建议纯接口：

```text
Observe(previousFrame?, currentFrame, limits) -> ChangeBatch
ChangeBatch: scope, fromSnapshotId?, toSnapshotId, sequence,
             baselinePresent, entries[], omittedCount, resyncRequired
Change: kind, subjectKey, previousEvidence?, currentEvidence?, reason
```

只处理同scope、单调capture sequence、合法有限数据；非法输入全量验证后拒绝，不先部分更新记忆。重复snapshot不得产生第二批逻辑事件；世界/绑定切换清空旧基线并发`baseline_reset`，不得跨角色diff。事件只是事实提示，不能作为动作票据。

|事件|允许说什么|不能推断什么|
|---|---|---|
|`observed_first` / `observed_again`|本次首次看见/重新看见此格或对象|不是生成/刷新了资源|
|`observed_value_changed`|同一格两次真实known值不同，保留两次来源|不推出谁挖了、何时在不可见期间变化|
|`observed_empty`|旧非空气格在本次实际known且为空气|不是仅从visibleBlocks列表缺项得出消失|
|`not_currently_observed`|旧目标本次不在当前可用事实中|不能叫destroyed、collected、dead；裁剪也可能导致缺项|
|`self_fact_changed`|真实自身挂载/支撑/浸水等变化|缺字段→false不是下船；漂移不是主动导航|
|`inventory_delta`|真实同次库存前后数量差|复用已有反馈；不独立证明资源来源或任务完成|
|`knowledge_expired` / `knowledge_evicted`|私有证据过期或容量淘汰|不是世界资源消失，不触发追赶/采集动作|
|`navigation_terminal`|绑定request/run/receipt的真实终态、剩距、已行距离和停止状态|部分移动不叫到达；取消受理不叫已停稳|

块比较使用Game明确的value归一化函数，例如移除纯光照位；纯helper不猜mod内容编码。格键而非随机ref用于“同格值变化”比较。对象若没有稳定身份关联，只能“当前观察列表不同”，不能按最近坐标拼出同一个移动实体或杀死/拾取因果。

全世界block-changed事件可作为内部失效提醒，但不能把隐藏坐标/新值推送给模型。涉及正在使用的局部证据时，先标需重验/停下，再用本角色新视觉决定可公开事实。不得从隐藏来源审计生成感知事件。

事件与模型调度分开：动作/库存重要结果和控制失效可唤起检查，其余观察变化合并到有界邮箱。建议初版每actor最多64条待处理、每prompt最多16条摘要；这是配置上限，需测量后冻结，非性能承诺。同subject多次变化可合并，但取消/失败等关键终态不能被“最新值覆盖”抹掉。超限显式omitted/resync，重发当前快照，不无限积压或每格叫模型。

初版继续发完整当前有限快照+变化摘要，**不做delta-only协议**。后续若节省tokens，基线必须对应模型实际收到的快照，不是宿主最近扫描；未投影的ref不能由事件绕回Offers。异步旧候选继续走现有`AsyncDecisionHandoff`的前序身份、期限与fresh复验，不新增只凭event序号的派发通道。

## 5. 模型可选look/navigation明确契约

不新增高层“找岸/找木头/找食物”确定性策略。先把已有工具语义和结果说清：

|入口|当前语义与适用范围|模型应收到的真实结果/限制|
|---|---|---|
|`act_FaceTowards(destination,timeout)`|朝当前观察位置，目标ref需fresh；不能用历史块冒充当前观察|原生run终态与实际eye/body姿态；不是导航|
|`act_FaceTowards(bearing,pitch?,timeout)`|bearing相对当前身体Facing；pitch为绝对头俯仰；省pitch保留原头俯仰|身体被parent约束时不可用；不是固定扫描循环|
|`host_navigate_local(bearing,distance,max_seconds)`|绝对世界方位0=+Z、90=+X；1–4m、1–12秒；现有observed局部路线/补观察/对齐/台阶|只朝模型指定方向，missing/blocked时如实停止，不改为另一个资源方向|
|`act_MoveTo(destination或bearing+distance,range,timeout)`|原生目标移动；bearing是相对角度；完整Player走direct locomotion，无AI Pilot/Pathfinding|不是已证明安全走廊；有碰撞/期限和真实失败；不能称自动绕障全局寻路|
|`host_cancel_navigation(request_id)`|只取消指定host导航；与cancel_action区分|stopping/busy直到真实停稳或quarantine|
|`read_map`|带lastSeen的历史位置分页|用于模型选择回访，不保证资源仍存在|

角度统一在文档/结构化事实中显式列明：Game `RelativePoint`绕+Y轴旋转负bearing；若诊断世界角用`atan2(x,z)`，native新角=当前角−bearing。+Z下native +90指向−X；不要把host导航的绝对90传到native当同义词。`NavigationLookPlan`又采用`atan2(-dx,-dz)`，其Direction向量为适配权威，禁止直接混用YawRadians。

导航反馈建议在现有结果上增添结构化诊断，不另开执行器：

```text
requestId/runId/receiptSequence, phase, terminalStatus, reasonCode
requestedEndpoint, actualPosition, pathDistance, remainingDistance
bodyMode: walking|mounted|swimming|unavailable|unknown
observationId, evidenceMaximumAge, missingCount, missingSample[]
blockedReasons[]: missing_or_unknown | refresh_needed | observed_solid |
                  unsupported_ground | mode_unavailable | native_blocked | ...
settled, cancelRequested, ownerQuarantined
```

状态区分`accepted/running/stopping/arrived/failed/cancelled`。路线只做了一部分，仍以真实failed及remaining返回，可另记`progressMade`，不修改为成功。`segment_start_InvalidOperationException`这类当前粗错误应在入口归类为实际body/lease/clock原因；不能让模型靠猜异常文本决定反复同动作。

`NavigationLookPlan`可在**模型已授权的同一导航目标内**补缺失支撑/头部净空证据；这属于完成已选目标的局部执行，不是新战略方向。独立探索look则由模型明确选角度/目标；不把内部四周候选自动升级成选岸行为。每次主动look后获取新视觉；没得到新信息也是正常结果，不伪造coverage。

## 6. 受阻与水边能力缺口：不要改名掩盖

|实际缺口|源码现状|合理下一步，不替模型选方向|
|---|---|---|
|骑乘时不能陆地转身|`FaceTowards → CanUseLocomotion`要求ParentBody为空；32公开自身事实已能说明|新增独立、有原生限位的头部look能力，或明确mounted-look不可用；不能清ParentBody假装转身|
|船上工具菜单不完整|原生Catalog已有Mount/Dismount/Steer；当前Profile仅32加了条件Dismount|逐一暴露并复验真实能力。Mount target必须绑定实体；不能落入当前默认block target枚举。Steer当前只限原生turn/throttle/duration，不承诺驶向某岸|
|Dismount不证明安全落脚|原生只验证挂载关系、侧向碰撞和动画终态；未证明陆地/水深|模型看到“下船动作可尝试，但落点安全未验证”；若需要安全下船技能，独立证明目标落脚/净空和真实落稳，不能自动开关旧动作扩大保证|
|有游泳控制，不等于上岸导航|direct MoveTo在ImmersionFactor>.5且SwimSpeed>0时设置SwimOrder|水深、可呼吸空间、可上岸接触与身体包络未形成已观察路线合同；暂不宣称水底ref可达或安全。后续游泳mode单独设计/原生验收|
|host局部导航仅稳定地面|Start要求grounded、无parent、immersion≤.1、低速度；执行中持续守卫|明确mode_unavailable；不让模型重复同请求“试运气”，也不隐式下船|
|可见沙/砾不等于稳定走廊|ObservedFlatRoutes只接受限定稳定全块；fallback LocalRouteCandidates有显式ObservedFullCube|公开所用groundPolicy与局限，不把看到一片表面当整段空气/支撑证明；模型可选补观察或别的目标|
|走廊/坡地受限|连续平路为同层轴对齐完整包络，台阶有独立投影与守卫|基于当前证据解释哪项不满足；扩大几何支持须独立纯测及原生台阶/动态阻碍验收，不用提高重试次数代替能力|
|对象/危险信息不足|模型见实体name/position/ref，未有统一可验证攻击性/骑乘类型/碰撞事实|可提供来自原生已见对象的能力描述；不能按模糊name猜或从世界实体全集补资源位置|

32三种子已经区分“骑乘导致陆地动作不可用”与“可正常转向但未见候选”。后续正反例应检验接口事实与模型选择，不改成保过的固定找岸流程。

## 7. 推荐实现顺序与验收

1. **合同与同次来源**：先冻结scope、capture/clock映射与当前/历史/未知语义。Game/Adapter补同次frame桥，不增加扫描次数；Program/Offers按最终ModelFacts接入。量化实际扫描次数、reads、prompt体积，不用代码行数宣称更快。
2. **纯变化helper**：只做diff/有界合并/基线恢复，不选路线。测试unknown不变air、known→unknown不变destroyed、真实air变空、光照不制造资源变化、ref轮换不制造新物、跨actor/session/revision隔离、时钟回退/重放、过期/淘汰、全量验证后提交、事件截断/resync、模型裁剪无权限回流。
3. **公开导航诊断**：复用Inspect结果，区分缺证据、已见阻挡、mode不支持、超时/取消/未停稳。look与nav四轴/±180/俯仰测试；旧run回包不能覆盖新run。纯测后再由协调者安排原生受控反例。
4. **真实感知回归**：同角色转头→新观察、回访历史格改变/遮挡、known-air与输出裁剪、跨角色不可串；look失败不宣称观察成功，部分移动不宣称arrived。天然海上/沙滩/陆地分别保留真实结果，不注入资源、不暗读来源审计给模型。
5. **模型方向选择**：同一公开接口让模型明确选look/nav/wait/Dismount等；评估有证据的选择、失败后避免无意义重复、未知时不虚构路线、实际获取和费用。无模型纯测不宣称模型自主；动作数量/转向覆盖率不替代任务成功。
6. **水上能力与多人预算另门**：先补真实动作可观测能力，再谈自然上岸和长链。全世界统一帧预算与每actor有限邮箱应先于扩大人数；不照搬MC每角色40ms预算，更不能声称50人已验证。

最初交付为设计与源码审查，不创建第二套记忆实现。后续P3经协调者授权按第2步实现最小纯helper，范围见文末；公共完整frame与宿主接线仍为单独工作。
