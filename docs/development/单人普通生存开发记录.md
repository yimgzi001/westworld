# 单人普通生存开发记录

## 目标与验收

在自然生成的普通「生存」档里，让一名 AI 依据局部观察自己选择生存目标，并用原生动作维持生命。开局食物清空。模型使用官方 Terra，关闭思考。测试累计 API 用量上限为 1 亿 token，单局请求次数不限。保留可切换的跟拍画面。

### 2026-11-11 本轮十天生存目标

- 这一轮先用上一场死亡记录和游戏攻略指导开发。复现棕熊逼近时的挪步受阻，验证角色在崖边能提前转向有落脚证据的退路。保留连续导航和自动跳。长期生存优先补足稳定食源、做熟食及复用安全庇护。 [生存战争生存技巧](https://survivalcraftgame.fandom.com/wiki/Tips,_Tricks_and_Common_Mistakes) · [游戏作者更新记录](https://kaalus.wordpress.com/updates-history/)
- 主验收使用上一场的自然种子 `natural34-b`。角色必须自主觅食、进食和过夜，连续活满 10 个游戏日。两天用于中途检查。十天是目标验收门槛，记录后角色仍在同一场自主行动。达标前失败则记录原因，继续优化并复测。记录实际进食、主动睡眠、存活时间及验收结果。
- 保留 48 格同帧全向观察、关键生存信息和多步决策。压缩重复输入，减少容易被避险动作打断的请求。用 `natural34-b` 开局后 2400 游戏秒对比。上一场在这个窗口发出 54 次请求，53 次有用量，共 307,832 token，其中输入 305,129、输出 2,703、缓存命中 0。目标至少下降 25%，即最多 230,874 个有用量记录的 token。取消和缺少用量的请求单独统计。 [OpenAI Docs 缓存与用量](https://developers.openai.com/api/docs/guides/prompt-caching)
- 每轮集中实现和测试，按自然测试发现继续优化。用中文记录改动和测试结果，每轮完成后提交并推送 `cjh`。

## 2026-11-10 提前避险和跟拍

- 增加 `scout_local`。模型指定方向和目的，技能完成原生转船、短程划行、靠岸下船和陆地短步。食物、可睡地点、受伤或路径受阻都会触发重新决策。
- 角色定时从自己的视锥和遮挡检查获得猎食者信息。在实际危险距离内可以中断采集、等待或过期的模型决策，执行原生避险动作。饱食充足时减少在水中停留觅食。
- 增加 `--watch`。镜头跟拍同一个角色，画面层没有独立玩家输入，也没有加入生物生成用的视口列表。F8 可以切换画面。

## 2026-11-10 一次环视和连续生存动作

- 陆地首次决策、抵达新区域或旧观察失效后，原地向四个方向取样一次，再合并实际见到的食物、动物和地形。历史目标用于选择方向。实际拾取前需重新观察并进入原生范围。
- 地面有支撑和净空证据时，优先在同一原生移动动作内连走 2 至 4 格，走路时把视线恢复到接近平视。台阶仍校验一格落差和真实落脚。遇到障碍或证据不足时再观察。
- 一次 Terra 决策最多安排四步。原生脚本已验证三个等待动作共用一次决策，中间因空背包无法进食时会停止后续一步。采集现在会自己沿已观察的地面靠近食物，并核对拾取或库存增长，再继续吃。
- 黄昏前约 120 游戏秒开始优先准备庇护。根据攻略选择三格深土坑作为临时方案。用原生动作挖已看到的软土、捡土、封顶、休息，醒后拆顶并跳起垫土回到地面。原生睡眠条件继续生效。 [原作者睡眠说明](https://kaalus.wordpress.com/2017/02/26/sleep/) · [临时土坑攻略](https://survivalcraftgame.fandom.com/wiki/Tips,_Tricks_and_Common_Mistakes)
- 生肉留在背包中。当前游戏配方要求工作台和 8 块圆石制作熔炉，生肉的烹饪配方还需要燃料。完整烹饪链等待生存基础闭环验证后接入。 [熔炉攻略](https://survivalcraftgame.fandom.com/wiki/Furnace)
