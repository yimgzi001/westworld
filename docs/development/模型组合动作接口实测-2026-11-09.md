# 模型组合动作接口实测

日期：2026-11-09；上个已推基线 `02805413`。所有执行在 dot 云电脑，新隔离世界，不使用用户电脑。

## 本阶段交付

模型从实际 ActorTools schema 和角色私有观察中选取有界工具步骤，不再只能从“吃、采集、搜索”三个高层候选选择。制作、攻击、拾取、存储转移、炉内等待等能力经同一通用会话入口接入。当前配置筛选 28 项原生工具，实际菜单随可见引用变化；不能说所有原生能力均已开放或验证。

- 一角色一控制所有者，游戏线程执行，模型只接收 JSON。
- `(session,actor,sequence)` 有序防重复执行；缓存淘汰不允许旧请求重跑。进程内账本不是崩溃持久事务。
- 原生错误/不确定写入先取消或读取并对账；取消不回滚，熔炉燃烧也不会因为取消等待停止。
- 每步刷新真实观察并校验原参数，不用邻近对象悄悄替换过期目标。
- 长动作由原生执行器异步运行并返回最终状态；目前模型在步骤/计划边界规划，尚非同一角色动作中预取下个模型计划。
- 工具参数的语法合法不等于配方/库存/碰撞等前置成立，最终仍由原生层判断。
