# 全能力统一接口与批量真实验收计划

2026-11-10，用户要求优先一次覆盖接口、并行开发后集中调用真实游戏采集，而非逐个食物/动作长期串行。本文件是下一大批计划，不是完成报告。

## 基线与范围

原生catalog共52项（31动作、21查询/任务），另3个宿主导航工具。详见逐项矩阵与源码复用报告。原生存在、模型菜单开放、当前可调用、真实调用通过、模型自主采用，是五种不同状态，不互相冒充。所有工作在dot云电脑，cjh分支，不碰用户Minecraft/main/原始世界。

本批优先复用ActorTools、ActorTaskExecutor、RecipeTaskComposer和现有执行账本。大模型选择目标、顺序与策略，本地技能负责连续执行及真实结果；不新增固定生存路线或任意脚本代理。

## 并行模块与文件边界

1. **统一能力层**：原生descriptor索引、查询/写/取消/任务分类、类型化schema、原生范围与实验profile显式区分、不可用原因、分页发现。解决当前32工具预算而非将55个大schema一股脑塞入上下文。不得为覆盖率静默漏工具。
2. **身体/交通/装备**：姿态、攀爬、骑乘操舵、游泳相关原生MoveTo、穿脱与物品选择。引用来自当前观察及本人装备事实，不能默认target为方块。
3. **生产/交互/战斗**：库存/掉落/采集/放置、配方及原生组合制作、工作台/熔炉状态、交互/物品使用、远程瞄准、配置与家具。嵌套对象只能来自实际可读参数与闭合schema，不允许任意JSON或伪造材料。
4. **社会/有限任务**：真实可听/可见人、Speak/Offer/Respond、原生submit_plan及结果查询。保持单一任务执行器；不另造第二条动作队列，不把社交表变成全知地图。
5. **公共观察/投影与验收**：统一真实引用、当前槽位关联、已知/未知/截断/历史状态、结果差量和原生终态。准备8组连贯正负场景；与实现并行，但冻结统一SHA后串行占用游戏窗口批测。

模块各自拥有新适配文件和纯测试，中央registry/Prompt/原生会话仅一位集成者修改。每模块先完成最小编译/契约回归，最后统一host/源指纹、全回归、原生批测与独立审查，不边跑边改代码。

## 统一契约

- 每项能力返回原生是否实现、actor是否支持、当前是否可用、参数来源/范围、不可用原因、实验限额及原生执行证据。
- 状态观测只给角色当前可感知或本人已知历史；旧地图可回访，不恢复旧实体/资源操作权限。
- 动作统一session/actor/request/版本/期限、accepted与terminal区分；fresh重验、唯一owner、停止、部分完成/失败/unknown不可省略。
- schema按真实类型映射；库存值/槽/count保持关联；姿态/转向负值保留；对象/数组按照原生定义闭合验证。
- 工具发现/分页是传输预算，不是隐藏游戏能力。范围放宽前核验原生约束及取消/总请求预算，不移除有限界限。
- 日志常规稀疏、诊断可细采，关键动作/失败/取消/停止单独保留；不把1秒写成统一目标，也不为逐帧覆盖消耗整个开发周期。

## 集中真实验收

按能力审查所列8族：观察/知识；移动身体交通；物品装备；采集建造；制作设备；战斗使用；社交交付；有限计划与中断恢复。每族一次连续场景覆盖正常路径和关键错误，真实调用原生状态/库存/世界变化，人工夹具明确标注；不为每个参数新开一场。

记录原生返回、角色/世界变化、失败原因、取消后无新写、CPU/内存及有效采样窗口。接口验收与模型自主生存分开。真实模型只在已批准数据范围及官方授权路径内做有限新场次；拒绝则停止该步骤，不绕过，不重放历史未知请求。离线、人工、助手决策、外部模型四类结果分开。

## 交付与后续

每个完整批次推cjh源码/测试/能力矩阵/脱敏可复现证据。排除密钥、私人文件、版权游戏资产与存档。提交前核验完整tree和远端租约，不改main。下一里程碑是52项能力的统一可发现适配及状态清单和8族原生采集报告，不等同‘所有能力所有情境已通过’，未支持项必须点名。
