# 自身骑乘与支撑观察（32批）

`observe.self` 与 `read_self` 共用原生 `ActorQueries.ReadSelf()`，新增如下字段（JSON camelCase）。旧 SelfView 构造仍兼容，未填值为 null，原生 JSON 序列化会省略 null 字段；缺字段或 null 均是未知，不把未知解释为 false。

|字段|事实来源与语义|
|---|---|
|isMounted|存在 ComponentRider 时读取 Mount != null；缺 Rider 为 null。骑乘动画过程中如实反映当前 Mount，不保证动作可执行。|
|hasParentBody|当前 ComponentBody.ParentBody != null；与骑乘分开，不把所有父子身体关系称为骑乘。|
|grounded|StandingOnValue.HasValue，代表原生支撑接触，不表示安全地形、未滑动或可到达。|
|immersion|当前 ImmersionFactor；非有限值为 null，与原 read_environment 使用相同原生量，不把浸水推断为游泳能力。|

actor/body 不可用时 ReadSelf 仍整体返回 null。观察投影保留这些字段，不读取其他实体位置或地图。自然确定性 driver 可据两个明确 false 判断其转向前提；字段缺失必须视为未知。

原有 `act_Dismount` 无目标动作进入宿主工具菜单，仅当实际 observation.self.isMounted 为 true 才提供；导航繁忙仍不提供写动作。没有自动下船，没有新增 Mount，也没有将方块引用伪装为坐骑。实际派发仍走原生前提及 ledger，菜单存在不等于原生成功。

本次只做源码、组件契约序列化、模型投影和菜单纯测以及编译。真实骑乘/地面/浸水数值与下船结果须由独立原生场景验证，不能用 DTO 测试冒充实测。
