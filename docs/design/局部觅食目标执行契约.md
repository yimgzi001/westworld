# 局部觅食目标执行契约

本阶段沿用 ADR-001 的“一世界权威游戏线程、模型低频决策、本地连续技能”。不是增加每格调用模型的脚本拼接。

## 分层与完整能力边界
1. NativeActorSession 在游戏线程产生私有观测快照：自身身体/库存、距离5米内且120度视锥内的已加载方块，保守体素遮挡。采样包络扩大至9×9×4=324格，unknown保持null。扩大包络不扩大真实可见距离。
2. IDecisionProvider 异步接收纯DTO，只返回目标。当前测试提供器是300ms延迟确定性替身，不是语言模型。
3. HighLevelDecision 的 SatisfyHunger/ForageOne 携带 CellTarget 坐标与原观察完整编码值。调度器比对保留的独立原始快照，不信任提供器可改的输入数组。
4. NativeForaging 接受一个有ID的父目标，独占该角色控制；执行 Approaching → Harvesting → Collecting → Eating。父目标不逐格请求模型。
5. 原生身体/物理、Miner.Dig、自然掉落与PickableGathererPlayer、Clothing进食结算仍是权威。禁止通过改地形或发物品完成技能。

## 前置与后置证据
- 当前只支持可见的成熟普通南瓜131。腐烂244不在范围。完整块值会含光照及数据，不能把131与完整value直接等同。
- 提交：会话、角色、观察ID与3秒时效、三维位移≤2米、目标唯一已知证据及预算验证。
- 接近：有限直线局部移动，原生碰撞不绕过；最多0.4归一化速度。支撑/区块状态由局部执行器判断，不能作为模型隐藏资源知识。没有通用绕障寻路、跳跃或长距离探索。
- 采集：逐帧从角色眼睛重新射线，第一命中必须仍是目标且距离≤3米。目标变化停止；使用原生挖掘进度、挥动与掉落。方块变空气且BlocksDug增加1才认定采集。
- 拾取：接近刚采集的已知位置，等待原生吸附。只有自身库存中对应成熟南瓜实际净增才认定获得；不调用AcquireItems补发。掉落物编码原生会改IsDead，不能与地形编码直接比较。
- 食用：重新观察实际库存槽，通过已有原生进食路径；库存减1、Food增加、FoodItemsEaten增加1联合验收。
- 结果保留 Harvested、Collected、FoodBefore/After与位置/阶段。部分失败不回滚已发生世界变化。

## 幂等、取消与边界
同一ID同payload重放返回同一记录；不同payload冲突拒绝；跨技能ID统一排斥。全会话最多256票据，父任务为未来食用子票据真实预留容量。记录不静默淘汰，重启后的持久化对账尚未实现。
每父任务墙钟30秒上限；采集和拾取阶段分别8游戏秒，无接近进展2游戏秒则退出。父期限检查先于子进食；取消撤销输入、撤销未结算食用、保留已经入包证据。清除输入不是冻结物理，终态不表示已经消除惯性。
采集后区块会临时离开Valid；此时停止并等待重建，而非立即误报不可走。预算仍持续计时，不能无限等待。

## 不能声称的能力
本次人工平整地面、放置一株原生南瓜、清空初始库存，是明确的集成夹具，不是自然生成世界自主找食。
库存同值净增证明本角色取得物品，不在多人竞争环境证明来自唯一指定掉落；掉落证据身份/独立可见掉落DTO尚未实现。
未证明自然环境探索、制作、狩猎、烹饪、跨session恢复、长期生存或大规模稳定。
下一步以同一目标契约接本地授权4B模型，记录实际请求/输出/用时与资源。随后验证自然生成资源和可恢复宿主，不用替身成功代替模型成功。
