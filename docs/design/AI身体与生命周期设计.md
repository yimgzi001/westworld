# AI 身体与生命周期设计 v0.2

> 迁移保留的目标设计。适用性需按 Survivalcraft 游戏机制重新核对，其中的设计要求不表示当前游戏或 AI 接入已经实现。

本方案衔接个体状态、行动、世界、调度与初始化设计。用户已确定关注身体、成长、生老病死和繁衍；以下方程形式、资源分配顺序和首版范围是设计建议，并非用户已确认或经过验证的人体规律。

## 1. 采用什么层次的身体

建议采用“资源收支＋少量功能系统＋局部伤势＋生命周期阶段”的宏观身体。只有统一生命值无法解释饿、困、失血和腿伤的不同后果；完整器官、细胞和激素模拟又远超首版所需。首版不需要用大模型扮演器官，也不把模型自述当成生理结果。

身体输出三层信息：实际状态；本人能感到的症状；当前行动和认知能力。观察者可查看三层，角色只得到后两层中本人可感知的部分。实际感染、剩余寿命或生育概率不会直接进入个人上下文。

“饥饿、疲劳 0—100”可以作为面板摘要，不能成为唯一底层变量，也不能由角色编辑。身体约束使行动有代价；至于忍耐、求助、冒险还是分享，由个体自己决定。

## 2. 状态怎样存

实际身体仍由世界的统一结构化存储维护；个人档案引用身体标识，避免两份真相。每次变化关联模拟时刻、来源过程、资源账目与事件编号。

| 状态组 | 保存的实际状态 | 更新依据 |
| --- | --- | --- |
| 身份与发育 | 出生时刻、身体构型、个体差异、成熟度、年龄相关潜在能力 | 经过的模拟时间、已实现的成长 |
| 物质与能量 | 组织与储备质量、体水、可动用能量、可用于组织合成的粗粒度营养底物、消化队列 | 实际摄入、吸收、消耗与排出 |
| 劳累与睡眠 | 体力疲劳、睡眠压力、昼夜相位、睡/醒状态、睡眠质量历史 | 活动、清醒时长、光照、环境与睡眠 |
| 温度与生命功能 | 核心温度、循环/呼吸/供能功能、累积严重损伤 | 热交换、局部损伤、供给不足与疾病 |
| 伤势 | 受伤部位、结构损伤、出血、疼痛、污染、愈合进度、残留功能损失 | 接触与受力、照料、修复过程 |
| 疾病 | 暴露来源、感染实例、阶段、病程进度、症状、有限的病原相关免疫状态 | 接触、体内病程与恢复 |
| 生殖与妊娠 | 当前生殖能力、周期相位、妊娠进度、胎儿状态、产后恢复、泌乳状态 | 身体条件、实际互动、时间和资源 |
| 生存与意识 | 存活/死亡；清醒/睡眠/昏迷；死亡时刻与原因链 | 实际功能变化与一次性生命周期事件 |

年龄、饥饿摘要、当前负重能力等尽量派生，不手动保存一套会漂移的副本。意识状态与疾病、伤势分开：一个人可以同时腿伤、感染并睡着，不能被单一“健康/生病/死亡”枚举覆盖。

体重由互不重叠的质量分量求和。体水与干组织分开，血液中的水是体水的子集；消化道内容、妊娠组织分别计入当前身体总负载，但不重复计入干组织。衣物、背负物和被抱的孩子属于外部负载。能量储备是对应物质的属性，不能另加一份“能量质量”。

## 3. 统一时间和计算约定

统一使用模拟秒。能量用 kJ、质量用 kg、距离用 m、温度用 °C；身体体水按 kg 水记账，世界水库存沿用 m³，转移时使用版本内声明的水密度换算，不能把两个单位直接相加。生物速率的时间单位统一换算为秒。展示为小时、日、岁不改变积分单位。所有系数须带单位、适用阶段、来源/假设及版本。

以下是待校准的计算结构，不提供临床阈值。clamp 表示限制在指定范围；速率必须乘实际时间间隔，不能每调用一次模型就加减一次身体值。

身体、动作和环境按[世界联合结算契约](./AI世界状态与自然演化设计.md)推进。身体过程申报供给需求与配比，按实际获配量计算供能、修复、成长和其他后果；不能在外部库存被限缩后仍保留原先的完整身体收益。每次计算的 Δt 由最近事件、最大允许步长及最早阈值共同限制；中途水源耗尽、受伤失能或分娩发生，就切分区间并重算未提交效果。人的成长或孕程不会因为服务器等待而增加。

## 4. 饥饿与能量怎样计算

生存依赖角色实际取得并摄入的食物和水。自然资源按其环境过程变化，身体持续消耗，缺供能够导致衰弱、失能与死亡。存活、人口增长与文明发展作为观察结果，工程验收核对因果关系和收支。

实际吃下的食物从世界批次扣除，进入本人的消化队列。各批次保留能量、水、营养底物、污染、加工状态和已吸收比例。按消化速率逐步吸收，不是吃下瞬间全部变成体力；无法吸收的部分进入明确的排出/简化环境汇。

每段时间记录：

**能量结余 = 实际吸收能量 − 基础维持 − 活动额外消耗 − 调温额外消耗 − 修复/成长/妊娠/泌乳的实际投入。**

基础维持率由当前身体规模、发育阶段、个体代谢差异及状态计算。活动部分只计高于基础维持的增量，来自实际移动距离、负载、地形、加工受力与完成进度。不能在“开始动作”“持续过程”“动作完成”三处各扣一次相同成本。

资源分配采用明确的身体近似：先核算维持与已发生动作，再在实际剩余供给及可动用储备内分配修复、成长和生殖相关投入。后者按阶段配置的有界需求与权重分配，不能先让每个过程各自读取同一份剩余量。供给不足产生实际欠缺与损伤；这个生理分配假设不替角色安排社会任务。

结余可以进入有限储备；不足则以有限速率动用已有储备，必要时发生组织消耗和功能下降。快用能量池下降不直接宣布死亡；只有实际供能不足及其持续后果才进入生命功能结算。储备动用时同步减少对应物质，不允许无质量来源地持续供能。

饥饿感由胃内剩余、近期吸收、能量不足历史和个体感受共同形成，不是“距上次吃饭多少小时”的唯一函数。相同饥饿感的人可以拥有不同储备与危险程度。热量充足也不自动保证成长和伤口修复：组织合成还需要粗粒度营养底物和水。

这里采用收支结构，不照搬减重公式。NIDDK 的成人动态体重模型可以说明动态建模思路，但其官方适用范围排除了未成年人、孕妇和哺乳者，不能直接套到本世界全部人口。[NIDDK 研究说明](https://www.niddk.nih.gov/research-funding/at-niddk/labs-branches/laboratory-biological-modeling/integrative-physiology-section/research/body-weight-planner)

## 5. 饮水、排出和体温

**体水变化 = 饮水及食物实际吸收水 − 呼吸/皮肤/排泄损失 − 伤口失水 − 向妊娠或乳汁等独立分量的净转移。**

身体合适水量随当前身体组织与阶段变化；脱水程度用相对缺口及持续时间表达，派生口渴、活动能力和严重功能后果。失血既影响循环功能，也减少其中对应的体水和其他物质；不能再把同一份水从“出血”和“伤口失水”各扣一次。胎儿水转移是母胎内部账，整体负载求和时不算外流。

饮水行动只有真正取得、入口并吸收才补水。携带水、看见河或说“我喝了”都不补水。排出、蒸发和呼吸产物有明确去向；首版允许粗粒度环境汇，不声称已实现完整化学守恒。

体温使用简化热平衡：**有效热容 × 核心温度变化 = 代谢供热＋外界得热−散热。** 水分、湿衣、风、遮蔽、火与活动参与热交换；调温增加的能量和失水费用进入同一收支。热平衡中的代谢热来自已记录消耗，不能作为第二份消耗再扣一次。

首版不逐器官算温度；极端温度如何影响功能与损伤使用显式曲线。角色收到冷热、发抖或眩晕等感受，不获得全知的精确危重判定。

## 6. 体力疲劳与睡眠分开

体力疲劳 F 取 0—1，建议以如下有界速率近似：

**dF/dt = 工作积累率 × (1−F) − 可用恢复率 × F。**

工作积累随相对负载、活动强度和身体状态变化；恢复率受休息、供能、水分和伤病限制。休息可以缓解体力疲劳，但不产生能量、不自动治愈结构损伤。达到不能维持某动作的功能边界时，动作减速或中断。

睡眠压力 S 同样取 0—1，但单独推进：清醒时按 dS/dt=(1−S)/τ醒 积累；睡眠时按 dS/dt=−qS/τ睡 消退。τ 是阶段和个体相关时间常数，q 是受噪声、寒冷、疼痛等影响的睡眠质量系数。这是本模拟选用的近似形式，不是经验证的人体预测公式。

另存昼夜相位，由环境光照和内部节律推进；困倦由 S、相位、伤病等共同决定。夜晚不是强制睡觉命令；“尝试入睡”也不保证立即睡着。入睡、被惊醒、自然醒和极度困倦时的非自主失能由声明的身体机制产生，没有固定全员起床表。单次长睡不会把伤病和营养欠缺全部清零。

睡眠压力与昼夜节律分开的概念参考 NHLBI 的说明；睡眠不足可以影响注意、学习、记忆和反应，但具体扣减曲线属于本模拟假设。[睡眠调节](https://www.nhlbi.nih.gov/health/sleep-deprivation/body-clock)、[睡眠不足的影响](https://www.nhlbi.nih.gov/health/sleep-deprivation/health-effects)

## 7. 受伤、疼痛与修复

首版部位划分为头/躯干/左右上肢/左右下肢等少量区域。每个伤势实例记录结构受损、出血速率、疼痛、污染、修复与可能残留功能损失。受伤来源必须对应实际接触、跌落、材料受力、动物或人造成的伤害，不能随机凭空生成“剧情伤口”。

伤势对不同能力有不同作用：腿伤限制行走、手伤限制操作，循环或头部功能损伤可能影响意识。疼痛引起干扰，但不能把所有局部伤直接换算成相同比例的全身智力扣减。

**修复进度率 = 阶段基础修复率 × 实际分配的供给充足度 × 局部条件修正。** 修复消耗真实的时间、能量、水和底物；供给修正由同一资源分配器产出。出血和污染按支持的照料作用改变，不按模型说出的“疗效”改变。修复率、组织重建与残留损伤相容，不能进度满了就重新生成不存在的组织。

照料需要实际接触、时间、材料与技能。首版只支持明确建模的物理照料效果；说出草药名称或诊断不产生治疗，也不因谈论该作用暂停。实际待执行的照料依赖引擎无法结算的新作用时，沿用行动协议的技术边界暂停机制，不能临时发明疗效。支持范围内的无效操作则按真实尝试结算。

## 8. 疾病从暴露到病程

首版用少量声明为虚构近似的疾病原型，表达接触传播、食物/水暴露和伤口相关感染；不承诺复现某种真实传染病。疾病原型定义传播途径、潜伏/可传播/症状/恢复阶段、持续时间分布、对身体过程的影响及免疫衰减。中毒和冷热损伤另算，不都放进传染病。

每人依据实际暴露累计危险量 H：**ΔH=∫λ(t)dt，区间感染概率=1−exp(−ΔH)**。λ 来自具体接触、摄入或局部污染及易感性，不因全地图有病人而增加。每个易感周期预先抽取并保存一个危险量阈值，累积越界时发生感染；不在每次切小步长时重新抽一次“百分之几”。感染后按原型冻结的阶段规则重新进入易感周期，不重复判成多份同一感染。

感染实例只推进自己的病程与实际损伤。可传播阶段与症状阶段分开，允许尚未察觉但已经影响传播；角色只感到出现的症状，不能知道隐匿感染状态或全局传播链。阶段时长、病情差异使用独立且可恢复的随机流。

照料、避寒或补给可以通过已经建模的过程改善恢复条件；接近照料也可能增加对应途径的暴露。恢复不一律等于终身免疫；免疫只对已定义的病原原型生效，不能成为通用“抗病值”。同一疾病的损伤与死亡风险不能在多个子系统重复扣算。

## 9. 成长怎样发生

日历年龄由当前模拟时刻减出生时刻计算；成长实现量由实际资源与身体过程计算。先定义阶段相关的潜在体型和能力曲线，再计算：

**实际组织生长率 = 潜在生长需求率 × 供给充足度 × 当前身体条件修正。**

潜在需求参考年龄、当前组织和个体差异；实际生长同时消耗能量、水和组织底物。供给不足时可以长得慢，不能生日一到凭空补足身高体重。身高与组织量通过同一发育模型关联，禁止一套改身高、另一套独立免费加体重。营养恢复后的追赶幅度也有界，不追溯改写过去。

能力成熟和学习经验分开：成长可以开放更复杂的动作、表达和规划范围；实际技能仍需要可追溯的观察、练习与反馈，不能每长一岁自动获得采集经验。身体成熟不直接决定性格和社会地位。

婴儿依赖真实喂养、保暖和照料，反射性哭声、吸吮及睡醒按阶段能力产生可感知事件，无需为每次哭泣调用模型。是否回应由其他人自行决定。逐渐开放简单意图和模型决策；不让新生儿使用成人动作列表。仍承认基础大模型已有知识，不能声称这就是从零发育的人类认知。

## 10. 衰老与死亡

衰老通过平滑且有个体差异的曲线改变基础功能上限、恢复速率、脆弱性与残余自然死亡风险，不设“到某个生日必死”。经验和知识不因年龄统一清空，年长也不自动等于判断能力差。需要模拟认知病变时必须有单独机制，首版不把它藏在年龄惩罚里。

生命功能至少区分供能、循环/呼吸和严重结构损伤。各系统分别累计缺供损伤，例如 **dL系统/dt = k损伤 × 当前缺供程度 − 有供给支持的修复率**，其中缺供程度由实际需求与已满足量的相对缺口计算，损伤有界。每个系统定义当前功能与损伤、局部结构的映射；可逆程度、不可逆边界和持续时间条件在参数表声明。严重伤病可以直接破坏功能。死亡不是饥饿摘要达到 100，也不是储备池刚好见底。

死亡来源有两类：已建模的明确功能失败；未建模个体自然失效的残余风险。残余风险 h 随年龄和个体脆弱性变化，**区间概率=1−exp(−∫hdt)**，也用持久化累积阈值，避免小步长增加死亡抽签次数。已建模伤病的风险不能又完整加入残余 h；原因链记录近因及上游原因，不能把同一次死亡算两次。

失能与死亡分开。昏迷者不发主要思考请求，部分自主动作被取消；身体仍代谢，支持范围内的照料可能改变后续状态。死亡在一次原子事实提交中完成：取消待安装决定和不能继续的动作，停止主动认知与活体代谢，建立一次尸体/遗体状态，保留物品实际位置和容器关系。不可死亡后再吸收食物或多次生成尸体。

死者未消化内容、体水和组织按声明账目转入遗体及后续分解，不突然消失；妊娠中的独立分量也必须纳入母体死亡结算，不能继续作为无依附的活体过程运行。首版不支持死后继续妊娠或特殊抢救；相应过程终止并记录，不作为独立出生。私人记忆归档但不自动给后人；财物不自动按亲属关系转移。其他人通过实际看见、听见或交流得知，不能全员获得死亡通知。

## 11. 繁衍、妊娠、出生与照料

生育欲望、对某人的关系判断、双方当次同意、身体生育条件和实际受孕是不同状态。首版只支持具备相应生殖能力的成年个体自主、双方确认的抽象互动；成年边界使用本实验明确的年龄门槛，建议 18 岁。身体成熟曲线不绕过该门槛；不模拟未成年人相关性行为。长期伴侣关系、婚姻和社会分工都不是生理前提。

模型只提交交往/邀请/接受等意图；双方意思与当前能力实际满足后才形成有正持续时间的互动。不能一个人的“愿望”替对方完成同意。生育能力不直接从姓名、性别标签或人口是否够多推断。

受孕模型以实际完成的合格互动、周期相位、身体条件与阶段相关可育性计算机会。首版建议：每周期累计有效互动量 X，**周期机会危险量增量 = 周期可育系数 × 相位修正 × 身体修正 × 有界饱和函数对 X 的增量**，与保存的一次随机阈值比较；所有修正非负，同一周期上限有限。不合格或未完成互动不增加 X，不能每条 API 回复重抽一次，也不能无限重复零时间动作刷到成功。具体概率曲线和周期长度由生理参数包提供，不从部落人口缺口反推。已有妊娠不再受孕，产后生殖状态按身体过程恢复，不能因一条新意图立即复位。

妊娠有两个进度：日历孕程与胎儿实际成长。日历孕程按模拟时间走；胎儿能量、水和组织增长需要母体实际分配。**胎儿增长量由所获能量、水和底物中最紧的约束决定**；妊娠维持的额外代谢与进入胎儿的物质/储能分开记账。不能把同一份能量同时留在母体储备、记为散热消耗又装进胎儿。

食物不足不直接触发“禁止怀孕”开关；实际身体条件可以改变受孕机会、孕程风险和资源分配。孕程推进并不保证标准体重新生儿；损失、非活产及分娩并发状态通过声明的过程结算，不由模型临时写剧情。相关结果只做抽象记录。妊娠终止须关闭胎儿成长和相应维持过程，把已有组织按支持的残留/排出阶段处理，并进入相应恢复状态，不能静默删掉质量或无限期继续耗费孕程资源。

达到分娩条件后，分娩是持续的身体过程，可能受身体状况和实际照料影响。活产提交时才创建独立活动人口标识：母体妊娠分量转为新生儿身体、相应剩余物及环境账；不能复制母体质量。非活产不产生一个还能继续思考的角色。胎儿记录在活产前不占一个独立行动者，观察者单独统计孕程和活动人口。

新生儿创建自己的身体和个人档案，初始经验来自出生后实际可感知事件，不复制父母长期记忆。身体差异可以使用有界的亲代相关采样＋随机差异，必须标成遗传近似；首版不模拟完整基因、不按父母“智商”取平均，也不宣称已复现多代遗传与近亲风险。个性发展另由前述个体机制表达。

泌乳取决于产后阶段、身体状态与实际供给：母体投入能量、水和底物，产出有限乳汁。乳汁只有实际进入婴儿并吸收才补给婴儿；直接喂养按流量记账，存储则生成有限批次，不能两处同时使用。未喂出的乳汁仍有去向与有限容量，不当作无限奶源。泌乳与身体恢复不会强制派发照料任务；抱持、喂养、提供食物和保暖均需实际有人行动。首版不支持的替代喂养技术不自动获得安全有效的效果。

## 12. 怎样影响行动和思考

每次更新产出一个当前能力集合：移动速度、耐力、负载、手部操作、发声、感觉、注意、记忆唤起、规划范围、学习效率与处理速度。每种能力分开计算：

**当前能力 j = 当前发育/训练下的基础能力 j × 联合身体可用系数 j。**

可用系数由相关局部伤势、供能、水分、睡眠压力、温度、疼痛和疾病造成的功能变化计算。不是把所有状态各乘一次独立惩罚：例如感染引起的脱水已经通过体水影响功能，就不再因“感染”“腹泻”“脱水”对同一损害重复乘三次。疾病可以另有不重叠的直接功能作用；参数包须画清原因到功能的映射。

动作按当前能力检查并在过程中持续更新：做得慢、负重变小、动作失稳、必须停下等都有实际依据。仍会做石器的人手受伤，可以知道怎么做却暂时做不了；技能不被删掉。严重失能限制可选动作，不强制生成新的社会选择。

认知部分使用与前文相同的抽象参数：限制本次可处理的观察和可唤起的记忆、规划深度与学习效果，给出本人能感到的疲倦或疼痛，不直接给出隐藏诊断。有效处理速度是相对于基准的无量纲比例；低于思考能力边界时不启动主要决策，其余情形可用 **D=clamp(D基准/有效处理速度, D最短, D最长)**，从开始时快照确定并保存，始终为正，与 API 延迟、token 数无关。普通身体变化影响下一次思考；失能、死亡或重大可感知打断可取消尚未安装的决定，沿用调度协议。

不能只把上下文截短、提示“你很笨”就声称得到真实智力差异。是否产生预期的错误率、反应与学习差异需要后续评估；身体暂时影响不覆盖基础性格、技能或长期记忆。感受到不适可以触发既有注意条件或必要唤醒，但不在每个身体小更新时调用模型。

## 13. 一个联动示例

某人清晨清醒，昨天的睡眠不足仍体现在睡眠压力里。他感到困和饿，准备外出采集；程序不替他选择先吃还是先走。

他开始移动后，身体按实际路程和负载消耗能量、积累体力疲劳。太阳和环境影响热交换；等 API 的现实时间不计入路程和代谢。疲劳导致速度下降，预计到达时刻重新计算，不能依旧按满体力速度获得成果。

途中摔伤手，结算局部损伤与疼痛，原计划中需要双手的加工步骤可能失效。生成本人能感到的新观察，合并一次必要决策。他可以求助、改用另一只手或继续冒险；任何选择都要付实际代价。

后来他吃下取得的食物，资源批次转入消化队列，逐渐补充能量和营养。休息缓解体力疲劳，伤口只有拿到资源并经过修复时间才改善；睡着后睡眠压力下降，不会因为“结束一天”清除伤势。若食物带有污染，暴露和可能病程另按疾病过程推进，不能模型一说好吃就变成无害。

## 14. 参数包与启动前检查

首版必须有一套冻结的、注明“未校准”的身体参数包，至少包含：年龄/体型曲线；维持和活动增量率；消化与储备转换；水与热交换；疲劳和睡眠时间常数；伤势及修复；疾病阶段与暴露；功能/失能/死亡条件；生殖周期、妊娠、分娩、泌乳和婴幼儿依赖。具体数值由后续实现方案提出，不要求用户逐人填写，也不能运行时让模型临时估计。

成年边界、每种阶段曲线的适用范围、资源分配顺序、最小/最大步长及阈值求解误差都属于可检查配置。体型、年龄、活动、孕程和哺乳状态必须有不同适用项；不能把 50 人全当同一成年体型乘以固定日耗。

初始食品“约两日量”按这 50 个初始身体及声明的参考活动估算，并标注活动假设；它不是保证每个人两日不饿。初始组织、储备、胃内容、睡眠压力等已经结算到观测零点，不能初始化后补扣此前几十年消耗。初始幼儿须有适用食物/喂养来源与可接触照料背景；只有成年人能吃的食物不等于全体人口都有可用补给。若婴儿依赖乳汁，初始化须同时生成与已有出生背景相容的实际泌乳者、泌乳阶段及供给条件；“无初始妊娠”不等于“无产后泌乳”，也不能仅指派一名照料者就假定有奶。

以下是后续实现时应验证的场景，当前未运行：

| 场景 | 要检查的结果 |
| --- | --- |
| 食物入口、消化和行动消耗 | 来源可追踪；没有瞬间全额吸收、负储备或重复扣费 |
| 休息与睡眠分开 | 体力可缓解但缺觉仍在；睡觉不凭空补水补组织 |
| 受伤、失能、照料和病程 | 局部能力受损；技能保留；隐藏感染不进入全知上下文 |
| 更换积分步长与增加 API 调用 | 暴露/死亡危险量和宏观收支在误差范围内一致，不增加抽签次数 |
| 缺少组织底物的儿童 | 年龄增长而身体未免费长到标准体型；恢复也不追溯改写 |
| 受孕、孕程、活产和泌乳 | 有真实自主互动和物质来源；无无限重抽、质量复制或免费乳汁 |
| 死亡与保存恢复 | 一个死亡提交、一个遗体；待安装决定失效、库存不消失、不重复出生 |
| 现实网络等待与模拟暂停 | 所有身体和生命周期冻结，不能因 API 慢让某人多饿一小时 |

没有做过年龄、营养、睡眠和生育参数校准前，只能说机制已定义，不能说已经模拟真实人体。首版目标是使人的选择承担连续、可追溯的身体后果，并让代际延续真实依赖资源和照料。
