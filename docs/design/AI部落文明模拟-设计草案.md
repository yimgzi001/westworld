# 西部世界设计总览

> 当前设计基线：在仓库 `game/` 的 Survivalcraft / SCAPI 1.9.5.1 上扩展。本文记录目标与取舍；实现及验证范围见[当前状态](../development/当前状态.md)。

## 1. 项目方向与用户已确定的要求

让多个具有独立经历、欲望、性格和记忆的 AI 个体，在现有游戏世界中长期生活、学习和相互影响。初始目标仍为 50 名原始部落成员，包含男性和女性；从一人和少人数逐步接入。人类设置初态与通用机制后只观察，不安排职业、日程、村庄、领导者、战争或文明发展顺序。

项目从已有地形、生物、人物和物品出发。用户以地球长期演化说明“少量根本机制产生复杂结果”的方向；本项目不因此增加从无生命物质演化出生命、重新模拟宇宙或重建整个物理引擎的任务。自然演化指游戏能力范围内的人物行为、经验、分工、技术使用与社会组织的持续变化，不保证繁荣或指定结局。

用户不必逐个人编写人生，也不必逐项设计全部细则。开发者负责提出少量可检查的默认机制、生成有差异的初态、验证实际后果，再用观察发现缺项。50 人的人口比例、年龄与具体物资仍属可调整预设，见[初始化](./AI初始条件与初始化流程设计.md)。

当前运行位置已确定为 Windows 本机，游戏、人物调度与 AI 状态保存在本机，模型通过 API 调用。Linux 服务器部署与无界面运行留待后续需要时评估，不阻断本机版本。已有服务器历史配置和实际运行边界统一在[开发与验证](../development/开发与验证.md#运行位置与已有服务器记录)维护。

## 2. 复用游戏，按缺项扩展

| 范围 | 当前开发方向 |
| --- | --- |
| 地形、空间、物理、昼夜与天气 | 先复用游戏坐标、区块、碰撞及已有过程；不先改造成球面星球 |
| 身体与生存 | 先复用生命、食物、体力、睡眠、体温等现有组件，核对 AI 人物是否真正具备这些能力 |
| 物品、工具、制作与建造 | 先使用游戏物品、配方、挖掘与放置规则，建立真实执行和反馈；开放材料制造是后续扩展 |
| 个体自主性 | 新增个人感知、驱动力表达、记忆、分层目标与执行、交流和模型调度 |
| 长期运行 | 接入一致存档、调用账、费用与容量控制，验证玩家远离时 AI 仍能活动 |
| 代际与更丰富世界 | 成长、生育、衰老、详细疾病、开放制造和球面地表保留为后续目标，缺项显式标记 |

各版本先登记“复用且已验证、需要适配、新增未实现、未启用”的能力清单。未启用的扩展不成为早期或首个游戏版 50 人观察的前置要求；缺少繁衍的版本不能声称已验证跨代演化。旧专题中的宏观物理、生理方程是相应扩展的候选模型，不替换游戏已有结算，不让同一份饥饿、伤害或库存被两套机制重复计算。具体差距见[当前状态](../development/当前状态.md)。

优先使用现有组件与扩展接口，必要时修改源码。首轮可由 C# / .NET 10 在游戏内接入模型适配器；Python 服务、数据库与观察端框架尚未定案，不因会话中的示例引入额外服务。游戏状态是事实来源，模型与观察端不能直接另写一套背包或地形。

## 3. 根本驱动力怎样形成行为

采用“身体与环境压力 → 本人感受与判断 → 欲望/目标 → 行动 → 实际后果 → 记忆与方法调整”的闭环，具体个人状态在[个体状态](./AI个体状态设计.md)维护。

- 求生与避险：食物、疲劳、冷热、伤害和死亡后果由已启用的游戏机制产生；口渴等新增需要尚未实现时不能假装存在。
- 个体偏好：少量稳定差异表达好奇、亲近或独处、自主、积累、认可、劳动与休闲等倾向。它们影响选择，不直接指定职业或人生目标。
- 有限资源和信息：人物只能依据局部感知、个人经历和实际收到的消息行动，可能竞争、误判、隐瞒或欺骗。
- 经历的延续：行动的成败、投入与所得进入自己的可访问记忆；可以复用方法、调整习惯、学习或遗忘。
- 相互依赖：交流、交换、照料、协作与冲突通过实际行动发生，对方有自己的目标，可以拒绝。

每个人有强烈求生愿望和死亡恐惧，但不机械选择一个最高分动作。不给所有人共同的“发展文明”奖励，不用善恶分、职业树或固定剧情制造社会。也不把饥饿自动解释成抢夺、获赠自动解释成感恩。分工和规范是否形成，要看实际选择与后果。

同一基础模型按需服务多个角色，个人上下文与记忆隔离；接受预训练知识，不接互联网、不专门构建知识遗忘门槛。身体、偏好、信息和经历共同形成差异，不能仅靠提示词宣称产生真实人格或人类意识。

## 4. 每个人的分层自主执行

首轮实现建议把下表的职责分为认知与规划、任务执行器和游戏动作适配器。认知层根据个人观察交出有限计划，执行器跟踪步骤和进展，适配器执行原子动作并报告实际结果。世界调度器统一安排各人的思考、动作与结算。

认知与规划维护持续的个人认识、关切和目标，在新证据或无进展时重新取舍，并提出带预期和界限的方法。具体运行契约见[认知循环与目标调整](AI认知循环与目标调整设计.md)，包括认知变化与动作请求分别校验提交。既有个人计划、等待和近期过程仅覆盖部分连续性；新协议首版的实际能力及验证见[当前状态](../development/当前状态.md)。

| 层 | 职责 | 模型与程序边界 |
| --- | --- | --- |
| 长期目标 | 当前重视什么、是否改变方向 | 本人结合感受与记忆形成；不预置“建立村庄”任务 |
| 任务规划 | 分解目标、安排依赖与有限分支 | 模型提出方案；规划器仅展开本人可用的方法与约束 |
| 技能执行 | 复用采集、制作、建造等操作步骤 | 共享执行代码，个人方法、进度与熟练程度独立 |
| 具体行为 | 寻路、接近、操作目标、检查完成与失败 | 在已授权的目标、资源、搜索范围及停止条件内处理 |
| 底层控制 | 移动、转向、碰撞、挖掘与放置 | 游戏组件实际执行并结算，不能用模型叙述替代 |

问题在能够解决的最低层处理：局部绕障可以重算路径，材料耗尽则按已有分支处理或向上报告。扩大目的、改变生活策略、选择是否争夺等需要本人新的判断；低层不能为了少调模型临时替他作决定。计划可中断、取消、恢复，且每步重查真实前提。具体层间契约见[行动与模型交互](./AI个体行动与模型交互设计.md)。

共享模型、执行器和游戏引擎，不共享他人的内心或未经传播的方法。人物不需要各自常驻线程或模型实例。一次思考可以支持许多底层动作；按需唤醒、有限并发和最长思考间隔见[调度设计](./AI时间推进与调度设计.md)。

## 5. 玩家飞行与网页观察

用户以本机玩家身份进入世界并飞行查看，独立观察摄像头退出开发范围。建议复用原版飞行控制，给实验中的本机玩家单独开放飞行，实验世界继续使用生存规则。玩家占原生玩家槽位，独立于 50 名 AI 创始成员及其认知调度。

正式实验仍以观察为主。玩家是世界实体，能被正常感知，实际交互按游戏规则结算；人工介入与 AI 自主行为分开记录。玩家飞离营地后，AI 行动所需的区块仍应保持可用。退出游戏进程、本机休眠或关机时模拟停止，之后从存档恢复。

网页面板独立于玩家操作，只读已提交事实。人物自述、主观判断、候选与观察解释分别展示。打开或关闭网页不改变模拟状态。查询和回放不调用角色模型；可选日报独立计费，不反馈给人物。详见[监控与观察](./AI监控面板信息与交互设计.md)。

## 6. 本轮运行额度与暂停

本轮按以下额度设计，正式实验尚未启动。既有模型接入测试用量见[当前状态](../development/当前状态.md)。

| 项目 | 当前口径 |
| --- | --- |
| 模型费用 | 本轮累计 USD 200；包含角色决定、回想、摘要、重试和可选观察分析，不按天自动重置 |
| 运行数据 | 本轮本机管理的世界、AI 状态与记忆、调用记录、日志、快照、备份及临时写入合计 15 GB，按十进制 15,000,000,000 字节计；源码、安装包及构建产物不计入 |
| 人物调用机会 | 不设个人累计或每日调用次数配额，不用费用排名限制某个人思考 |
| 时间与人口 | 额度不是寿命、人口上限或文明阶段；观察窗口用于测量，后续可在同一配置下续跑 |

这两个数字是初始运行边界，不是足够运行多少天、多少代的预测。先测一人、少人数和 50 人短段的实际请求、费用与数据增长，再给出可覆盖时长的估算。多实验共用本轮额度时合并记账，重启、恢复或新分支不能清零已发生消费。

调用前把已知消费、在途预留、未知费用负债和下一次待派发请求计入检查；容量检查包含即将发生的写入、日志和恢复所需余量。预计不能安全容纳下一项时就停止派发/推进，保存一致状态并暂停，不等实际账单越界或磁盘写满。预留及预警参数由实现者根据测量给默认值，不另要求用户逐项填写。

不在额度用尽后改用规则人格、跳过人物、临时降低认知频率或删除世界来继续。追加额度后可以从原时点和原队列续跑，沿用已有结果。供应商无法提供可证明的计费上限时，本地按保守估算和未知负债控制，最终外部账单仍以其计费为准。费用计算不在本文固定单价。

## 7. 时间、事实与存档

世界使用统一模拟时间，游戏帧与 AI 事件时钟需建立明确映射。模型请求异步执行，主线程不等待 HTTP；角色等待回包时可以继续既有动作，世界照常推进。候选落盘后在游戏更新边界校验，动作按当时的世界状态结算。详见[调度设计](./AI时间推进与调度设计.md)。

模型只产生意图。位置、背包、方块、身体与实际交流由游戏及已启用扩展结算；个人记忆和信念可能错误。新动作、计划续步和相关竞争经过统一执行入口，保存动作身份、真实进度和效果标记。原生存档与 AI 状态必须能恢复到同一边界，不能只分别保存后宣称一致。

默认当前状态模式保存可续跑状态、必要调用与费用账、个人记忆及有限观察资料；逐事件历史回放是显式选择的模式，纳入同一容量。压缩、日志轮转与备份轮换不得破坏恢复、去重或尚在保留期的证据。详见[存档设计](./AI存档恢复与历史回放设计.md)。凭证不写入版本库与导出包。

## 8. 长期演化与能力边界

人物可以形成方法、分工、群体、规范和制度，也可以游玩、偷懒、拒绝合作、欺骗、迁徙或失败。角色自称“猎人”“领导者”与观察到的持续行为分开，不存在称号直接授予权限的机制。详见[社会关系](./AI交流与社会关系设计.md)和[学习传承](./AI学习发明与知识传承设计.md)。

原生配方是当前游戏的生产规律，不宣称已经支持任意材料发明。成长、繁衍和代际传承仍是长期目标，需要真实可执行的生命机制后才能验收；新生个体有自己的状态，不复制父母记忆。球面地表、细致生理与开放制造作为后续能力方案保留，不阻止先在游戏中观察自主生活。

实验启动前固定初态、游戏与模组版本、模型和认知配置。运行中角色仍可改变目标与方法；改变引擎规律、模型或认知机制的开发更新建立有来源的新实验分支。已知未支持的目标可以保留为打算，不能靠叙述制造成功；实际执行依赖无法结算的关键作用时，保留最后一致状态并按能力边界暂停。

## 9. 实施与验收

先复用游戏完成一人的“感知 → 决定 → 分层执行 → 实际反馈 → 记忆 → 保存恢复”，再做少人数独立互动和 50 人压力/短段观察。正确性、信息隔离、玩家飞行与远处 AI 活动、额度暂停和恢复是首轮门槛；不要求先实现所有后续生理和世界模型。详细出口见[实施路线](./AI分阶段实施路线设计.md)及[验收设计](./AI测试验收与演化证据设计.md)。

评价自然演化要有实际资源、行动、记忆传播和持续变化的证据；聊天文本、建筑数增加或角色自称文明进步不足以单独证明。短期生存与合作证据不能代替跨代结论。这里模拟人工社会，不承诺重现地球生命史。
