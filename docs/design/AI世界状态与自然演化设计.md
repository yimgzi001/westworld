# AI 世界状态与自然演化设计 v0.2

> 迁移保留的目标设计。适用性需按 Survivalcraft 游戏机制重新核对，其中的设计要求不表示当前游戏或 AI 接入已经实现。

## 1. 世界层负责什么

世界层保存唯一的空间、物质与生命事实，推进时间，并接受《AI 个体行动与模型交互设计》中的行动。人的记忆、欲望和解释仍按《AI 个体状态设计》维护。

初始条件决定开局的地形、生物、物品与气候背景；冻结的过程模型决定后续变化。自然更新通常不调用大模型，也不根据故事需要安排丰收、暴雨或动物袭击。天气、动植物和物品更新使用普通数值计算、简单控制器及记录下来的随机过程。

正式世界的地表面积有限，表面没有地图边缘。河边营地是 50 名创始成员的出发地。地表几何和日常生存过程采用宏观近似，公式、参数、单位与适用范围随规则版本冻结。

## 2. 存储的共同骨架

世界状态具有统一的权威来源，提交后才发布新世界版本。下述集合表达状态职责，实际组织方式依据游戏引擎与接入设计确定。

| 集合 | 核心内容 | 举例 |
| --- | --- | --- |
| world_configs | 范围、坐标、单位、天体与气候参数、边界条件、规则版本、随机状态 | 日长、年长、纬度近似参数、区域尺寸 |
| terrain_cells | 地形和空间环境状态 | 高度、坡度、土层、地表水、土壤水、地表温度 |
| weather_regions | 天气背景与正在发生的天气过程 | 云量、空气温度、风、降雨强度、过程阶段 |
| species_defs、material_defs | 只在开局选定的物种和材料模板 | 植物生长条件、动物基本行为、木材或石材属性 |
| entities 与组件 | 世界内具体的人、植物、动物、物品、容器、结构 | 一棵树、一只动物、一个石制工具、一处住处 |
| stocks、batches | 资源或物品批次的唯一数量与状态 | 树上附着果实、采下食物、种子、燃料与腐殖物 |
| processes | 跨时间持续的变化 | 动作执行、火、加工、腐败、发芽、气象过程 |
| world_events、resource_deltas | 已提交事件及资源来源、去向和差量 | 采集、摄入、降雨、蒸发、砍伐、死亡 |
| checkpoints | 完整恢复所需时钟、状态、队列、版本与随机状态 | 暂停或故障后的恢复点 |

共同元数据包括实验标识、稳定对象标识、版本、有效模拟时刻、最后更新时刻、规则引用和生命周期状态。对象标识不重复使用；个人对对象的识别仍由感知决定，不能因内部编号相同就自动认出从未辨认的对象。

时间用模拟秒；位置和距离用米；质量用千克；水量用立方米；能量用千焦；温度用摄氏度。计数资源明确单个质量或批次组成，不能把“份”“公斤”“个”混为一谈。数值误差容限和舍入余量处理在规则中声明并审计。

## 3. 空间与地形

### 球面地表与区域精度

- 全局地表采用立方球网格。将立方体六面的网格投影到球面，按共享边确定相邻地块。跨接缝时换算坐标与方向，继续沿同一片地表计算距离。环行路线回到同一个地块标识。星球半径、网格精度和坐标规则在开局冻结。 [立方球方法原文](https://doi.org/10.1006/jcph.1996.0047)
- 地理默认用固定种子生成一颗类地星球。开局确定全球粗粒度的海陆、高度和气候背景，并在一个有淡水的流域放置营地。营地及相邻可达区域先使用较细的地形、水和资源。后续区域按同一生成版本与全球坐标细化，已发生的状态变化随存档保留。生成结果和资源状态须独立于角色抵达、观察者打开页面或进程重启的顺序。
- 跨区移动沿相邻地块或区域内实际路径消耗时间与体力。山坡、水域、负重和身体状况影响可达性。每个时刻只有一个权威位置，跨区沿用同一模拟时钟和结算规则，角色只收到当地可感知的信息。
- 离线验收先核对全局连通、接缝邻接关系可逆以及连续环线返回起点，再用独立场景让角色从营地穿过可通行的区域接缝。比较连续运行和跨区时中断恢复的最终位置、时钟和资源账，复访同一地块时核对已有变动。环线是地表连通性测试，人的环行能力仍取决于地形和交通机制。

### 地块与实体位置

建议用地块保存环境场，用米制坐标保存实体的位置。每个地块包含标识、范围、高度、坡度、基底材料、土层、土壤水容量与当前水量、地表水量、地表温度，以及对其上实体的引用。可通行程度和遮挡由这些数据及具体障碍计算。

地块是环境计算单位，不是人能一步跨越的距离，也不表示同格的人能互相接触或看到格内全部物品。树、石块、营地、河岸和人拥有更具体的位置或简化范围；操作距离和搬运距离按实际坐标检查。

地形类别用于描述和索引，不独立给予永久效果。例如“森林”应与实际植被相符；砍掉植被后，遮挡与资源随实体变化，不因标签仍叫森林而凭空保留。

首版高度与基底通常不自行重塑；挖掘可按明确土方转移模型改变局部地面。大规模侵蚀、地质变化和连续流体求解不在默认范围内，遇到依赖未支持过程的作用不能由旁白补结果。

地块标为石质或有矿物，不代表存在无限可取得材料。可开采部分必须有有限的可追踪体积/质量，或具体物体库存；采出材料要从相应来源扣除。未实现的地质形成与矿物生成不会自动补库存。

星球尺度、区域尺寸和地块大小分别确定。创始流域的范围依据可达距离、资源和运行成本验收。

局部测试预设仍声明有限活动范围。球面世界的区域接缝属于正常移动路径。实际动作若需要当前版本无法表达的作用，按最后一致状态保存并记录能力边界。外部水和气候输入单独记账，补充规则从有来源的新实验分支验证。 [行动边界契约](./AI个体行动与模型交互设计.md)

## 4. 水、天气与周围天体

天体层首版保存决定日照、昼夜和季节的边界参数，不为每颗天体建立完整物理过程。季节输入由模拟时刻与冻结参数计算；未支持的潮汐、轨道和辐射影响不假装已经参与。

天气采用有持续性的区域过程：气候与季节提供背景，前一状态和带种子的扰动影响后续温度、云量、风与降雨。降雨过程有起止、强度变化和空间覆盖，不是每轮毫无关联地随机挑一句天气描述。本方案不是完整气象预报模型。

地表水和土壤水由地块持有唯一数量。河流、湖泊或积水范围是这些库存及连通水路的几何/逻辑表示，不另放一份可重复取用的水量。流动沿相邻地块或已声明水路转移；降雨、渗入、蒸发、饮用和灌溉形成显式差量。

地表与土壤状态共同影响移动、可取水位置、植物和物品湿润程度。水分变化不等于完整水力学：流速、淹没、涉水能力和物体被水搬运等后果，仅在相应模型已定义时计算。

天气影响地表、物品和身体，住处则通过已有材料与结构影响局部暴露。地块环境温度、物体温度与人体体温分别保存或推导，不能互相直接覆盖。角色收到的是光线、冷热、风雨、水位等可感知现象，不自动获得精确预报或隐藏污染指标。

## 5. 植物怎么存、怎么生长

物种模板保存适宜条件、成长阶段、维护需求、结果与繁殖方式、可采部分和材料属性。单个植株或明确范围的植物斑块保存物种引用、位置、出生时刻、生长阶段、结构生物量、可用储备、健康、损伤，以及附着果实或种子的库存引用。

植物更新读取这一段时间的光照、水、温度、空间和已声明养分近似条件，计算维护消耗、生长、成熟、结果、衰弱或死亡。结果依赖阶段、环境和储备，不固定到每天自动补满。生长和结果消耗或转移相应物质与储备，不能同一份生物量反复兑现。

树上果实具有唯一附着库存。采集把实际取得部分转到人的持有物或容器，未取得的部分仍在植株；植株的总质量由结构与附着部分派生，不同时把同一果实计入两份独立总量。

繁殖先产生有来源、数量和活性的种子或其他已支持的繁殖材料；传播和发芽受位置、时间与环境约束。成功发芽消耗相应繁殖材料并建立新植株。首版不试图求解完整遗传和授粉生态，但采用何种近似必须明确。

砍伐、采果、取枝或连根拔除分别造成不同的实际差量。不能采完果实便等价于杀死整株，也不能树已变成木材仍继续长果。死亡后可用部分、残体和腐殖物按支持的过程转换。

## 6. 动物怎么存、怎么行动

每只参与互动的动物有独立身份、物种、位置、身体与年龄、能量、水分、疲劳、伤势、生长/繁殖状态，以及有限的感知和当前行为。群居物种可以有群体关联，不假定所有物种都有人的社会认知。

首版使用低成本的物种行为控制器：根据自身需要和局部感知，在觅食、饮水、移动、休息、逃避、接近及繁殖等已支持行为中选择；通常不调用大模型。控制器也不能自动读取全部世界里的最近猎物或人物计划。

动物吃的是世界里真实存在的资源，喝水扣减同一水量，移动和活动消耗身体储备。追逐、攻击和人的狩猎进入共同动作结算，不能单独给人一次“狩猎成功”奖励后凭空生成肉。

动物死亡后，实际身体可转为尸体及可加工部分；后续取肉消耗尸体资源。同一身体不能既作为活体继续行动，又被重复转成食物。出生需要已声明的身体条件和此前投入，不能不扣成本复制成年个体。

初版保持个体动物及一致的控制粒度。未被人看见时也继续更新，不因观察者打开面板而改变动物规则。是否将小型或大量生物建模为斑块/种群，应在开局声明，不在运行中随镜头距离偷偷切换。

## 7. 食物、种子与其他资源批次

食物可以是植物附着部分、可采资源或实际物品批次的一个组件。建议保存：批次标识、来源、材料/物种、数量与单位、质量组成、含水、可食部分、营养与能量数据、加工状态、温度、腐败/污染状态、实际位置及最后更新时刻。

隐藏危险属性属于世界事实，不因进入模型上下文就全部暴露。外观、气味、味道和后续症状按感知与身体模型表现，角色可能据已有知识猜测，但不会获得数据库诊断。

采集、拆分、交接、加工和摄入都操作同一库存。拆分后的各批次继承实际状态，合并也不能重置时间或抹去污染。条件不同的批次可放在同一容器，但保留子批次，避免用新鲜食物把旧食物“平均洗白”。

腐败由经历过的温度、含水、暴露、储存条件和时间推进，不只看当前天气或“第几天”。处理可以改变水分、结构、可消化程度和部分危险因素，效果来自已支持的过程；不能一律把“加热”解释为所有食物恢复完好。

摄入从实际食物扣减，身体按营养与损耗近似计算获得。腐败、损失和残留去向记账；物品离开视野、无人看管或过期，不等于直接从世界中删除。

## 8. 物品、容器、结构与记录

通用实体保存类型、组成、形状/尺寸近似、质量、温度、含水、损伤和耐久等组件。材料模板保存相应性质；工具效果由材料、形状、连接、状态与动作共同计算，不单靠名称赋予任意功能。

物品实际位置使用互斥形式：地面坐标、某容器内部、某个体持有、附着在某实体，或处于明确的多人共同搬运关系。容器嵌套不得成环，子物体坐标可由父对象推导，不能同时在背包和地面出现。

容器容量、总负重和结构质量考虑真实组成。复合工具或住处由部件与连接关系构成，质量不把父对象和同一子部件重复累加。共同搬运只有一个被搬物的位置，承载与参与者单独关联。

物理持有与社会所有权分开：程序知道东西放在哪里、谁抓着它；角色可以对归属有不同看法。物理结果不默认执行共同财产或私有产权制度。

建筑与遮蔽物保存范围、材料、连接、覆盖和损伤。遮雨、挡风等来自已声明的结构近似，破损会改变作用，不能因名字叫“房子”就永久抵抗所有天气。

世界内记号保存载体与实际形成的痕迹/符号。内容可供观察者审计，但其他角色必须实际观察并按自己的经验解释；不把记录内容自动广播成所有人的知识。

## 9. 持续过程：火、加工、腐败与分解

持续过程保存参与实体、开始与上次更新时间、必要条件、资源投入、内部进度、所用规则和下一次检查时点。它们是世界状态的一部分，重启后不能重新从起点发放产物。

例如火读取实际燃料、含水、环境和已定义的热交换过程，消耗燃料并形成热与残留。影响周围物体需要空间作用机制；风和湿度只通过已支持的参数起作用，不触发任意剧情级火灾。

加工记录实际投入、过程进度、损失与产物。途中停止可以留下半成品、损坏或可回收材料，不能自动退回全部输入且保留输出。分解把残体转为可追踪环境库存或声明的外部排放，不通过清理程序无声删除物质。

共享属性扩大组合范围，但不是万能物理。若某种关键作用尚无模型，沿用行动协议中的能力边界处理：标记并暂停相关结算，不能由语言模型即兴裁定现实后果。

涉及未支持作用的技术暂停发生在一致提交边界，保存原意图与原因并停止本次世界的时间推进；不能只冻结相关物体却让共享资源与其他过程继续演化。已经提交的历史不回写，新机制通过新版本实验引入。

## 10. 时间怎样推进

采用同一个整数模拟时钟，按不同过程安排更新。下面频率只是尺度建议，精确步长与误差控制留给数值方案：

| 过程 | 建议尺度 | 必须提前细分的情况 |
| --- | --- | --- |
| 行动、接触、交流和动物决策 | 秒到分钟 | 相遇、资源将耗尽、即将完成或中断 |
| 身体消耗、火、物品受热和快速水变化 | 有界短步或解析推进 | 临界身体状态、火蔓延、突发降雨与接触 |
| 天气场、地表/土壤水、食物暴露 | 分钟到小时，按过程细分 | 暴雨、环境切换、储存地点或加工状态变化 |
| 植物成长、繁殖与缓慢分解 | 小时到日 | 采集、砍伐、播种或环境突变前先结算到当前时刻 |
| 年龄、季节与生长阶段 | 按时间推导或安排阶段事件 | 到达阶段边界 |

不同更新频率不允许资源使用旧状态。人准备采集或动物准备取食时，涉及资源和环境先推进到同一模拟时刻。连续过程读取这一段时间的暴露与输入，不用结束时的一个天气值代表整段历史。

无人观察的地方照常演化。仅在不影响交互、阈值和中间事件时，可以把慢过程按累计量一次更新；这种优化须与规定误差内的小步推进一致。人物接近或面板打开不能改变自然规律。

天气、生态、动物等随机流分别记录状态，调用模型的次数变化不能偷偷重排整年的天气。随机流划分和求样时机属于固定版本，不能只记一个种子就声称必然完整复现。

## 11. 自然变化与人的行动如何合并

联合结算采用同一条流程：**读取共同状态 → 申报需求和约束 → 分配实际资源 → 计算实际效果 → 联合校验 → 原子提交。** World 提供状态与过程模型，Resolver 组织求解和竞争，Persistence 提交已经一致的结果。各过程不能自行扣库存或发布产物。

| 环节 | 最小接口内容与约束 |
| --- | --- |
| 共同输入 | 实验、规则、世界版本、阶段、区间起止、已生效边界输入、参与过程及稳定随机键；同轮计算只读同一候选起点 |
| 需求申报 | process_id、资源来源/去向与单位、期望流量或数量、身体/工具占用、可分割性、最低有效投入、资源配比约束、最早完成/耗尽/中断边界 |
| 实际分配 | 每个过程实际获准使用的量、占用及竞争依据；多种资源联合满足约束，未使用的候选分配释放后重新协调，不形成永久锁定 |
| 效果计算 | 按实际投入和有效时间计算进度、产物、损耗、身体变化、练习反馈及下一边界；未获资源的尝试仍按真实发生的动作计算成本，不能一律视为免费或完整成功 |
| 校验提交 | 核对库存、物质去向、唯一位置、能力占用及效果依赖；状态、资源账、过程游标、事件和随机状态同阶段提交，成功后才发布 |

分配不是默认均分，也不按模块调用、个体编号或 API 返回次序兑现。各资源的竞争规则在实验前固定；真实开始时间、接触条件和已发生的进度可产生差异。已经消耗的资源不重新分配，模型的愿望或尚未开始的长计划不能预占整段未来库存。

降雨、水流、植物吸收、动物饮水与人的取水参与同一资源账。区间内新增供给仅在它实际到达后可用，不能把区间末产物提前供给区间初的另一个过程。存在供需依赖或分配改变过程速率时，联合求解或细分区间，重新计算全部受影响的候选效果；禁止只裁剪扣减量却保留原先的完整产出、进度或生理收益。两项加工各需一份燃料而只有一份时，实际分配必须约束两项加工的全部后果。

若计算发现更早的耗尽、完成、接触或失能边界，丢弃尚未提交的候选，从原持久状态按缩短区间重算；不回滚已提交历史。重算沿用绑定过程的随机驱动，不通过反复试算重抽竞争结果。数值方案须声明整数秒内的阈值归属、误差容限、最小步长及有限求解次数；无法得到满足约束的结果时保存诊断并技术暂停，不能无限细分或把负值夹零掩盖问题。

提交后再生成个人可感知的变化与可能唤醒。只在受影响的个人满足其唤醒安排或基础认知条件时调用模型；自然变化本身不意味着 50 人全部思考。启动时的一次性投入与后续区间消耗都遵守上述契约，并用不同效果键避免重复扣算。

| 人的行动 | 直接世界变化 | 可能持续影响 |
| --- | --- | --- |
| 采果 | 附着库存转入实际持有物 | 后续食物、种子传播与植株负担变化 |
| 砍伐 | 植物受损、材料转移、现场残留 | 遮挡、局部暴露与后续生长改变；未建模的深层气候影响不自动存在 |
| 取水或灌溉 | 从源地块转入身体、容器或目标土壤 | 水位与植物可用水变化 |
| 狩猎 | 位置、接触、伤势与体力变化 | 动物死亡/逃避及尸体处理，不能先发放奖励肉 |
| 搭建 | 消耗或连接实际材料，形成结构 | 改变局部暴露、物品存放与损伤过程 |
| 点火和加工 | 燃料、热、材料状态与残留变化 | 已支持的受热、燃烧、保存或损坏结果 |
| 丢弃食物、播种 | 实际批次移动或播种处理 | 分解、动物取食、种子存活与发芽 |

自然环境会反过来改变人的可行动条件，但不自动指派“现在必须迁徙”之类社会决定。

## 12. 资源与物理约束能保证到哪里

首版严格检查已追踪资源的转移不重复：取得必须有来源，拆分与合并数量相符，容器与地面不双存，死亡和加工不重复发放产物，资源不能为负，所有过程按阶段只提交一次。

世界是有明确边界的开放系统。日照、降雨、上游来水、蒸发和排放等有外部输入输出记录。植物增加生物量涉及水和来自未逐分子模拟环境的材料输入；不能把日照直接当作凭空生成质量。被追踪的物质、储备、损耗和外部近似来源须说明，不能假称已经实现完整元素闭合循环。

温度、土壤肥力指数等近似变量不等于可任意相加的守恒库存。若未显式求解热量总账，不宣称全系统严格热力学守恒。使用更细物理需要增加实际状态和方程，不能仅靠改字段名字提高真实性。

## 13. 初始化：让用户少写什么

建议用户主要决定世界尺度、环境风格和实验重点；生成器根据冻结模板与种子创建连续地形、水路、气候背景、相容物种、资源、少量初始物品及可居住位置。物种、材料与过程模板由构建者设计，不要求用户为每株植物或每个物品写一套规则。

地形与水路需相容，生物依赖的水和食物必须实际存在，初始物品有材料来源或明确标为开局配置。模板、随机初始结果和来源一并保存，正式运行中不因人口下降临时增加资源。

启动前在独立调试世界做环境自检：水流与资源收支、不含人的基础生长、摄食与分解、库存非负、更新频率一致性等。再检查 50 人的起点是否立即被参数错误困住。自检不能保证生态永远稳定，也不保证群体必然生存或产生文明；正式世界从保存的初始状态重新开始。

## 14. 一个完整联动例子

这是虚构设计例子：一段降雨过程增强，降雨输入增加地表与土壤水；已定义的地表模型使部分路径通行成本上升，露天木材含水增加，屋内物品则按真实遮蔽程度受到较少影响。果丛是否增产还取决于其阶段、后续日照与储备，不会因为下雨立即多出果实。

阿木按原计划沿路搬运木材。行动执行器根据新地形状态重新计算进度与体力消耗；他可能到达得更晚。如果途中实际触发中断或本人设定的可感知唤醒条件，就生成局部观察并让他重新思考。

他只知道自己淋雨、脚下变湿、负重难走等感受，不直接收到“整个流域土壤水量是多少”。他可以选择继续、暂放木材、改走记得的路或找地方休息；决定由本人作出。被放下的木材仍留在原处继续受环境影响，不因离开记忆或视野而消失。

## 15. 需要验收与明确的剩余边界

验收重点：实体唯一位置；库存与组成不双计；行动和自然过程共享资源；跨步和恢复后不重复结果；不观察时仍更新；暴露历史影响慢过程；局部感知不泄漏隐藏属性；植物/动物死亡与资源转换相符；随机过程不依赖 API 返回顺序；未支持物理作用不被包装成真实结果。

正式实验前需固定星球与创始区域的空间参数、地形生成版本、气候模型、物种及材料模板、各类自然过程的单位、误差、步长与阈值处理。
