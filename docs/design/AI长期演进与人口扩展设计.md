# AI 部落文明模拟的长期演进与人口扩展

> 基于 Survivalcraft 的目标设计，尚不表示已实现。游戏复用范围、根本驱动力和运行额度以[设计总览](./AI部落文明模拟-设计草案.md)为准；专题中的新增机制按能力清单逐项接入，不要求先重建一套世界。

设计补充。原始部落是初态。长期目标是让世界容纳繁衍、技术积累、制度形成和进一步创新，并让人口增长后的每个合格角色都能进入决策队列。

## 世界规则与世界内的创造

将物理能力做成可组合的机制。材料有属性，物品有结构，装置有能量和物料的输入输出，生产过程有时间、技能、磨损和实际产物。角色可以提出设计、制造、试验、比较结果、记录工序、传给别人。后来的人能把这些工序连成生产流程，再把装置作为新装置的部件。是否采用和传播，由人物的判断与行动决定。

例如，已建模的容器、流体转移和机械传动可以支持一项提水装置的试验。角色实际做出装置后，世界按流量、动力、损耗与故障结算。维护者积累经验，后来者能够照记录复制，并把装置用于灌溉。这条链既可能提高供给，也可能因修不起而停掉。技术验收看实际产量、可靠性和可复现性。

游戏版从原生配方、方块工具和装置起步，观察角色如何实际使用、组合和传播方法；下述开放材料与计算机制是后续目标。

长期能力包括生产、测量、储能、信息传递与可编程装置。程序作为世界内工件，依附于真实存在的模拟设备，使用受约束的虚拟运行环境，消耗模拟时间和设备资源。角色可设计和组合已有机制，宿主引擎与基础规则由版本定义。时代名称只用于观察，实验日期与人口规模不触发技术解锁。

每个冻结版本的自主演进范围取决于该版本的世界机制。角色可以形成尚无法验证的假设，先试验能够表达的部分。真正执行时若遇到缺失的关键物理作用，沿用已定义的能力边界暂停，保留意图与状态。若后来新增物理能力，由同一检查点建立有来源的规则版本分支，继承可兼容的人口、物资与历史。扩展能力的外部更新单独标记，与世界内产生的发明分别记录。严格只观察的运行以开跑前冻结的能力为准。

以用户的只观察要求作为正式长期验收标准。首版从创始流域观察生存、合作、冲突和经验传播。目标长期实验开跑前冻结游戏世界、模组和足以支撑本次研究范围的底层机制，以同一条历史中的自发成果作为证据。开发阶段可用有来源的继承分支验证规则扩展，注明适用版本与锚点。触及能力边界的截断保留为实验结果。假设与谈论和实际执行的判定见 [行动协议](./AI个体行动与模型交互设计.md)。

长远目标包含超过现实参照的特定能力。预先定义可比的任务和资源边界，观察同等投入下的产量、能耗、可靠性或计算能力。角色可以先在模拟世界中超过相应参照。现实可行性需要独立证据。开放式演化研究将持续产生新颖性作为研究问题，繁殖和遗传本身不足以保证这种结果。本项目也把跨代创新作为观察目标，将人口、资源、知识传播与实际技术效果一起验证。[Taylor 的开放式演化研究](https://arxiv.org/abs/1507.07403)

## 人口增长与决策机会

50 人是创始人口。出生、照料、成长、迁徙和死亡照已设计的规则结算。新增活产个体分配稳定身份与自己的状态。婴幼儿先按阶段能力进行身体反应和活动，在具备自主决策能力后加入与成年人相同的调度入口。人口可以增长、停滞或下降，世界记录真实供给与照料压力。

采用按需请求、每人有机会的调度。合格角色遇到必要事件可以进入队列，长期未获得思考机会时按既定最长模拟间隔安排一次；个体的总调用次数与日调用次数不作为资格条件。睡眠、失能及发育阶段沿用身体和认知条件。已有行动仍可执行，重复唤醒合并。每人同刻只保留一个主要决定，额外回想和格式修复仍有有限轮次。

按个人的实际触发时点保存输入和待处理顺序。并发上限控制在途请求数，轮转派发兼顾空闲和执行中的角色。限流时延后派发，额度不足时保留已保存响应和请求账目，按运行控制策略暂停。

如配置了阶段预算，可用经授权的追加运行额度继续原运行。额度变化属于现实运行记录，原世界时钟、个人资格、已有结果和认知规则保持一致。供应商的速率与上下文限制按实际接口处理。恢复时优先复用已经持久化的有效响应。对未知的外部用量继续保留负债，按原先的有限重试策略处理。

## 人口增加后的实施顺序

首版仍按一人到 50 人的路线验收，数据模型从一开始使用可新增的身份与队列。游戏版先验证已有角色新增、失能和死亡的资格变化；启用生命周期扩展后再验证出生后加入、成长后获得调度机会。再用高于 50 人的测试人口验证旧角色、成长后的新角色和队尾角色都能获得服务，暂停恢复后队列完整。测试使用预定响应，正式世界的增长来自其实际历史。

真实运行记录每个模拟日的活跃人口、每人有效思考机会、等待分布、请求数、用量与费用。平均每人调用量相近时，人口从 50 增到 500，单位模拟时间的调用总量也约增至十倍。并发影响处理这些请求所需的现实时间。优先合并同刻重复唤醒、控制上下文长度、让已确定的有限动作继续执行。以后可扩充服务容量或在统一顺序下并行处理独立工作，验收条件始终包括个人机会、消息因果和真实资源账。

人口扩展压测同时保留同刻与长期错峰场景，按[调度专题](./AI时间推进与调度设计.md)记录请求分布、实际在途数和等待耗时；单靠并发数无法预测提速。

长线里程碑依次验证代际延续、后代能够独立复现并改进技术，以及复杂装置和制度能够维持真实运行。各里程碑是验收与观察范围，世界内事件依实际选择和后果发生。
