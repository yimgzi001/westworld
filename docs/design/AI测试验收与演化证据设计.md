# AI 测试、验收与演化证据设计 v0.2

> 基于 Survivalcraft 的目标设计，尚不表示已实现。游戏复用范围、根本驱动力和运行额度以[设计总览](./AI部落文明模拟-设计草案.md)为准；专题中的新增机制按能力清单逐项接入，不要求先重建一套世界。

本方案衔接世界、身体、个体、行动、调度、初始化、面板、社会关系、学习与持久化设计。目标是给出可检查的放行条件、故障定位方式和演化证据等级。后文的阶段规模为建议；任何未执行、预算未覆盖或观察时间不足的项目均不标为通过。

## 1. 分开验收三个问题

| 问题 | 验收对象 | 允许的结论 |
| --- | --- | --- |
| 程序算对了吗？ | 资源、状态、可见性、调度、原子提交、恢复、费用与显示是否符合规格 | 在已覆盖场景与误差范围内，未发现所测违规 |
| 这个模型适合观察什么？ | 参数和近似能否表达生存代价、个体连续性与互动；是否对设定异常敏感 | 可用于声明范围内的人工社会观察；不等于还原史实 |
| 某个现象从哪里来？ | 事件与观察链、输入输出、规则配置、隔离对照和多次运行 | 对特定实验和机制给出有范围的归因，不声称读取模型内部动机 |

上述区分参考模拟模型验证和用途适用性评价的研究，以及 ODD 对模型说明、设计理由与评价的要求。具体案例和放行条件属于本项目设计。[Sargent：模拟模型验证与确认](https://ics-websites.science.uu.nl/docs/vakken/msosi/VerificationValidationSargent.pdf)、[Grimm 等：ODD 模型说明协议](https://jasss.soc.surrey.ac.uk/23/2/7.html)

工程通过不要求角色善良、存活、合作或建立制度。经核查的饥荒、失败合作、迁徙、灭绝或长期没有变化都可能是有效结果。明显错误的物理参数、行为协议失效和未经核查的叙事另行处理，不能因为结果看起来有戏剧性就算成功。

## 2. 每个测试用例先固定什么

用例记录：编号、要验证的契约、场景初始快照、规则/参数/引擎版本、固定意图或模型输入、随机流及稳定采样键、注入故障点、目标提交边界、预期事实和误差容限、费用上限、通过/失败/未覆盖判据。

优先使用三种独立判定依据：人工能算的小账；跨事件恒成立的约束；同一世界只改变无关实现因素时应保持的关系。不要把被测算法再抄一遍当预期值。对物理、存档和信息隔离加入故意破坏的小测试副本，检查验收工具确实能发现漏扣库存、重复效果或多读一条私人记忆；这类副本永不用于正式运行。

比较分三类：

- **必须精确一致**：实体数量和位置归属、离散事件顺序及效果去重、已提交阶段、决定可访问范围等；相同历史回放按保存结果精确核对。
- **允许预先声明的误差**：积分、温度、质量浮点舍入、阈值定位。按量纲和场景规定容限、误差汇总方式及阈值落点；不将大偏差夹为零掩盖问题。
- **只能比较分布或记录差异**：真实模型输出和长期结果。相同种子不等于相同文本或同一条社会历史；不能用固定词句或一个结局作唯一答案。

启动前分别冻结技术版本、世界参数、初始快照、种子清单、模型/提示协议、预算和观察口径。初始化种子只按事先声明的结构与开局条件筛选，记录拒绝原因；不能挑选“30 天最繁荣”的种子再称自然演化。

## 3. 世界规律、身体与制造的验收矩阵

矩阵同时保留游戏接入契约与后续身体/开放制造扩展。每个版本先按能力清单选择适用路径；原生游戏按其真实规则与单位验收，不以尚未启用的独立口渴、局部伤病、孕程、完整生态或自由结构加工判定首个游戏版失败。共同要求是物品不复制、效果不重复、信息不泄漏、恢复一致；扩展未启用单列，不能标为已验证。


| 编号 | 小场景或检查 | 放行条件 |
| --- | --- | --- |
| W1 库存账 | 固定一批食物和两个容器，拆分、合并、交接、食用、腐败 | 每步有唯一来源与去向；未用部分保留，合并不刷新腐败或污染；剩余＋已转移＋明确损耗与输入相符 |
| W2 唯一位置 | 容器套装、共同搬运、掉落、原持有者死亡 | 每件物品只有一个实际位置/附着关系；无嵌套环、共同搬运不复制实体和质量 |
| W3 自然输入 | 无雨与有雨、静止与流动、有燃料与燃料耗尽、采摘后的植株 | 输入/输出和阈值按声明机制发生；采摘不等于杀死植株，库存不会每天免费补满 |
| W4 动物循环 | 动物进食、死亡、处理残体 | 活体、遗体、可取得物料不双计；残体物质有去向 |
| W5 身体账 | 同一初始身体分别进食、饮水、负重、休息、睡眠 | 实际吸收有延迟，水、能量和活动记账不重扣，休息不免费补给；疲劳与睡眠压力可分辨 |
| W6 伤病与危险量 | 局部受伤、潜伏感染、照料、改积分步长 | 局部功能而非统一掉血；隐藏感染不泄漏；同一暴露不因额外调度或切步抽更多次 |
| W7 生命周期 | 独立测试副本放入接近事件阈值的幼儿、衰弱者、孕程等 | 生长消耗资源；出生、死亡只发生一次；母胎、乳汁、婴儿和遗体的物质有真实来源和去向 |
| W8 制造与学习 | 新名称旧结构、改变结构、加工中断、失败练习 | 名称不赋予功能；支持的组合由结构计算；半成品、投入和学习量可追踪，重试不增益 |
| W9 能力边界 | 游戏区块接缝、谈论未知技术、执行无法结算的关键作用 | 正常跨区移动和可执行准备不被错误拦截；实际无法结算时保存暂停。立方球接缝仅在球面扩展启用后另验 |
| W10 初始化 | 按基线和边界预设生成；在独立副本演练第一批事件 | 人口、亲缘、身体、物资、可达资源、照料背景与零点状态自洽；无隐形历史扣费，不将演练结果带入正式快照 |
| W11 联合资源与依赖效果 | 两项加工争一份燃料、人和动物共用水源、区间中途耗尽、多资源投入不足、同区间供给晚于需求 | 实际分配同步约束产出、进度和身体收益；缺投入不保留完整效果；未使用分配释放，无提前借用未来产物；缩短区间重算无遗留预占、重抽随机或重复效果，有限求解失败明确暂停 |

守恒核对明确统计范围与单位。例如世界水体积与体水质量经冻结的密度转换；血液中的水不在两份库存重复扣。只对承诺的资源账和封闭子系统断言守恒；太阳、雨水、排出等显式列外部输入输出，简化热平衡不冒充完整热力学闭合。

一项手算小账示例：初始 5 个单位的食物，移入另一个容器 2 个单位，应得到原处 3、目标处 2、全体合计 5。若其中 2 个单位随后实际入口，按同一账的范围记录容器减少与消化队列增加；吸收、排出与后续消耗另在实际发生时核对。分别在转移前与提交后中断，恢复结果须与不中断基线匹配。

长时参数测试使用独立副本：检查营养不足、补给、睡眠、季节资源变化在声明范围内的方向、幅度与积累误差。通过手算或高精度参考只说明数值实现可信；如果所有可用开局都因不合理参数立刻崩溃，应检查模型适用性，而非自动补资源。正式试验未自然遇到罕见事件时，以专门用例验证机制，不能说正式运行已覆盖该事件。

用途评价另做参数敏感性检查：预先列出活动消耗、资源恢复、感知范围和回顾间隔等关键假设的候选范围，建立相互独立的比较运行。若现象只在很窄的取值下出现，报告适用范围与依赖，不把调整参数后碰巧得到的结果混作原版本的验证，也不据此宣称已与真实史料校准。

## 4. 人的行为与信息隔离验收

| 编号 | 测试 | 通过判据 |
| --- | --- | --- |
| P1 身份/权限 | 在人物身边放置可见和被遮挡的物品；另在他人背包、档案或观察者审计放唯一标记 | 检查实际出站请求、回想结果、反馈和触发理由。可见项有合法引用；遮挡或私有信息不经输入、菜单、错误或唤醒侧漏 |
| P2 记忆连续性 | 经历→保留→再次遇到→概括/遗忘→保存恢复 | 可回想时正确提供本人的条目；来源失效后，摘要与关系说明不把忘记细节偷带回；可保留独立判断 |
| P3 意图与事实 | 自称已取得食物、已学会、对方同意、规则已通过 | 未结算动作不改库存、熟练度、别人心理或社会权限；主观自述允许错，不能获世界核验标记 |
| P4 交流与合作 | 两人提出交换并实际交接；第三人未听见也未目击，随后听到转述；另测发声中断、忽略请求和退出共作 | 实际出站输入符合接收范围与发声时长。双方独立回应，实际交接只结算一次，旁人转述后只获得带来源的消息。共同劳动记录实际贡献与退出 |
| P5 关系和规则 | A、B 对同一赠食/承诺的理解不同，或一人只宣称自己是首领 | 方向性关系独立；到期不自动处罚；宣告不赋予控制他人的能力 |
| P6 传承 | 讲解遗漏、独立练习、损坏记号、长辈死亡与后代接触 | 只获得实际接收内容，不复制技能或死者私有资料；可记录接触与复现差异 |
| P7 恶意或无效输出 | 错身份、越权读记忆、未知操作、用对话索取宿主权限 | 权限和协议在执行层拒绝；技术错误有界处理，不写成人物已做错或已服从 |
| P8 有效表现 | 单人一天和少量由真实模型驱动的角色互动，比较有/无可用经历的相近情境 | 看记忆是否实际提供、动作是否可执行、个人打算是否跨时点延续；报告不相关复述、反复失败与趋同，不规定唯一正确的人生选择 |

权限测试同时用正反例：能看自己的合法记忆，也确实不能读他人的；能听见近处讲话，也不会获得远处私语。对隐藏事实的配对检查保持一切可感知后果不变，比较有效输入投影，不因模型恰好没复述标记就认定没泄露。可以凭预训练知识猜测一般事实，但不能伪造受系统认证的世界经历。

角色“太像”或“常忘事”先拆成三种可诊断问题：经历没有进入感知、记忆没有被检索、已经提供但输出没有使用。前两类可检查系统契约；后一类属于模型表现，按样本记录和改进。若要将行为连续性或协议可用性作为正式质量门槛，须在试验前定义口径、抽样和阈值，不能看完故事再挑标准。没有出现某种性格差异也不能仅凭一次回答判为程序错误。

## 5. 时间调度和预算验收

先使用可控响应器或保存的决定带做确定性测试：同一观察对应同一个预先固定的有效决定或故障。核对实际输入快照与 T+D；若输入已先出现不应有的分歧，就在首个差异处报告，不用强行送入同一答案掩盖问题。任何预置决定都标为测试来源，不计入自主行为证据。

| 编号 | 对照变化 | 预期不变或预期结果 |
| --- | --- | --- |
| T1 API 返回顺序 | 用模拟接口跑同一批 50 人，比较串行、10 并发和 20 并发，注入乱序与慢响应 | 世界在同一模拟时点冻结到必要响应齐备。相同决定下世界事实、竞争与动作次序一致，现实耗时可不同 |
| T2 同刻竞争 | 计划续步、新完成决定和动物动作同刻争资源；另测同一人续步被新决定替换，交换读取/排队次序 | 所有来源进入统一启动集合，不因完成回调提前抢占；同一人不双启动；联合结果保留真实先后，固定条件与随机键下不受遍历顺序影响 |
| T3 思考耗时 | 返回已缓存但未到 T+D；期间受伤、失能、死亡或普通饥饿 | 结果不提前生效；重大中断正确取消；普通变化不丢掉无关有效字段，行动开始时重查条件 |
| T4 多重唤醒 | 同刻消息、计划结束和回顾；连续对话与反复自我提醒 | 同一人合并必要决策，遵守正耗时、最小反应间隔及动作互斥；无零时间死循环 |
| T5 步长和外界时间 | 同一固定驱动下细分积分，插入不改决定的额外检查；暂停、提速、关闭面板 | 在孤立平稳场景符合容限；真实阈值不跳过；不重新采样；仅墙钟变化不影响世界 |
| T6 失败与预算 | 限流、超时、格式错、余额不足、未知用量 | 恢复重试有界；整批预算预检；不让部分成员先做；未知费用不清零；达到边界保存暂停 |
| T7 观察访问 | 打开面板、订阅更新、断线续读和提交控制 | 首条事件及时送达，续读无重复效果，控制到达安全边界，关闭观察窗口后世界仍按既定规则运行 |
| T8 错峰吞吐 | 相同配置下分别运行同刻、长期错峰和交流连锁轨迹，再在每种固定轨迹内比较并发数 | 不为凑批延迟唤醒或提前使用未来观察；逐类报告批次分布、单人批次占比、在途数、等待/计算/存储耗时及每模拟日用量与速度，不把不同轨迹强求为相同结果 |

对照比较排除现实时间、请求回包顺序等应变化的技术字段，保留模拟时刻、阶段、资源账、决定安装与事实。ID 重映射只有在逻辑身份和随机取样也对应时才可比较同一个结果；否则按多次平局场景检查是否存在系统性偏置。

步长检查比较有解析或高精度参考的小场景与关键阈值，单独处理接近阈值时的时钟舍入误差；不要求改变实际世界轨迹后几个月的社会演化仍逐项相同。真实模型的上下文、返回、用量和错格式另做有限调用检验，不能用它代替固定决定的调度对照。

预算验收分别核查可证明的最大计费量与本地估算控制。只能估算时，验证预留、未知费用和停止派发，不能认证最终外部账单绝不超额。若运行要求外部账单硬上限，供应商及账户须支持这一保证，否则该要求未验收。

## 6. 存档、恢复与历史验收

先建立不中断基线。用相同初始状态、固定决定、随机驱动和模拟截止点，在同一测试用例的不同阶段强制中断，再比较恢复后的已提交事实、个人状态、队列、效果与库存。检查恢复的不只是最终存活人数，还包括第一处有分歧的阶段。至少分别测试可控的写入错误与进程强制退出；进程测试通过不能代替真实存储故障的保证。

| 编号 | 故障点 | 必查结果 |
| --- | --- | --- |
| R1 提交前 | 资源已分配、效果已算出、启动成本写到一半但未提交 | 库存、进度、身体、随机游标和完成标记整体未生效；恢复不保留候选预占，重算不重新抽签 |
| R2 提交后 | 计划续步已登记或动作已启动，提交成功但未确认/推送 | 以阶段与稳定标识恢复待启动项及计划游标；不重复登记、启动或扣费；观察流可补发并去重 |
| R3 连续过程 | 发声、搬运、加工、消化、学习和孕程的中途 | 从真实进度、持续区间和半成品继续；不重复发声、摄入或出生 |
| R4 调用中 | 待派发、发送不明、完整响应已存、候选等待 T+D、迟到回调 | 有效响应复用，未知尝试保留；重试不重复安装，现实等待不推进世界 |
| R5 备份与所有权 | 快照写一半、备份截断、版本不符、两个进程争写、磁盘满 | 坏副本不发布、旧有效点保留、只有一个运行器、原版本兼容才继续；出错不先执行后补写 |
| R6 观察资料与分支 | 当前状态模式检查最新进度，启用日报时核对 08:00 取材与去重。历史模式检查回放和历史页重连。两种模式都从旧备份恢复 | 观察资料对应同一存档与时点，打开资料时复用已存结果，世界状态保持一致。丢尾部标明缺口，新分支保留已发生的真实费用 |
| R7 运行进程停机与重启 | 在测试服务中正常停机、强制退出、替换应用并复用持久盘，从独立备份在隔离目录恢复 | 数据目录和运行意图可恢复，单运行器所有权生效，未完成批次按记录续接，已提交效果只出现一次 |

仅持久化结果完整且后续输入一致的情况，才要求恢复后的模拟事实与不中断基线一致。外部响应实际丢失、必须重新调用时，测试的是状态、负债、选择和去重契约，不要求未保存的文字能够恢复或两次样本相同。真实供应商幂等/账单能力未核实前不宣称外部请求只计费一次。

## 7. 怎样主动找出逻辑漏洞

1. **在安全提交边界核对不变量。** 检查负库存、重复位置、关系所有者、时间倒退、区间重复、死者仍能行动、出生不记账等。廉价检查持续运行；代价大的审计可在固定边界或独立副本复算。发现违反即技术暂停并保存证据，不能静默改值继续。
2. **组合边界而不只测顺利流程。** 例如“人在搬运时受伤、放下装水的容器、另一人同刻接取、程序提交后崩溃”。跨身体、对象、冲突与恢复的组合应单列高风险场景。
3. **自动生成动作序列。** 在隔离测试中生成有效动作、极端数量、无效引用、重复请求与不同事件顺序。保持可复跑的生成种子，失败后缩减到能复现的最小序列，不能只保留最终错误画面。
4. **改变本不该有影响的因素。** 替换遍历顺序、延迟 API、开关面板、改变无关检查的分割点，寻找事实变化或资源偏置。相关随机驱动和真实输入必须保持可比。
5. **验证检查器自己能报警。** 在测试副本故意制造一次重复扣款、幽灵动作、全知记忆或监控回灌，确认独立对账/输入审计能抓到。不要只依靠执行器自己宣称“成功”。

异常记录包括最早错误版本、之前的快照、相关事件/意图/可见输入、实际与预期差量、涉及单位、随机键和调用状态。先用持久事件和状态定位首个不一致，再判断是规格不清、实现错、参数不适合、模型失误、技术边界或观察误读。

修复进入新版本；原实验保留异常前后记录，不改写已发生历史。相关故障加入回归用例，再跑受影响的契约与联合场景。一次故事看起来合理不能抵消一个已复现的资源或权限错误。

## 8. 分阶段放行，先验证核心假设再扩大世界

阶段顺序与交付范围见[实施路线](./AI分阶段实施路线设计.md)。这里维护每次放行所需的证据。早期探索允许世界机制不完整，所有已开放路径仍需满足正确性、信息隔离、恢复和预算契约。

| 阶段 | 建议运行范围 | 出口条件 |
| --- | --- | --- |
| 1 最小离线闭环 | 无模型；一人、小场景、固定决定与故障注入 | 已启用资源/身体/动作账、时钟、个人输入、记忆与持久化通过；具备进入早期调用前的保护路径 |
| 2 早期真实模型探索 | 明确小预算；先一人，再在多人路径离线通过后试 2—5 人 | 实测动作协议、个人连续性、独立回应、等待与费用；明确简化范围、失败和未覆盖能力 |
| 3 游戏接入与离线扩展 | 无模型；核对能力清单、跨模块场景、50 人同刻与错峰批次、故障注入 | 通过 W/P/T/R 中已启用机制的必要路径及下述 G1—G5，未启用扩展明确标注 |
| 3 的候选版复核 | 最终候选版本的一人和少人数有限短试 | 复核适配后的 P8 闭环、接口用量、故障/预算控制，旧探索证据不冒充最终版本验证 |
| 4 50 人运行试验 | 先短段，再按预算推进约 30 个模拟日的建议窗口 | 启动、运行、暂停、恢复、观察资料、费用和容量达到预定口径，技术截断如实报告 |
| 后续演化比较 | 预登记种子、对照分支和多年窗口 | 有相应事实链、差异与不确定性；跨代结果和开放技术演进另验收 |

**早期真实模型探索前的最低门槛：**

- 使用固定决定通过已启用路径的资源收支、唯一位置、实际产出、身体变化、正耗时与 T+D，验证意图不能改事实。单人也用隐藏对象和他人资料夹具验证输入/回想/错误反馈隔离，并通过无效或越权输出检查。
- 保存精确输入、完整响应、阶段与效果标识，验证提交前后中断、响应已存后恢复、暂停继续、未知外部尝试及有限重试。预算覆盖主要调用和额外回合；先预留、记录发送意图，再派发，未知费用不释放。早期不能只有假额度计数器。
- 冻结本次简化范围、供应商/模型、协议、价格或估算限制、请求/token/金额预算、重试边界、存储余量、模拟终点和质量口径；具备受控访问、可读时间线与停止入口。未验证的动作不开放，未实现机制明确列出；早期探索具备受控观察和停止入口，正式运行验证实际访问边界。
- 扩到 2—5 人前，再以固定决定通过个人隔离、讲话实际送达、独立回应、交接、统一启动竞争，以及相应多人批次的预留、失败和恢复。不要求此时完成尚未开放的动物、制造、繁衍与传承。

这些用例可复用 W/P/T/R 矩阵中的对应场景，但结果必须注明简化范围；不能将测试人口符合小场景写成正式 W10 的 50 人初始化已通过。核心安全与一致性路径缺失即不放行，不能仅凭一次成功调用进入下一规模。

**50 人短段前：** 阶段 3 已启用能力的必要路径及 G1—G5 通过，关键遗漏标为未通过；最终候选版本至少各有一条 P8 单人和多人闭环：真实经历进入后续输入并产生有效决定，实际交流送达后由接收者独立回应、忽略或拒绝。没有已知重复结算、信息泄漏、假成功、绕预算、不可恢复状态或观察回灌，调用用量与失败处理可解释。无模型的罕见生命周期专用场景验证机制，不能算作正式演化历史。

**完整 50 人窗口前**，短段通过运行、恢复、观察资料和费用验收。依据同刻与错峰轨迹实测，登记吞吐、存档体积、恢复耗时、模型可用率及预算和容量阈值。到达指定模拟终点才记为窗口完成，预定自然终点如灭绝单列。按原因登记提前停止和未覆盖范围，保留所有登记运行。

首个游戏版正式观察范围是已冻结游戏能力内的生存、分工、休闲、合作、冲突和方法积累，不要求先完成所有后续生命周期与世界扩展。缺少出生和成长机制时，不验收代际结论；启用后才按 W7、P6 等完整检查。多年演化、复杂技术与超出现实参照的结论需要另外的能力范围和证据。

**发布演化结论前：** 需要相应事实链和比较证据；缺少对照、适用性未确认或数据不足时限制结论，不要求停止一场本身正确运行的探索试验。行为指标与质量阈值在试验前定义，不规定唯一正确的人生选择，也不事后挑标准。

### 游戏接入与长期运行补充检查

| 编号 | 场景 | 必须检查 |
| --- | --- | --- |
| G1 分层执行 | 固定计划走近、拾取、进食，在拾取后重开；另测绕障、有限重试与取消 | 到达看实际位置，拾取与进食核对实际库存和结果。恢复从进食继续，拾取效果只发生一次。每个控制帧沿用已启动动作，受阻只在授权范围内处理 |

检查 G2 时用同一固定动作与随机驱动隔离观察因素，不能以重新调用模型产生的差异替代无干预验证。G4 不必真实花完本轮资金或写满容量；验证逻辑与当前配置，再在真实运行记录实际用量。稳定性窗口和阈值开跑前登记，未达到就报告未覆盖。

## 9. 怎样证明现象确实经过角色互动

先检查“事实来源”，再评价“机制影响”。每个关键变化带来源类型：初始设定、自然过程、引擎结算、角色已生效决定/行动、角色主观看法或观察者推断。实现时检查正式配置、提示、初始化器和可写入口，确保没有预设剧情、群体标签回灌、观察者报告改状态或悄悄指定谁接受谁。

零点核查覆盖个人自由文本。基线不生成客观已成立的制度或指定领袖；初始记述若已有某分食主张、领导印象或类似规范，将其标为初始注入的信念，可分析传播、争议或维持，不能计为从无到有。检验某条规则首次形成时，在运行前排除目标信念已注入的开局或另列分层，不能事后挑种子。模型已有观念仍是接受的实验条件。

以“分食惯例形成”为例，完整证据链可以包含：

1. 有具体的实际共同采集与分配争执，记录资源账。
2. A 在独立决定后实际提出先约定分法，记录发出和可听范围。
3. B 确实收到，后来本人记住、复述或采纳；未听见的 C 当时没有该来源。
4. 后续决策的实际输入含相关经历，输出选择先商量，并在世界内执行。
5. 不同场合再次发生，出现他人提醒、拒绝、变更或延续；面板可展示具体差异。

这能支持“发生了交流、传播和遵守行为”。只是模型说“我们已经建立制度”，只算表达；只是观察到重复分食，可能来自共处或资源相似，仍不足以认定共享规范。是否属于稳定规范，由事先声明的事实口径和解释共同判断。

把来源证据分级：

| 等级 | 最多能说什么 |
| --- | --- |
| 叙述或候选 | 有人说过、某模型提过、观察者提出解释；尚无实际结果 |
| 事实模式 | 可验证地发生了几次合作、争夺、复现或自称；原因尚未区分 |
| 可追溯互动链 | 某条实际感知/记忆进入某次决定，随后有独立行动与结果；不能据此读取内部推理或确定唯一原因 |
| 对照支持 | 在已指定的对照、种子和样本中，改变某机制对事先定义的结果有可重复影响；结论限于该模型和条件 |

故事文本、模型简短理由和事后报告都不作为唯一证据。显示日志引用和可能替代解释，例如初始熟人关系、环境共同压力、模型预训练观念、共享行动目录或资源分配机制。

## 10. 用隔离对照检查互动的作用

对照实验从明确的同一锚点或匹配开局建不同实验标识。正式主世界保持只观察。所有干预、可比条件、种子与版本记入清单，不把对照结果拼进原历史。

建议区分两类：

- **局部输入对照**：从某次实际思考前的测试副本出发，保持同一观察时点和唤醒机会，只变化一条可访问消息或一段明确记忆，比较接受、拒绝、询问或协作倾向。控制条件不塞“你没收到那条消息”之类额外暗示；检查该信息有没有经摘要、已派生信念或另一渠道泄漏。这只检验给定处境中的信息作用，不代表整段社会过程。
- **整段机制对照**：从消息传播前或相同初始化出发，只调整预先声明的一种传播/记忆通道，保留其他规则和独立环境随机驱动。之后让角色自行行动。因改变而产生的后续接触、资源与决策差异是结果，不把基线后半段的意图强行喂给对照，也不冻结本应受行为影响的环境状态。

例如比较“正常收到分食提议”和“该表达在对照中未送达”，保持相关物理位置、资源、模型与规则版本不变，预先定义后续多少模拟时间内的真实协作、事前约定和分配结果。若只删语音，还要记录其他人的转述、视觉行为和已知同类经验；不能把受影响路径说成所有知识都已消除。整段对照改变一次送达也可能改变唤醒和后续事件，这是该干预的一部分；局部输入对照则固定唤醒以区分直接输入效应。

首轮整段对照建议问“已有合格提议时，送达是否影响后续行为”：在提议已产生、尚未送达时配对，依据事先定义的条件登记机会，不按未来是否形成惯例挑锚点。若要估计“从开局启用某种传播机制的效果”，另用预登记开局比较，不以已出现提议的样本代替所有开局。

观察工具还要用正反例验收：只有自称首领而无回应时不得标为已被服从；有实际提议、独立接受和出力时能指出证据。这些测试不计为自主演化样本。

比较计划在看结果之前登记：主指标、观察窗口、分母、种子与重复数、预算/停止条件、如何处理预算暂停和其他失败。独立环境随机驱动尽量配对；互动变化会改变本来就依赖行为的事件，不要求全程随机调用顺序一样。供应商模型响应仍可能波动，采用多次独立运行或配对开局、记录实际模型版本与运行顺序，不能只用一次成功对照得出普遍结论。

以运行/配对为主要独立单位，不能把同一世界中相互影响的 50 人当作 50 次独立重复。样本少先给出各次结果、差异范围和反例，标注探索性。若预算不足以区分模型波动与效果，就报告证据不足。测试固定决定可用于证明调度无偏，不可用于证明删去某条信息后模型本来会怎么选。

首轮机制比较采用固定模拟窗口。干预可能改变对话和请求量，提前截断不能当作随机丢样本；保留全部预登记分支、停止原因和已观察结果，窗口不足时记证据不足，不只挑跑完的配对或事后缩短窗口冒充主结论。若另问“相同预算能观察到什么”，另行登记，将完成率、可覆盖终点和真实费用也作为结果。

## 11. 观察指标及报告口径

| 现象 | 事实指标建议 | 解释边界 |
| --- | --- | --- |
| 合作 | 实际共同出力次数、参与者、成功/失败，按可观察的有效提议或相遇机会计率 | 口头赞同、同处一地和强制出力分开 |
| 冲突 | 争议表达、资源竞争、实际对抗与伤害；按模拟时长/机会分开 | 分配观点不自动判为偷窃、仇恨或战争 |
| 关系/群体 | 方向性判断、实际接触与合作、自称和他称；按声明窗口统计 | 簇是观察解释，不是统一成员身份 |
| 规范 | 提议/听到/记住/采用/提醒/实际干预，记录反对和未触达者 | 一次宣言或行为重复不等于共同规则 |
| 发明/传承 | 实际制成、使用效果、接触、练习、独立复现、跨代复现 | 首次观测不等于独立从零发明；接触不等于掌握 |
| 稳定与代价 | 资源、人口、伤病、模拟速度、实际请求/费用、暂停和缺失 | 失败、灭绝和中断如实记录，费用估算与真实账单分列 |

报告事先说明分母、时间窗口与标注规则。有争议的自然语言标签保留原话和判定依据，必要时交独立读者复核，不让分析模型的一段解释当唯一裁判。未观察到、确实为零、因预算截断和缺少可验证数据分别标记。若研究人员事后发现新现象，可提出新假设并登记后续对照，不将探索性发现伪装为预先通过的指标。
