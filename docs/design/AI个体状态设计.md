# AI 个体状态设计 v0.1

> 基于 Survivalcraft 的目标设计，尚不表示已实现。游戏复用范围、根本驱动力和运行额度以[设计总览](./AI部落文明模拟-设计草案.md)为准；专题中的新增机制按能力清单逐项接入，不要求先重建一套世界。

## 1. 已确定的方向与本次默认方案

已确定：50 个原始部落成员，各自拥有持续的个人状态；重点是记忆、欲望、性格、思考和认知差异；逻辑上有个人档案、长期记忆和短期上下文；共享模型按需调用；不联网，不另行处理预训练知识。正式实验启动后人类只观察。

本文件提出的数据结构和更新机制是设计者的建议，不宣称已得到用户逐项确认，也不将其当作已验证的人类心理模型。具体初值、数值范围、时间常数和认知预算后续通过小规模实验确定。

核心原则：世界保存事实；个人保存自己的经历、判断与打算。短期心理状态可以快速改变；长期性格通常缓慢改变。相同经历对不同人可以产生不同影响，不能仅靠事件类型自动规定其人生选择。

## 2. 一个个体的五部分状态

| 部分 | 主要内容 | 唯一维护来源 | 常见变化尺度 |
| --- | --- | --- | --- |
| 身体与处境 | 出生时间、身体性别、生长阶段、位置、能量、水分、疲劳、伤势、疾病、持有物 | 世界引擎 | 按物理和生物更新频率推进 |
| 稳定个人特征 | 倾向、偏好、基础认知参数、可塑性等 | 初始化及受审计的成长/巩固过程 | 成长阶段或长期经历 |
| 当前心理状态 | 情绪、愿望、关注点、未完成目标、对自身与他人的看法 | 感知驱动的内部状态更新与模型提出的解释 | 分钟、事件或若干日 |
| 长期记忆 | 选择保留的经历、传闻、判断、反思和学习记录 | 本人思考/回顾时选择，记忆系统校验并提交 | 经历之后、回顾时、检索或遗忘时 |
| 短期工作区 | 当前感知、近期交流、唤起的记忆、当前计划及注意安排 | 运行器按个人范围组装，个体决定关注和计划 | 每次感知与思考 |

身体真实状态与身体感受分开。例如实际感染可以尚未出现可感知症状；不能把隐藏的感染原因直接告诉角色。世界保存的真实亲缘与个人相信的亲缘也分开。

## 3. 怎样存：两份个人资料，加上世界与运行状态

每份运行状态由统一的权威存档维护。记录带实验标识、个体标识、版本、生效模拟时间和来源，避免身份、时间或并发结果混淆。逻辑集合可按实际引擎拆分。

| 数据集合 | 内容 | 对应个人资料 |
| --- | --- | --- |
| agent_profiles | 身份引用、稳定倾向、偏好、认知配置、成长阶段配置 | “关于他”的个人档案 |
| agent_mental_states | 当前情绪、关注、愿望、目标、自我认识及关系判断 | 个人档案的动态部分 |
| agent_memories | 本人的记忆条目、来源、版本、可访问性及修订关系 | 长期记忆 |
| agent_workspaces | 当前短期缓冲、被唤起记忆、计划、下次思考安排 | 短期工作区；随检查点保存 |
| agent_skills | 经过行动验证的熟练程度、实践和反馈 | 档案可引用，结果由世界结算 |
| agent_state_changes | 状态变更提案、依据、接受或拒绝及实际变更 | 供观察者追踪，不作为角色可任意读取的全知档案 |

可导出为每人两份可读资料：个人档案（含动态心理状态）与长期记忆。短期工作区保存在运行检查点。导出只是观察视图，角色不通过宿主文件系统访问它们，也不维护第二套可互相覆盖的事实。

世界引擎保存身体与实际持有物，档案只引用这些事实。展示年龄由模拟时刻与出生时间计算。身体状态不允许模型通过“修改个人档案”直接改变。

## 4. 性格：稳定倾向、情境反应与习惯分开

首版建议使用少量倾向维度：风险容忍、好奇、主动接近他人的倾向、对陌生人的初始信任、耐挫与等待回报的意愿。维度选择本身是建模假设，不对应诊断或心理测量结论。

内部可以用有明确范围的数值表示强弱，同时保留简短文字描述与变更来源。传给模型时使用清楚的行为倾向描述，不要求它把小数当作精确的心理定律。

“总体谨慎”“今天受惊”“不信任某个人”“雨天走熟悉路线的习惯”是四种不同状态，应分别保存。一次失败通常优先改变眼前情绪、具体判断或习惯，不默认改写总体性格。

个体可以在回顾时提出长期倾向变化，须引用自己可用的记忆。运行器检查身份、依据是否真实可访问、变化范围与更新频率；缺乏支持的永久变化可以保留为暂时自我看法，不直接修改基础倾向。允许重要单次经历带来明显情境反应，但不预设必然形成某种长期人格或临床状态。

变化边界和可塑性机制在实验前固定，个体的具体倾向与习惯仍可变化。为防止每轮提示词把人重写，保留基础倾向、当前值及每次修订，不用新生成的一段人物介绍覆盖旧状态。

## 5. 欲望、目标与计划

用户已确定每个人具有强烈的求生愿望和对死亡的恐惧。危急处境下，角色可以把自己的存活放在守约、分享与名声之前，考虑冒险、争夺、欺骗，也可以选择求助和合作。恐惧随本人可感知的饥渴、虚弱和危险加强，具体手段由个人决定。身体能力、动作前提和资源数量约束最终效果。

欲望表达“想要什么”，目标表达“目前打算实现什么”，计划表达“准备怎样行动”。它们不应合并成一条永远必须执行的任务。

每项愿望建议保存：愿望标识、内容、指向对象、当前强度、预计持续性、产生来源、当前状态和最近修订。来源可以是身体感受、个人偏好、实际互动、既有记忆或自己提出的打算。身体产生饥渴等信号；角色可以形成、调整、延后或放弃相应目标，但不能删除身体后果。

生存需要、亲近、好奇、自主、资源积累、寻求认可或地位、休闲享受、兑现承诺等作为可能表达的愿望，不要求每个人都具备全部类型或按相同顺序排序。模型可以提出新的具体愿望，类型只帮助索引，不成为封闭的人生任务表。

多个愿望可以冲突。模型结合当前处境决定行动，运行器不机械执行数值最高的愿望。模型可以改变具体愿望；对稳定偏好的重大改写需要与性格类似的回顾与来源记录。某人获赠食物后可能想回报，也可能没有形成这一愿望，不由程序自动下达“回报任务”。

劳动投入、休闲偏好、风险与诚实倾向可以有稳定差异，也可以受经历影响；不把所有人设为最大化产出的劳动者。人物可游玩、探索、休息、拒绝共同劳动，或在供给允许时依赖别人。疲劳、伤病、失能、主动休闲和故意少出力分别记录，不能由“没工作”直接诊断为懒惰。

能力、兴趣、实际活动与社会称谓分开。有人喜欢狩猎却不熟练，也有人擅长建筑却更想游玩。专业分工由反复选择、练习、需求、交换与他人回应逐渐形成，允许兼任和转行；初始化不分配猎人、农民、建筑师或首领名额。称谓不自动增技能、给资源或控制他人。欺骗也可以来自日常利益、地位或个人打算，不仅发生在濒死求生时；不强迫每个人诚实或必然欺诈。

## 6. 情绪和关系判断

情绪保存类型或描述、强弱、所指对象、形成来源、开始时间及持续状态。身体感受可以提供不适或精力变化；模型结合自己知道的处境提出害怕、愤怒、安心等情绪解释。情绪自然回落的近似机制由运行器执行；具体含义和对象不能由全知事件标签自动指定。

情绪可以影响哪些记忆更容易被唤起及下一次决策，但不会强制唯一行动。角色没有调用模型时，身体与已存在情绪按既定机制推进；不声称期间持续发生了未计算的复杂反思。

每段关系判断带 owner_id 与 target_id，可包括熟悉、信任、依恋、顾虑或义务的文字与有限强度指标，并引用记忆。不要求双方一致，不存在所有人共享的“关系真相分”。一次互动通常先影响对该对象的判断，而非自动改变对所有人的态度。

## 7. 认知能力与技能

| 维度 | 如何在系统中体现 | 边界 |
| --- | --- | --- |
| 注意范围 | 每轮可处理的感知信息、能同时关注的对象 | 不能通过注意机制读取未感知的世界事实 |
| 工作记忆 | 同时保持的活跃信息项与可用上下文预算 | token 数与人类工作记忆不是等价测量 |
| 回忆能力 | 线索匹配、可访问记忆与检索的不确定性 | 不等于所有经历随时完美可查 |
| 规划能力 | 可同时维护的子目标、计划复杂度及外显规划范围 | 不能保证限制了基础模型所有隐含推理 |
| 学习效率 | 实践反馈转化为熟练度的速率与保持 | 不是知道某个名称就自动掌握技能 |
| 处理速度 | 部分判断与执行在模拟时间中的耗时 | 与 API 在现实中的响应延迟分开 |

共享模型条件下，这些参数主要约束信息、外显计划、学习与行动表现，不能保证制造出具有某个真实 IQ 的独立智能。初版统一基础模型，先通过具体情境检查差异是否真的表现出来。

身体疲劳、疼痛、疾病和成长阶段可以暂时影响有效认知参数，恢复后解除相应影响，不必改写基础能力。基础能力随成长的变化和实践学习是另外两条机制，参数及适用范围需声明为假设。

技能熟练程度根据实际练习、环境难度与反馈更新，由世界结算。个人可以误判自己的熟练程度；“我已经学会”作为自我判断保存，不能直接提高实际操作结果。新生个体有独立状态，不能复制父母经历；使用成熟预训练模型仍无法保证从零学习语言和认知。

## 8. 长期记忆条目

建议字段如下：

| 字段 | 含义 |
| --- | --- |
| id、owner_id | 记忆标识与所属个体 |
| experienced_at、recorded_at | 事情被体验的时间与写入时间，区分迟到回忆 |
| kind | 经历、听闻、推测、反思、意图或学习记录 |
| content | 本人保留的描述 |
| entities、place | 自己所知的相关对象与地点，用于检索 |
| source_refs | 本人可感知的观察、收到的消息或已有记忆引用 |
| confidence | 本人相信到什么程度，不是客观真值 |
| salience、emotion_tags | 本人赋予的重要程度与情绪关联 |
| accessibility | 当前可回忆程度及保留状态 |
| revision、supersedes | 更正或概括关系，不无声改写世界历史 |

来源引用由运行器验证访问范围；它不判定角色的全部解释是否正确。例如“他给了我食物”可以是观察，“他一定想利用我”可以是推测。推测不得通过改标签成为已发生事件。

来源合法不代表模型写出的每一句话都准确。记忆保留两部分：由感知系统提供、不可由模型改写的观察锚点，以及模型生成的个人记述。后者可以包含失真、误解或不确定性，始终作为主观内容，不能因为引用了锚点就被认证为事实。只有来自引擎感知记录的字段可以标为系统核验过的观察；自由文本不自动取得该标记。检索时角色收到其当前能够回忆的记述，锚点用于审计，不能绕过遗忘重新读取全部原始细节。

个人内置常识或模型提出的泛化观点，不需要伪造一次亲身经历来解释。用户已决定不专门限制预训练知识；本设计的来源校验针对模拟世界中的经历和可访问事实，不声称能追踪模型每项知识的训练来源。

## 9. 记住、检索、巩固与遗忘

短期观察由感知机制进入有限缓冲，个人思考时选择保留什么。直接没有进入角色感知的事情不会进入候选缓冲。不是每个移动步骤都自动生成一条长期个人记忆。

检索在本人可访问记忆内结合当前线索、时间、涉及对象和本人关注进行。候选上限和索引策略属于认知机制；个体可以改变关注线索，但没有全局数据库检索权限。可按需调用“回想”能力，但额外模型轮次要计入费用。

巩固可以形成更短的经验概括，须保留来源与不确定性。概括中的自由文本仍属个人记述；新增、失真或猜测的内容不得被标为系统认证的观察，更不能改写世界中的人物、事件或成功结果。每次回顾不必重写全部记忆，也不自动重写人格。

遗忘先表现为可访问性和细节保持下降；已忘记的细节不再通过引用编号绕回观察者档案。审计所保留的旧版本与原始记录只供研究者核查。若保留了“我以前在河边受过伤”的概括，角色可以记住概括而不再拥有原始细节。

遗忘和保留语义覆盖所有进入上下文的个人资料。短期缓冲会过期；档案摘要、关系说明和目标说明不能长期复制已经失效的事件细节。独立形成的判断、习惯或愿望可以有自己的保留周期，例如仍不信任某人却记不起具体原因；此时只提供该判断，不把隐藏的证据全文重新注入。未完成目标可以保留，但须有独立的回顾、失效或放弃机制，不能顺带永久保存所有背景。组装上下文时统一执行这些规则，审计字段和旧版本不属于角色的可读资料。

遗忘速度与重要性等关系是初始认知假设，不应伪称为自然心理定律。首先验证最基本的身份隔离、来源和连续性，再比较不同记忆机制。

## 10. 一次思考怎样读写

1. 在确定的模拟时刻生成本人身体感受与局部观察，加入短期缓冲。
2. 读取当前档案、心理状态、未完成目标；只从本人的可访问长期记忆里取相关片段。
3. 组成有长度边界的上下文：身份与倾向摘要、实际约束、感知、相关记忆、当前打算与近期交流。保留能影响承诺和未完成事务的必要内容。
4. 调用模型，一次返回行动意图、计划和候选心理更新；可以同时选择记忆、调整愿望及安排下次思考。记忆写入与心理更新不会各自必然增加一次 API 调用。
5. 运行器校验提案的数据结构、所属人、依据、允许范围与世界可执行性。认知状态更新与行动意图按版本保存；实际行动后果只能在世界结算后产生。
6. 到达行动完成或失败时，世界记录结果，角色仅收到可感知的部分。下一次思考可以据此写入经历、修正判断或改变打算。

计划与预计结果只能作为意图保存，不能提前写成已经发生的记忆。一次调用只看到调用前有效的信息，不能把尚未结算的其他角色意图当作已知事实。

### 首版认知运行器

每个人绑定一个 `ActorCognition`，由宿主在游戏更新线程轮询。首次、粗粒度身体变化、任务终态、收到新消息和回顾到期都可以触发思考。同一轮合并触发原因。已有待处理轮次时返回同一份输入，决定生效后才标记已呈现消息，并按决定给出的消息 ID 确认处理。只读消息工具可查看同一份收件箱；长句按实际听到的片段合并，漏听处保留缺口。收件箱保存最多 32 项，优先回收已呈现的消息，未呈现消息溢出计数随下一轮报告。

[上下文组装](../../game/Survivalcraft/Westworld/Cognition/ActorCognitiveContext.cs)按本轮原因选择数据块。档案、身体感受、可用动作、局部观察、当前任务和未完成承诺优先保留。社会、任务终态或回顾轮附带背包；回顾还可读本人所在地的环境。收件箱每次最多展示 6 项，回忆最多 4 条，优先取当前消息、未完承诺或本轮原因相关的个人记述。观察、已送达消息、原生身体状态和任务结果仍各有维护来源。

成功决定可以保留、启动、替换或取消任务，同时更新当前目标、保留一条带来源的记述、增删未完承诺并约定下次回顾。首版最多保存 32 条记述和 4 条未完承诺。私人记述与不可改写的证据分开保存，组装时只展示记述及来源标识。最近一轮的实际输入和接受的决定可从宿主读取。完整心理演化、记忆巩固、跨人物调度及真实模型仍按相关专题推进。接口和隔离场景见[开发与验证](../development/开发与验证.md#人物认知运行器)。

## 11. 谁能改哪些状态

| 内容 | 模型的作用 | 程序的作用 |
| --- | --- | --- |
| 身体、位置、真实持有物和操作熟练度 | 提交行动，自述感受或自我评价 | 依世界机制结算真实结果 |
| 愿望、当前判断和关注 | 提出保留、调整、放弃或新建 | 检查身份、格式、来源和合法操作 |
| 情绪 | 解释本人处境，提出状态变化 | 推进既有状态、身体影响和约定的恢复机制 |
| 长期记忆 | 从本人经历中选择、解释、概括和修正 | 限定来源与读取范围，维护版本及可访问性 |
| 长期性格与基础认知 | 在合适回顾中提出有来源的变化 | 执行预先声明的成长、可塑性与变化边界，不据单次事件自动安排人生 |
| 思考时点 | 安排回顾与可检测的唤醒条件 | 执行调度、基础唤醒和最长间隔，控制 API 并发与预算 |

身体状态、经验选择、心理变化边界和检索策略都会影响角色。不存在完全无假设的认知设计。这里尽量避免的是“某类事件必然对应某个社会选择”的固定脚本；所有机制应可审查、可比较。

## 12. 更新如何提交与追溯

每次状态修订保存：目标字段、旧版本、新值或变化方向、依据的本人记忆/观察、简短说明、生效时间与本次决策标识。影响基础特征的提案还记录累计证据及是否只作暂时自我判断。

只对相匹配的版本提交。重复响应不重复改变情绪、关系、技能或记忆。模型不直接覆盖整个档案；没有变化的部分保持原状。格式或网络故障不成为角色自己遗忘、挨饿或人格变化的原因。

长期记录区分角色的自述、系统参数与观察到的行为。监控中的“他在想什么”显示计划和简短判断，不声称读取了模型完整内部思维。

## 13. 一段具体经历的更新示例

这是虚构设计示例。阿木原本较谨慎，对阿禾的了解不多。一次觅食不顺后，他实际看见阿禾分给自己食物。

| 状态 | 可能的更新 | 是否必然 |
| --- | --- | --- |
| 身体 | 实际吃下食物后，按食物与代谢模型更新能量及饥饿感 | 世界结算决定 |
| 短期感知 | 留下可感知的交接和谈话 | 取决于注意与感知范围 |
| 长期记忆 | 本人选择记住“阿禾在我找不到食物时分给我一些” | 由个人记忆选择决定 |
| 情绪 | 可能感到安心，也可能因先前经历而疑虑 | 由个人处境与解释决定 |
| 对阿禾的判断 | 可能更愿意信任他，也可能暂时观望 | 允许与实际善意不一致 |
| 愿望 | 可能想回报、进一步接近，或继续自己的打算 | 不自动下达回报任务 |
| 总体性格 | 通常先保持原状；较长期回顾再考虑一般信任倾向是否变化 | 不因一次赠食自动改写 |
| 认知与技能 | 不会因为获得食物就提高基础能力或采集熟练度 | 无相关实践就没有对应技能增益 |

几周后若经历多次可访问的互动，个体可以形成或修正更广泛的看法；这仍是个人归纳，不宣称客观世界所有人都变得可靠。后续新经历可以改变这个判断。

## 14. 第一版需要验证的现象

重点检查：重启后仍记得未完成事务；别人没看见的事不会进入自己的上下文；承诺和过去互动会影响后续行为；同一事件在不同经历下有不同解释；短暂情绪不会无故覆盖性格；模型叙述不会直接提高身体或技能；遗忘的细节不会从全局档案漏回；记忆、愿望与人格更新都能追溯到对应个人的经历。

这些能检验架构的一致性与个体连续性，尚不能证明人格、智商、成长或遗忘已经真实复现人类。首版不需要先建立复杂心理学分类，也不需要让用户为 50 人手写完整人生；初始化可生成差异与少量已发生的背景，并明确哪些属于初始设定。
