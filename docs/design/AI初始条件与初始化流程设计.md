# AI 初始条件与初始化流程设计 v0.2

> 迁移保留的目标设计。适用性需按 Survivalcraft 游戏机制重新核对，其中的设计要求不表示当前游戏或 AI 接入已经实现。

## 1. 已确定的内容与推荐开局

用户已确定：50 人，包含男性和女性，从原始部落阶段开始；重点是每个人独立的经历、欲望、性格与认知；共享模型按需思考，不联网，不专门移除预训练知识；初始化后只观察；本轮只设计。

下列比例、年龄分组和物资数量均为推荐的首版实验预设，不是用户逐项确认，也不宣称符合真实史前人口与生活条件。预设目的：既有成长与照料，又有足够可行动成员；已有基础语言、用火与简单工具，但没有指定首领、职业、货币、产权或未来社会制度。

建议默认：25 名男性、25 名女性；一个已有共同生活背景的小群体，在温和季节的清晨开始观测。身体性别用于明确的生理机制，不预先决定性格、认知、职业或社会地位。

时间零点是“开始观测”，不是所有人和生命在宇宙中刚诞生。出生时间与预设背景可以早于零点；这些是声明的初始条件，不伪称此前已经实际运行过完整历史。

## 2. 用户主要需要决定什么

| 项目 | 推荐处理 |
| --- | --- |
| 人数与起点 | 采用已确定的 50 人、原始部落 |
| 人口结构 | 默认采用本文分布，可整体换成另一预设 |
| 环境 | 球面世界上的创始流域，默认周边有水路、林地、草地和石质区域。 [球面地表设计](./AI世界状态与自然演化设计.md#球面地表与区域精度) |
| 开局处境 | 默认资源并非无限，但存在可达水与食物，无预置必然灾难 |
| 模型和预算 | 正式接入与运行前明确供应商、模型、币种、请求及费用边界 |
| 随机种子与规则版本 | 保存明确种子；具体参数由生成器按冻结模板产生 |

不要求用户手写 50 份传记、每棵树或全部初始物品。系统提供生成结果摘要与可检查的完整初始快照。当前未请求实际生成或启动。

## 3. 总流程

1. 固定预设、规则、物种/材料模板、生成器版本和随机流。
2. 生成地形、水路、气候初态与边界条件。
3. 生成植被、食物、动物、材料及其当前状态。
4. 选择符合本次预设的营地候选与活动范围。
5. 联合生成 50 人的年龄、身体条件、出生时间与真实亲缘，避免事后无法满足年龄关系。
6. 生成稳定个体差异、操作经验、熟悉关系及少量结构化开局背景。
7. 给各人分配其能知道的背景与初始记忆，形成稀疏的主观印象。
8. 生成初始物资、实际存放/持有/附着关系、人员位置与身体/短期状态。
9. 执行结构校验、开局约束校验、独立调试检查及运行准备检查。
10. 输出开局清单、风险提示、生成尝试记录和初始快照；冻结后登记第一批真实事件。

生成之间存在依赖与回溯，但不允许无限重试、静默放宽约束或挑选未来最成功的种子。

## 4. 年龄与身体怎样生成

推荐默认年龄配额：

| 年龄段 | 人数 | 目的 |
| --- | ---: | --- |
| 0—5 岁 | 4 | 覆盖早期成长与依赖照料 |
| 6—12 岁 | 8 | 覆盖学习与有限行动能力 |
| 13—17 岁 | 4 | 覆盖逐渐成熟的阶段 |
| 18—39 岁 | 22 | 主要可行动成年群体 |
| 40—59 岁 | 10 | 更长经历与身体差异 |
| 60—69 岁 | 2 | 年长成员与代际联系 |
| 合计 | 50 | 16 名未满 18 岁，34 名成年人 |

先按配额与亲缘约束确定可行的年龄区间，再在区间内采样具体出生时间；整体性别配额是 25/25，不要求每个年龄段也机械对半。成年、成长及生育条件采用已声明的身体模型；年龄范围是设计参数，不作为史实。

身高、体重、可行动能力和有效认知参数与成长阶段相容，并保留个体差异。身体性别相关差异只来自明确的身体机制；不用性别直接派发社会任务或智力排名。

推荐基线无初始妊娠、无马上致命的预设伤病；允许日常饥渴、疲劳和身体差异。若后续采用带伤病或妊娠的开局，作为另一组明确初始条件。无初始妊娠的 30 日短试验未出现出生，不等于生育机制失效。

婴幼儿不获得成年人完整叙事和行动能力。身体反应、依赖照料与允许的简单行为来自成长阶段配置；同一成熟模型仍可能带来超龄知识或表达，这项限制不能仅凭缩短上下文宣称已经解决。

## 5. 亲缘、接触与主观看法分开生成

首先生成真实亲缘：父母、子女、同胞及相关出生时间。亲缘图不得成环，亲子时间满足本版身体生育条件，已去世或未纳入活动范围的祖先可以作为明确的历史背景记录存在，不算额外活跃人口，不拥有隐形行动或资源库存。

然后生成共同生活和接触背景：谁一起生活、谁曾一起做事、哪些人比较熟悉。默认接触网络连通，包含若干联系较密的小簇，但不是人人互相深知；亲缘簇不自动成为婚姻、职业或权力制度。

最后生成各人自己的认识：实际知道谁的名字、如何认识某人、熟悉程度及少量初始印象。主观印象可为空或较弱；同一次经历可有不同理解，不强制双方信任值相等，也不规定亲属必然信任彼此。初始印象记录为种子化的个人状态，不当作世界事实。

对依赖照料的成员，开局给出实际照料背景和可接近的照料者，并让相关成员知道已经发生的照料经历；可以有现有牵挂或未完成打算，但不强制未来一定继续照料。后续选择与后果仍由个体和身体过程产生。

不为保证繁衍自动配对，不为保证合作选出首领，也不为制造冲突指定反派。若设定初始结伴关系，须作为双方已存在的初始关系记录，不能在正式运行里把尚未回应的请求算成同意。

## 6. 性格、认知、技能和初始愿望

稳定倾向从冻结的分布生成：风险容忍、好奇、社交主动性、初始信任倾向、耐挫、等待回报的意愿。默认中间范围较常见，保留差异，不刻意为每人塞一个极端标签，也不把同一组倾向复制成 50 份。

生成机制与分布本身是初始假设。相同种子可复查参数，不根据谁将来更成功重新抽取性格。家族内的认知或性格相似性只有在明确的继承假设存在时才生成，不默认把家族或性别当作智力标签。

认知配置包括基础注意、工作记忆、回忆、规划、学习与处理速度，再通过成长阶段和身体状态得到有效参数。不给每人分配一个声称真实的 IQ；检查的是参数在后续具体行为中是否产生可观察差异。

已有语言、用火和基本生存操作属于共同起点，但操作熟练度与实践背景有差异。儿童、年长者与不同成员各有实际能力，不人人精通全部工具。技能作为初始化的操作经验写入，来源标为开局条件；模型自称擅长不额外提高数值。

初始愿望保持少而明确：身体感受、已有偏好、对熟悉者的牵挂或一个尚未完成的打算。允许没有明确长期目标，第一次正式思考再形成。不给“负责狩猎”“繁衍族群”“发展文明”等未来任务，也不先生成每个人全天行程。

## 7. 初始记忆先有素材，再有个人版本

初始化先建立少量结构化背景素材，如过去认识的地点、一次采集、一段照料或一场交谈。记录时间、地点、参与者、实际发生的基本内容、谁有机会感知到什么。地点与对象必须能对应到初始世界或明确的历史背景。

随后分配个人视角。亲历者、旁观者、听说者得到不同资料；未接触者不获得该素材。记述的解释可以不同，但不能让一个人的自由文本覆盖其他人的背景事实。某人当时尚未出生、阶段不允许或不在场，不能被标为该事件的直接经历者。

推荐记忆规模只是上下文与差异性的工程起点：婴幼儿以照料熟悉与简单感知状态为主，不强塞成人传记；儿童约 2—5 条个人素材；成年人约 5—10 条；年长者可有较多概括而不是完整人生记录。不是年龄越大就必然记得所有细节。

每条初始记忆标注 initial_condition 来源，区分背景假定与正式模拟产生的事件。过去的生长、吃饭或赠食不再次执行，也不重复扣发当前库存。初始实体状态已经结算到零点，背景只解释起点，不假装完整运行过几十年。

默认可以用模板生成基本个人资料，不调用模型。若需要更自然的个人记述，允许每人一轮模型整理，通常最多 50 个主要请求，格式修复另受预算限制。模型只使用分配给本人的素材生成主观记述或印象，不能创建新事实、偷看全体背景或擅自加入现代设施。

零点核查记录主观文本中已存在的规范主张或领导印象，保留为初始信念，不认证为已成立制度。若观察目标是某条规则从无到有，提前排除目标信念已注入的开局或另列分层，不把初始文本中已有的内容当作运行后发明。

模型已有的现代知识不另作清除。上述限制约束的是模拟中的过去事实，不要求为每项常识伪造来源。模型文本可能失真，仍按个人记述保存，不能靠一个合法引用就认证整段文字准确。

若使用模型生成初始化文字，保存精确输入输出与费用；只靠随机种子不能保证再次调用得到同样文本。初始化用量单列，不算成角色在正式世界中经历了多少次思考。

## 8. 地形、资源和营地怎样生成

推荐环境预设是有限的小型流域。区域尺寸、地块尺寸与实体精度独立保存；正式物理面积依据移动、资源与成本模型选择，不以格子数量直接推断可承载人口。

先生成连续地形，再确定低洼水路、边界来水与气候初态，最后按水、光照、土壤与模板条件放置植物和动物。资源呈有原因的斑块与差异，不是每格各放相同食物或给每人旁边刷新一堆。

植物有不同年龄和阶段，只有部分具备当前可采资源；动物有真实身体储备和食物/水依赖。可采石材、木材、种子等有有限来源，地块标签不提供无限库存。模板与初始对象均保存生成来源。

营地在世界生成后选址。基线预设要求：位置可站立，有通向可饮用水的可行路径，存在至少两个可达的食物来源斑块或等效多样来源，以及基础可用材料。可达性按距离、地形和身体模型计算，不凭地图看着很近判断。

这些是开局处境的主动选择，不伪称中立的随机宇宙。它们只保证符合本次开始条件，不保证食物永不耗尽、洪水不发生、50 人必然存活或合作。区域以外仍沿用明确的模拟边界和技术暂停规则。

冻结前列出本次可执行的动作/过程与适用范围、地图范围和边界触发条件、观察终点及未支持机制。独立开发测试记录边界首次触发时点、次数与原因，用于评估下一版区域和能力范围；不能靠挑选不会触边的成功种子掩盖限制。正式运行不得临时扩图或补物理作用，边界截断单列为未覆盖，不能算完成观察窗口。早期一人/少人数探索使用单独标注的简化初态，不伪称满足本篇的正式 50 人配额；其准入按[验收专题](./AI测试验收与演化证据设计.md)执行。

## 9. 初始物品与存放

推荐一份有限且可修改的开局物资清单：

| 物资 | 首版推荐数量 | 注意事项 |
| --- | ---: | --- |
| 简易身体覆盖物 | 50 件 | 尺寸和材料与对应身体相容；作用按已支持材料模型 |
| 石制切削工具 | 12 件 | 有实际组成和质量，不因名字直接具备所有加工能力 |
| 木制采集/掘土棒 | 12 件 | 可使用与实际技能、身体条件相容 |
| 固体携带容器 | 8 件 | 未密封容器不默认能盛水 |
| 可盛水容器 | 4 件 | 实际几何/材料支持容量与泄漏近似，不凭标签生成水 |
| 简易遮蔽物 | 3 处 | 有实际范围、材料、损伤和可用空间 |
| 现有火堆 | 1 处 | 有有限实际燃料与过程状态，不永久燃烧 |
| 干燥燃料 | 一批有限库存 | 质量、含水、材料和位置在清单中明确 |
| 初始食物 | 约 2 个模拟日的需求估算量 | 依据本版 50 人身体模型计算，实际存成有质量与状态的批次 |

清单是工程预设，不是史实或生存保障。食物需求估算须给出口径，不能直接把“够两天”当作物品属性或自动发放机制。

全部物资记为显式开局库存，不伪称已经模拟制造；只有模型支持作用的模板可以放入。若某物品依赖未实现的关键作用，应调整清单或能力范围，不能通过初始化跳过物理边界。

一部分物品由具备携带能力的成员实际保管，另一部分放在营地明确位置/容器中。分配考虑容量和既有背景，不按性别派职业，也不把所有资源集中交给预设领袖。物理保管事实与角色对归属的看法分开，不建立强制共享制度。

容器内容、工具部件和人体附着物只计一次。初始水若存在，记录为实际开局批次，不与河流可取水量重复。食物、燃料和工具在正式运行后不会因“初始应有数量”而自动补回。

## 10. 初始身体、位置和待办事件

人员在营地及可解释的邻近位置分布，身体不重叠到不合法空间，负重与持有相容，依赖照料成员有实际可接触的人与空间。不同成员的饥渴、疲劳和情绪可以有小幅差异，不全员完全一致，也不预设某人第一分钟必然死亡。

清晨这个时点的醒/睡状态属于初始状态；未来生活由个人决定。睡着者按已有身体和觉醒机制继续，没有既定计划的清醒且具备思考能力者进入首轮决策。不能为摊平 API 压力偷偷改变他们的模拟起床时间；若很多人同刻需要思考，按既定并发排队并冻结模拟时钟。

出生时刻、树龄、食物制作时间可以早于观测零点，但所有连续过程的已积分状态须明确结算到零点。不得把“出生于几十年前”当作需要在首次更新时重新计算几十年饥饿和成长。已有火、睡眠或加工过程保存剩余状态与后续检查，不重复扣过去成本。

第一批事件包含身体、环境、动物、行动/睡眠检查及必要的个人唤醒。先建立一致快照与随机状态，再允许任何正式模型决定进入世界。

## 11. 启动检查分四层

| 层级 | 检查内容 | 失败怎样处理 |
| --- | --- | --- |
| 结构与事实一致性 | 恰好 50 个活跃初始人、比例/配额、标识唯一、亲缘无环、出生与背景时间相容、库存非负、单位一致、位置与容器无双计、模板和过程可执行 | 阻止冻结，修复生成器或有界重新生成，记录原因 |
| 本次预设约束 | 营地/水/食物可达、身体与初始物资相容、幼龄照料背景存在、无所禁止的开局即致命处境 | 标为开局预设不满足，不假称程序错误；有界重新生成或修改预设版本 |
| 独立调试与风险诊断 | 在副本中检查水/生长/摄食/分解收支、事件推进、局部感知、恢复、资源竞争与慢更新；报告生态或人口延续风险 | 机制错误阻止启动；自然风险可报告，不自动把所有坏结果修成好结果 |
| 运行准备 | 模型适配、凭证配置、价格与用量口径、预算/重试边界、存储余量、检查点和监控版本能力 | 未具备则不启动正式运行；不能凭配置存在声称网络一定可用 |

本轮只是规定这些检查，没有执行或宣称通过。若将来需要实际 API 连通探测，作为明确的有限测试请求记录用量，与正式角色决策分开。

检查程序正确不等于预测所有人存活。不能为了让文明出现而反复预演 30 天、只保留成功种子；所有拒绝采样和筛选标准在预设中公开，生成尝试数与失败原因写入报告。达到生成次数上限就停下，不能无限后台抽取。

## 12. 冻结和启动

冻结产物包括：规则与模板版本、生成器和种子/各随机流、完整世界初态、50 人档案与实际能力、个人初始记忆、真实与主观关系、背景素材、所有物品与存放、当前过程和队列、模型配置与预算、检查报告及初始状态校验值。

预览可以指出风险或返回修改预设，但每次变更保留版本。冻结之后，未来运行只从这个初始快照开始；独立调试副本的时间、死亡、资源消耗和模型决定不带回正式起点。

正式启动时加载冻结快照，初始化观察流和运行账，发布“观测开始”的元事件，然后按《AI 时间推进与调度设计》处理首批世界事件与个人思考。第一次响应仍需经历模拟认知耗时，不立即兑现行动。

后续有困难不会重新生成更友好的性格、给食物续杯、替人配对或安排首领。改变物理、人口、物资或背景生成要求，应作为新版本/新实验；正常的技术暂停与恢复不重抽世界。

## 13. 初始化预览应该呈现什么

预览摘要：50 人年龄与性别分布、成长阶段与基础能力范围；亲缘与接触网络；每人初始资料和记忆来源样例；地形、水路、资源斑块、营地与可达范围；完整物资数量、组成和位置；初始过程与首轮可能需要思考的人数；模型初始化是否调用及其用量；检查通过项、风险与未建模边界。

初始状态标明哪些由规则推导、哪些随机生成、哪些明确指定。人物可能选择什么、谁将成为领袖、未来是否繁衍和存活，不作为初始化输出的承诺。

本方案允许生成器完成繁琐数据工作，但不把“生成器输出了 50 份文件”当成整个世界已运行或人格已形成的证明。
