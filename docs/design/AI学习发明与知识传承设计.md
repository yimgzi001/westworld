# AI 学习、发明与知识传承设计 v0.1

> 基于 Survivalcraft 的目标设计，尚不表示已实现。游戏复用范围、根本驱动力和运行额度以[设计总览](./AI部落文明模拟-设计草案.md)为准；专题中的新增机制按能力清单逐项接入，不要求先重建一套世界。

游戏版先复用原生物品、配方、工具耐久、挖掘与放置。个人学习先体现为方法记忆、任务步骤和行为修正；新增数值熟练度与任意材料/结构加工需另行实现验证。下文涉及开放制造、操作误差和记录载体的“首版”是相应扩展的候选方案，不要求先重写原生生产系统。

本方案衔接个体状态、行动、世界、身体、调度与社会关系设计。用户已确定接受基础模型原有知识、不联网、不专门设知识门槛；本设计保持这一条件。下面的学习速率、技能结构与加工近似是建议，尚未经真实人体或历史资料校准。

## 1. 学习由哪几部分构成

建议采用“私人知识与方法记忆＋引擎中的实际熟练度＋真实对象与使用反馈”。不引入部落共享科技值、时代解锁、统一知识库或负责宣布发明成功的总智能体。

| 层 | 例子 | 由谁更新 |
| --- | --- | --- |
| 个人判断与方法 | 我认为这种连接更牢；我记得先做哪一步 | 本人根据可知经历提出，按记忆机制保存 |
| 实际熟练度 | 操作精度、稳定性、某类动作的熟练程度 | 引擎根据实际练习与声明的学习模型更新 |
| 物理产物 | 一件真实工具及其材料、结构、连接、损伤 | 世界加工过程结算 |
| 已发生的效果 | 实际切下多少、花多久、何时损坏 | 实际使用与测量过程结算 |
| 观察者解释 | 首次观测到某结构、某方法传播给几人 | 从已记录事实计算，不能反向授予能力 |

这使“会说方法”“能稳定做出”“实际有用”“别人也能复现”分别成为可观察的事情。角色可能懂一些步骤却操作笨拙，也可能手很熟却讲不清原因。

本系统中的学习不更新基础大模型权重。长期变化体现在个人可读取的记忆与方法、计划习惯、实际熟练度，以及世界里的工具和记录。现代知识或点子可能直接来自模型原有能力，不要求伪造一次本世界中的发现经历。

## 2. 怎样存储，仍与个人档案和记忆衔接

实际熟练度仍归世界引擎维护；私人知识、方法和假设是长期记忆与个人摘要的结构化视图。它们引用同一份个人内容和可访问性状态，不另建一套永不遗忘的秘密知识文件。

| 逻辑内容 | 建议字段 |
| --- | --- |
| 熟练度分量 | 人物、操作/情境范围、基础熟练度、累计有效练习、保持状态、最后结算时刻、来源事件与版本 |
| 个人知识判断 | 本人的表述、适用条件、确信、亲历/听闻/推测/已有常识等来源、支持与反例、保留和修订状态 |
| 方法记忆 | 本人的步骤概括、材料要求、已知注意事项、适用情境、当前可回忆细节、来源、失败记录 |
| 试制打算 | 本人目标、设计假设、候选结构、拟执行的有限步骤、准备观察什么；尚未实现的内容始终是意图 |
| 实际加工/练习过程 | 参与人、动作与时间区间、真实输入、操作进度、实际误差、反馈暴露、输出与损耗 |
| 世界内记录 | 实体载体、真实痕迹、占用容量、清晰度、制作与损伤过程；作者意图单独保留作审计 |
| 观察者传承索引 | 实际接触与消息链、被提供给模型的内容、练习和复现记录、口径及不确定性 |

知识条目的确信是个人态度，不是引擎授予的正确率。支持证据必须在本人已接触的信息范围内，来源合法不保证解释正确。一般常识不必有虚构的个人发现来源；对本世界具体对象的隐藏性质，仍不允许从全局存储读取。

“他懂这个方法”若只来自角色自述，显示为自述；真正的操作能力以实际行为记录与引擎中的熟练度分量为依据。观察者能看实际参数，角色输入只得到本人可感到的表现和自我判断，不能用精确能力面板泄露隐藏答案。

## 3. 技能怎样通过练习变化

首版为已经支持的动作定义少量可复用分量，例如操作控制、材料加工、连接、追踪和辨识。技能作用范围应有操作、材料类别、工具或情境标签。不是每创造一个名称就新增一项能改变世界结果的万能技能，也不把熟练度当作科技等级。

一次实际练习中，按动作与个人参与程度计算有效练习量。建议的未校准更新结构是：

**熟练度增长速率 = 学习速率 × 本次身体/注意可用度 × 可获得反馈系数 × 练习匹配系数 × (1−当前熟练度)。**

基础熟练度取 0—1；速率按模拟秒计，其他修正为有界无量纲值。在有效练习时间上积分；若一段内各修正固定、其乘积连同学习速率记为 K，可用 **新熟练度=1−(1−旧熟练度)×exp(−K×有效练习时间)**，避免大步长直接越界。有效时间只包含本人实际参与的相应操作，不能在睡觉、等待别人制作或 API 排队时增长。本次身体可用度来自身体模型，不再对同一缺觉/脱水原因重复扣几次。

同一操作分摊到多个熟练度分量时，练习权重有总上限，不能给十个别名都增加完整练习量。身体动作与注意相容性沿用行动协议，不能靠同时声明多门练习获得多倍时间。跨情境迁移只采用规则版本内冻结的有限关联；学会连接一种材料不等于掌握所有材料。

失败也能提供练习和可感知反馈。成功与否不直接作为唯一加分开关；反馈系数来自本人实际感到的接触、结果和操作差异，不读取只有观察者知道的内部失败原因。极简单或远超当前操作能力的尝试可以有不同学习速率，但不得依赖隐藏的最佳解给角色提示。

同样动作持续练习可有递减收益，仍可能维持熟练；没有接触材料、只是不断说“练习”，不会增长。动作拆成多次请求不会额外奖励。积分采用有界或可组合的速率求解并设置误差容限，更新量绑定实际时间区间，保持对时间切分近似一致。

动作执行在区间开始使用当前技能与身体条件，产生真实进度和反馈，再提交该区间学习变化；长过程可在后续区间使用逐渐变化的技能，不追溯让初次操作变熟。保存恢复不得重复领取练习增量，随机误差按动作/物理阶段而非模型请求次数取样。

长期不用时可以有缓慢、分情境的保持变化，必须有明确的时间速率。基础熟练度、年龄相关身体能力、当前疲劳和方法是否还记得分开：疲劳或手伤不删除原有熟练度；忘记一次练习的经过也不必立即失去操作能力。熟练度参数不能反向提供已遗忘方法的完整步骤。

## 4. 技能怎样真正影响操作

熟练度应进入具体过程，例如影响允许范围内的控制误差、无效动作比例、单位进度耗时和可达到的精度。实际结果仍由投入、身体、工具、材料和环境共同决定。

一种可用近似是：本人选择目标操作参数，引擎根据熟练度与身体可用度生成有界的实际操作偏差，再用材料和结构规则计算变化。确定条件直接计算；只对已声明的不确定部分采样，不能统一用“熟练度就是成功概率”代替全部物理。

初学者可以尝试已支持的动作，不设“达到五级才允许制作”的任意门槛。真实的身体能力、接触、工具、时间与精度需求仍能限制结果。高熟练度不能把缺失材料变出来，错误方法也不会因等级高就变正确。方法改进主要改变本人选择的步骤和参数；练习进步主要改变执行这些步骤的表现，两者不可重复发放同一收益。

技能系数不是人体运动神经系统的完整模拟。它提供可检查的表现差异，而不声称基础模型已经在内部重新学会了低层动作控制。

## 5. 发明怎样从想法变成工具

建议的循环是：**遇到需要或产生兴趣 → 提出假设/结构 → 找到材料 → 实际加工 → 实际使用 → 感知反馈 → 保留、修改或放弃。** 这是可发生的链条，不要求每个人都像实验员一样执行固定步骤。

模型可以提出新的用途、工序或材料组合，不要求先在配方表里存在该物品名称。可执行部分必须表达成已支持的通用操作：改变形状、敲击/切削、连接/拆分、加热/冷却、搬运、修补和测试等。自由文字中的“制成坚不可摧的工具”只是愿望。

物理模型使用既有材料属性、粗粒度形状、边缘/接触特征、连接方式和状态计算效果。例如一件有柄刮削工具需要真实的工作部分、柄与连接；组合完成后，连接承载是否足够、使用时是否松脱仍由结构与载荷近似决定。改名、写用途标签或宣称发明成功，不直接增加效能。

模型可以估计材料强弱，但这些估计只属于个人判断，不能写回材料模板。新对象使用既有材料与连接实例组合产生，不因为产物“很新”就能追加未经定义的物性或世界规则。

每段加工都消耗实际时间与资源，产出半成品、成品、边角料、损坏或可回收部分。半途停下，已加工状态保留；拆解不得同时退回全部材料并保留完整产物。共同制作按实际投入计算，旁观者不自动取得同样熟练度或成品。

只有角色已经提供的有限步骤与可执行分支可以由运行器继续；“不断改进直到成功”不能授权程序替本人设计新方案。新问题或新策略需要正常思考，调用及时间成本按原调度方案计算。

## 6. 成功与失败由什么决定

至少区分四种结果：

| 结果层 | 谁能判断及依据 |
| --- | --- |
| 加工过程完成了什么 | 世界结算实际材料与结构变化，可能部分完成或失败 |
| 某次使用发生了什么 | 世界结算实际作用、耗时、损耗、损伤和产量 |
| 我是否满意、原因是什么 | 本人依据自己可感知的反馈解释，可以误判 |
| 是否比旧办法更好或可复现 | 观察者按声明口径比较已有事实；角色须自行观察、交流或测试 |

“做出外形”不等于“有用”，“用过一次”不等于“长期可靠”。工具也可以在不同任务、身体、环境和材料上表现不同。测试需要实际对象、时间、操作与可能的损耗，不能免费查询隐藏强度、寿命或完美配方。

角色可自行安排比较，例如用两件工具处理相似材料，看实际进度与损坏；也可以只凭一次体验过早下结论。程序不强迫使用对照试验，也不因为某人想知道原因就提供全知诊断。看到连接松脱可以产生相应感知，内部尚不可见的损伤或缺陷不提前告知。

程序只核验可表达的完成条件和实际结果。自然语言目标如“更顺手”“更美”可以由本人评价；它们不变成世界的统一成功分。目标是否达成、为什么达成也可能在多人之间有分歧。

技术错误、有效失败与模拟器边界沿用既有行动协议。已支持机制中的有效尝试按真实过程结算成本；格式/API 故障不变成练习失败。关键作用根本未建模时，在一致提交边界保存并暂停整个世界，不临时请模型裁定、不把未实现的作用判成自然界不可能。新增机制属于新版本实验。

## 7. 经验怎样变成自己的知识

实际行动后，本人能感到的结果进入短期缓冲。下次正常思考可选择保留具体事件、形成方法概括、提出原因假设、降低确信或修订旧判断。可以同时返回下一步行动，不为每条知识另发一次 API 请求。

例如“这次连接松了”可以来自感知；“可能是连接太松”是解释；“下次改变某个做法”是意图。三者分别保存，不能用一个成功标签把推测认证为规律。失败经验也可以被记住、误解或忽略。

方法记忆允许保留材料要求和有限操作步骤，后续在相容情境中由本人选择复用；具体动作开始时仍重新检查实际前提。记住方法不自动拥有材料、工具、身体能力或熟练度。环境变化或材料不同时，旧办法可以失效。

同一案例反复回忆可以改变保留状态和个人解释，不能凭空增加物理练习时间。反思能够形成更好的计划假设，但不能直接提高所有操作熟练度或从隐藏日志读出真实原因。

可执行方法保存所属人、来源经历、版本、所需材料与工具、有限步骤、参数范围、适用条件、停止/失败出口及实际验证记录。只有能映射到已支持动作的方法才交给执行器；自然语言打算仍为打算。方法改进保留旧版本与验证结果，未验证方法也可尝试但不能标为可靠。

共享采集或建造执行代码不等于所有人知道同一蓝图。个人取得方法需要本人已有知识或真实教学、观察与记录；他人的新方法不自动进入公共技能库。社会协商与组织经验也可形成私人方法记忆，不限于生产工艺，仍不取得控制他人的权限。

## 8. 教学、模仿与共同练习

教学仍由双方独立行动。老师愿意教、学生愿意听、真的听到、看见关键操作、记住并能复现，都是不同事情。指导内容可正确、模糊、错误或故意保留。

口头讲解通过真实交流传播；演示通过实际加工和观察传播。看得见成品不代表看见了全部工序；旁观时的角度、距离、注意、身体和遮挡影响可获得内容。不能把老师的私人方法文件或隐蔽步骤自动放进学生上下文。

学生可以把收到的说明保存成听闻或方法记忆，下一次操作因选对步骤而表现改善。但不会复制老师的熟练度。操作控制的练习增量只来自学生自己实际参与的动作；若定义辨识/观察类技能，其练习必须对应真正发生的感知活动并按该类技能模型更新，不能顺便给手部制作涨同等经验。

共同练习和协助需要真实时间、材料和出力，老师不因“教学动作”自动替学生完成。老师指出的错误只能基于自己看见、听见或实际测得的信息；双方都无权读取隐藏物理真值。

重复练习、复述或独立复现，可以让错误和遗漏通过真实反馈暴露；也可能一直没人发现。对老师的信任影响是否愿意听和相信，不强制决定实际掌握程度。名气和教导人数不直接生成客观教学质量加成。

## 9. 工具、记号与文字怎样承载知识

实物本身可以提供线索：别人能观察形状、连接、磨损或尝试使用，进而模仿、拆解或产生新假设；看不到的内部结构与制作过程仍需实际探索。只拿到工具不自动下载制作者的记忆。

世界内记录必须有真实载体与痕迹，使用支持的刻划、描绘、摆放或书写操作，占用材料、可见空间与时间。首版可用符号单元与粗粒度清晰度近似痕迹，不承诺已实现完整图形和光学模拟。长度、容量、制作速率和损坏规则须冻结，不能在一小道划痕里免费附上一整本说明书。

引擎可保留作者打算表达的内容用于审计，但读者只收到实际观察到、仍清晰的符号或形状，不能直接取得隐藏的 intended meaning。可辨认的文字呈现实际文字，未知符号呈现可见形状/稳定记号引用，不把私人意义表自动翻译给读者。符号约定可通过实际教学和经历形成，接收者也可以猜错。

沿用已接受的预训练知识条件：若模型本来就认识实际呈现的文字或图示，可以理解，不额外设置“识字科技未解锁”门槛。这不等于本世界的人已从零发明了文字；初始共同口语也不自动证明有过书写传承历史。

记录会受风化、破坏、移动、遮挡和遗失影响。修复和复制需实际观察与制作，复制可能遗漏，不能从作者意图字段或观察者备份无损恢复。写一份记录不等于所有人都读过；同一载体也不是全局可检索知识库。

角色的宿主文件仍不属于世界物品。模型没有读取死者档案、全局审计日志或任意系统文件的工具；世界里的“读记录”只能针对实际接触和观察的对象。

## 10. 后代怎样继承，知识怎样失传

新生儿有独立身体和个人经历，不复制父母的知识、熟练度、方案或关系。成长开放相应动作与表达能力后，通过实际接触、讲解、示范、练习以及接触遗留工具/记录积累经验。

照料者、亲属、其他熟悉者都可能教学，是否愿意、能否接触、孩子是否注意和记住由实际过程决定。没有“父母去世便转移一半技能”的结算。成熟基础模型的既有能力仍是实验限制，不能假称真正从零发育。

一项做法可以分散在不同地方：有人记得步骤，有人会操作，有人保管工具，某块载体留下说明。是否能重新实现，要看这些人和物能否实际汇合、交流、取得材料并完成操作；程序不把分散片段后台自动拼成公共完整配方。

传承链可以失真、改良、被保密或中断。若掌握者死亡，其他人未学会且没有可用记录，这条在世界中形成的传承可能断开。遗物仍可能提供线索，让后来者重新尝试。实际熟练者消失、方法记忆消失、载体不可读和暂时缺少材料应分别记录，不统一叫永久失传。

因保留基础模型知识，不能保证某概念从所有个人经历中消失后再也没人想到。此处的“失传”只指可观测传承或实际复现能力中断，不能据此声称模型内部的信息已经被删除。

群体会影响传播机会：合作让人更容易示范，冲突可能让人不愿教，迁徙带来新接触，排斥也可能阻断传播。但这些通过人的选择和实际接触产生，不给某个族群名称内置学习速度或科技加成。

## 11. 监控中怎样区分发明、传播与积累

建议面板显示：个人方法与确信；实际熟练度及练习来源；工具结构和使用记录；失败及边界暂停；实际教学和传闻链；记录载体状态；后代接触与独立复现情况。

“发明”不能只靠说出名称。可分别标注本次观测历史首次提出某想法、首次做出某结构、首次完成某项实际用途、首次被另一人复现。初始物品与背景已有做法单列，不能冒充运行中的发现；外形不同也不一定构成功能创新。

对方法和结构的相似性可以采用可解释的属性比较与人工/报告辅助分析，但不能假称存在精确通用的新颖性裁判。分析标签不开放新动作、不加技能、不广播给全体角色。世界里的称赞、命名或争夺发明归属仍要由实际交流产生。

传承指标可以逐级区分：

1. 确实接触过相关讲解、演示或记录。
2. 本人当前保留了相应内容，或明确声称理解。
3. 本人参与过相关练习并有实际表现。
4. 本人在另一次实际尝试中独立复现了声明的效果。
5. 后一代在真实材料和身体约束下仍能复现、修改或继续传授。

每项指标声明口径，不用“全族已掌握”覆盖只听过的人。长期实验可比较实际产出、耗时、损耗、可靠性、传播覆盖和中断，不能仅用方法条目变多证明文明进步。

系统保存谁接触过什么、哪些记忆提供给了哪次模型请求、输出是否引用以及后续行为。这证明信息路径和相关性，不证明某条知识就是模型内部决策的唯一原因；没有读取传承信息而重新提出类似点子，也不能强行归到某位祖先名下。

## 12. 调度、费用与一致性

练习、加工、使用和教学演示使用原有动作与身体过程，不需要每个敲击或每个学习增量调用模型。本人可给出有界重复计划和可感知停止条件，执行器只推进已明确的步骤；需要改变假设或设计时，再进入正常思考。

一次响应可同时返回方案、下一步动作、待保留记忆、方法修订与注意条件；不会因创建一条知识另发一次请求。教学双方按各自决策调度，老师不能用一次调用替学生理解、接受和作答。

拟议发明、方法和记忆更新经过正的模拟思考耗时后才安装；已返回的计划不等于工具已经制成。加工结果、学习增量、材料账、反馈与事件标识一起按实际时段提交。API 等待期间的练习、成熟、物品产出与教学仍由游戏推进的模拟时间和实际动作结算。

新方案不能为额外抽操作随机数、免费重试或重复获得学习量提供捷径。实际重做需要实际成本；网络/格式重试只处理技术请求，不回滚已发生的材料损耗。检查点保存半成品、练习累计、方法可访问状态、随机过程与待安装决定，恢复不能重复发奖。

## 13. 后续实施与校验范围

正式运行前需冻结：少量初始熟练度分量和作用范围、学习/保持速率、实践到技能的权重映射、反馈与身体修正、操作误差模型、加工与连接属性、可表达几何精度、记录的容量/速率/清晰度模型及观察指标。这些由实现方案提出可检查的默认值，不要求用户为每件工具写配方、为每个人写教案。

以下是后续验证场景，当前未执行：

| 场景 | 应核查的结果 |
| --- | --- |
| 只说学会、只听讲或只旁观 | 不复制别人的操作熟练度；保留内容有实际接触来源 |
| 成功与失败的实际练习 | 都可依据真实反馈变化；重复请求、拆分动作不免费加倍 |
| 新名称、老结构；新结构、原材料 | 名称不加属性；组合按原机制结算，无科技树解锁 |
| 错误方法与高技能 | 高技能不把缺失材料或不成立的作用变正确 |
| 部分加工与重新拆解 | 半成品、残料与损耗保留，无输入输出重复 |
| 疲劳、手伤与恢复 | 当前表现改变，基础熟练度及已有方法不被随意覆盖 |
| 教学遗漏、错误和误解 | 学生只接触实际内容，不能获得老师私人资料或隐藏原因 |
| 读刻痕与记录损坏 | 只呈现实际可辨认痕迹，不读取作者意图或恢复未见原文 |
| 出生、死亡与传承中断 | 后代不自动继承；遗物可存续、可再探索；不声称删除预训练知识 |
| 更换步长、API 排队和存档恢复 | 学习量近似一致、现实等待不算练习、已提交增量与产物不重放 |
| 关键作用尚未建模 | 技术暂停并保留边界，不能伪造自然失败或由模型临时写物理 |

这一阶段定义可连续学习、试错和传承的机制。是否出现有效改进、是否保留下来、是否跨代延续，必须等真实模拟记录来回答；不会预先安排技术路线或保证文明持续进步。
