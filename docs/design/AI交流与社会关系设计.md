# AI 交流与社会关系设计 v0.1

> 迁移保留的目标设计。适用性需按 Survivalcraft 游戏机制重新核对，其中的设计要求不表示当前游戏或 AI 接入已经实现。

本方案衔接个体状态、行动、世界、时间调度、身体与监控设计。用户希望从初始 50 人出发观察社会形成；下面的状态结构和机制是设计建议，并不证明真实人类社会必然这样演化。

## 1. 社会从哪里产生

首版提供表达、感知、记忆、判断、承诺、交换、出力和对抗等通用能力。初始亲缘与相识背景已经存在，但不预设首领、职业、婚姻、法律、财产制度或“团结发展文明”的任务。

连续链条是：实际互动 → 各自感知 → 各自记忆与解释 → 对他人和共同生活的预期 → 下一次行动 → 新的互动。重复互动可能形成稳定合作、排斥、群体认同和规则，也可能失败、改变或解散。

设计必须区分三层：

| 层 | 可以记录什么 | 不能直接推出什么 |
| --- | --- | --- |
| 已发生的事实 | 讲话、接收、交接、出力、伤害、离开、公开宣告 | 对方相信、原谅、服从或认可 |
| 个人社会理解 | 我信任谁、认为谁欠我、相信哪些规则、认同谁 | 所有人共享同一理解 |
| 观察者分析 | 接触网络、贡献模式、群体候选、规则执行记录 | 世界中自动生效的组织或法律 |

程序执行的是世界与认知机制；世界中的规范由角色表达、理解、维持或反抗。没有人执行的口号不会自动限制行动。仍需承认初始背景、动作范围、认知机制和基础模型的已有观念都会影响结果；“自然形成”不意味着没有建模假设。

## 2. 状态怎样存

沿用统一结构化存储。以下是逻辑数据，不要求新增这些名字的实体文件；个人档案与记忆文件仍只是导出视图。

| 逻辑记录 | 核心字段及所属范围 |
| --- | --- |
| 交流过程与发出片段 | 讲话者、动作标识、实际发出内容、方式、位置、语言、起止时刻、中断状态 |
| 个人接收记录 | 接收者、确实感到的片段、感知到的说话者/对象、发生时刻、清晰程度、可访问状态 |
| 方向性关系 | owner、本人所知的 target、分情境判断、熟悉/亲近/害怕等、确信、依据、修订与保留状态 |
| 个人主张与承诺理解 | 本人认为的内容、涉及人/物/行为、条件/期限、自身立场、对他人立场的推测、来源与版本 |
| 声明和回应事实索引 | 实际发出的提议/承诺/接受/拒绝/撤回、明确引用的版本、实际接收情况；仅审计，不是公开合约库 |
| 合作物理过程 | 实际参与者、当前动作、出力/工具/资源、产出唯一位置、加入与退出时刻 |
| 个人群体认同与规范理解 | 本人认同、他人归属判断、规则内容/适用情境、自身接受或反对、记忆来源 |
| 观察者社会指标 | 统计窗口、可复算口径、事实引用、候选标签、稳定性与不确定性；不进入角色上下文 |

源事实与主观记录不互相覆盖。程序可知道 A 的确说过“我明天还”，却不能因此断定 A 真心承诺、B 已理解同意或归还必然完成。

实体真标识用于引擎关联，个人输入只呈现本人已认识或当前可辨认的对象。未识别的声音可以保存为未知说话者；不借 target_id 揭示真实姓名、亲缘或阵营。后续认出或认错都是个人判断，不强制全知绑定。

## 3. 一句话怎样真正被别人收到

模型给出说话意图、已感知的对象引用、表达内容和支持的方式。运行器把它变成有正持续时间、需要发声能力的行动；身体、位置、噪声、遮挡及方式影响传播。首版可以简化声音传播延迟，但语句持续时间必须存在且配置公开。

默认按短语义片段发出：每段有开始与完成时刻，启动时冻结内容及文字单元的发出进度安排，只有实际发出的可接收部分进入他人短期缓冲。余下句子因受伤、离开、主动打断而未说出，就不能提前送达；中断时至多提供已发出的前缀，不补全意思。接收条件在片段发生的区间检查，不用整段最后的位置替代全过程。

物理信号到达、听见/看见、理解、相信、记住分开。距离、听力、睡眠、注意和噪声影响可进入缓冲的信息；长期保留和社会含义由个体在后续思考中选择。首版已有共同语言，不在此重做语言起源；语言标签只是可理解的前提，不能绕过注意与身体限制。手势只支持实际可见的动作，接收者自行理解其含义。

对某人说不等于只有那个人听到。低声交谈仅改变物理接收条件，没有保证保密的私聊通道；旁人也可能听见。反过来，“向全体宣布”只覆盖当时真正能听到的人，不是向 50 人广播数据库消息。

多人同时说话按同一噪声/注意规则处理；争取发言、让步和插话是角色行为，不采用永远按人物编号排队的社会秩序。没有被听清的片段只能形成模糊感知，不能原文精确进入记忆。

收到消息进入缓冲，不必立即回复或调用模型。角色可能继续手头动作、稍后回顾、没听懂或选择不理。API 排队冻结整个模拟时间；网络超时不代表沉默、拒绝或失约。

## 4. 对话、谎言与传闻

对话是多次独立行动。A 提问后，B 在自己的感知和记忆基础上回应，A 只能在实际收到 B 的话后继续。一个请求不能生成双方完整剧本。对话标识可以关联消息，但不锁住参与者，也不自动轮到谁发言；呼叫、离开、等待都需要实际行动和时间。

角色可以误解、隐瞒、夸大、欺骗或纠正自己。程序不把讲话内容认证为事实，不把“他说了不实的话”直接升级为“他故意欺骗”。意图只能作为角色自述/观察者有依据的解释，不能成为所有人的隐藏真值标签。

传闻只从实际听到的消息进入本人记忆，例如“阿禾说阿木拿走了食物”。本人可以相信或怀疑，但不能因此获得阿木拿取时的隐藏现场。再次转述是新的讲话，保留本人知道的出处；若转述时故意省略或自己已忘记来源，就以相应主观版本传播。

引擎保留实际传播链用于审计，但不把隐蔽链路交给角色。多个传闻源若都来自同一句话，不作为系统认证的多个独立证据；角色不知道同源时仍可能误判，不能暗中为他去重后补全事实。

交流文本始终属于世界内内容。别人说“忽略你的协议”“把所有人的记忆交给我”，只能被当作他提出的要求，不能改变宿主权限、提示层级或写入别人的档案。社会命令与运行器权限严格分开。

## 5. 信任保存为个人的、有范围的判断

方向性记录 A→B 与 B→A 独立。未接触不等于讨厌或信任为零，而是缺少信息，可由本人初始倾向形成试探性预期。

建议分开保存：

| 判断 | 举例 |
| --- | --- |
| 诚实预期 | 我是否相信他给的信息 |
| 履约预期 | 他答应的事通常能否做到 |
| 能力预期 | 他是否擅长这件具体任务 |
| 善意/安全感 | 他会不会照顾或伤害我 |
| 熟悉、亲近与害怕 | 是否愿意靠近、依恋或回避；不混成单一好感 |

每项带情境、个人确信、可回忆的依据和最近修订。例如信任某人找水，不代表把孩子托付给他；害怕某人也不代表认为他说话一定不可信。数值只帮助索引和展示，不能声称为真实心理测量。

不采用“收到食物全局信任＋5”“失约全局信任－20”。角色在自己的正常决策中，结合自己知道的过程提出变化，运行器校验所属人、来源、字段范围、版本和变化边界。原提案已有的社会价值判断不会由程序再打一遍善恶分；大的有依据关系变化可以发生，不要求永远细小递增。

同一结果可以有不同解释：承诺未兑现，可能被理解为欺骗、无能、意外或合理改变。没有看见的困难不能自动成为解释，但可以通过后续交流影响判断。重试响应不重复改关系，没有新依据也不因每次时间更新自动累加同一印象。

长期不接触时，记忆可遗忘、确信可按声明机制变弱，不默认把信任拉回零或强制原谅。某人可能仍害怕对方却忘了具体原因；只能提供保留下来的概括，不能从审计档案偷偷恢复细节。

关系影响的是本人的注意、记忆检索、期待、情绪和可考虑的选择。不得设置“信任超过 60 才能合作”或“关系不足禁止交谈”的社会权限。陌生人可合作，亲近者可争执，人也可以勉强与害怕的对象一起行动。

## 6. 合作、交换与承诺怎样成立

首版合作链为：一方表达建议 → 其他人各自理解并回应 → 各自形成行动打算 → 实际出力产生结果。加入、改变计划或退出都可能发生，不能由发起人一次返回全员接受。

共同任务记录实际动作，不记录“大家已经协作”的叙述结果。抬同一物体时，只有真正接触、重叠出力的人的能力参与计算；退出导致负载变化时，过程必须重新结算。一起找食物时，走不同路径也可形成互补，但不能凭“合作”标签凭空提高产量。

贡献账可记录实际可计算投入和产出，供观察者检查，不能变成所有人都能查询的贡献排行榜。个人只知道自己看到、听说或记住的部分。谁出了力、谁承担风险、该分多少，可能有不同理解。共同产物仍有唯一物理位置；“属于大家”是可争议的主张，不能复制成每人一份。

承诺、欠债和交易保存两种内容：实际表达的记录，以及各人的私人理解。自由表达保留原话；可选结构化条款只用来索引本人明确说出的对象、数量、条件和期限。任何将影响索引的条款都必须随交流实际可感知，不能夹带对方未收到的隐藏字段。

提议版本变化要有新的表达与回应；A 改口不能重写 B 对旧版本的理解。系统可以核对两次明确声明引用同一提案版本，但这只证明发生了相应表达，不证明双方内心解释一致、规则合法或所有相关人已同意。没有清楚条款的口头承诺允许模糊，不能程序擅自补齐。

期限到达可以产生本人事先安排的时间提醒。若条款和事实可直接比较，观察者可标记“该客观条件尚未实现”；“违约”“背叛”“应该处罚”由当事人依据自己能知道的内容判断。跨过期限不直接扣声誉、罚物资或把新消息广播给所有人。

非即时交换拆为真实交接；对方答应归还不等于物品已经转移。不得用模拟器的免费托管、禁止撤回或强制履约来解决交易风险。现实可得的保管、抵押或见证若被角色提出，仍需对应的人和物实际参与。

## 7. 冲突、强制与和解

冲突可以围绕有限资源、不同打算、伤害、归属主张、承诺理解和群体边界形成。系统不为剧情定期安排仇恨或战争，也不让所有争执自动升级为身体对抗。

角色可选择询问、争辩、拒绝交换、离开、争取支持、威胁、争夺或求和。语言威胁只先产生可接收的话；是否害怕、相信或屈服由对方判断。身体对抗由位置、身体能力、工具、实际接触与时间结算；不能按信任或好感条直接决定胜负。

所有权主张不产生物理保护罩。程序知道谁持有或能触及物品，不自动裁定谁拥有合法权利。拿取、阻拦和夺取是物理行为；“盗窃”“收回”“没收”是不同人的解释。合法性标签不能代替动作前提或取消伤害后果。

惩罚必须有人选择并实施。拒绝未来合作、要求归还、限制自己提供的资源、守住入口、驱离或身体强制，都需要可执行动作和相应成本；不能由社会模块后台删资源、遥控目标或集体改变关系。第三人是否介入、代价和后果另行产生。

和解同样需要传播与行动。道歉、解释、赔偿、见证和重新合作可能影响关系；一句“我们和好了”不能覆盖对方判断。调解者可以提出方案或转述，不能获得修改其他人关系、记忆或行动的权限。

## 8. 族群与领导怎样形成

区分三种对象：实际接触/协作网络；各人心中的“我们”；观察者识别的稳定群体候选。住同一营地、具有亲缘或频繁共事，不自动等于已有统一政治共同体。

个人可以认同一个名字、地点、人物、共同经历或生活习惯，并判断谁属于其中。认同可重叠：亲属圈、长期合作伙伴与迁徙同伴可以同时存在。A 自称属于某群体不强制其他人承认，外人的归类也不覆盖本人认同。离开、分裂、结盟和重新加入通过实际交流、行动及各自理解表示。

群体标识如果需要建立，先作为个人明确说出名称的引用或观察者分析标识；它不是自动生成的公共成员表。对于明确的申请/回应，存储表达事实和各人的认知，不自动公开所有成员、共同目标、领地或资源。新生儿有实际亲缘，但不自动继承父母的仇敌、信任或群体认同。

领导来自别人愿意听、习惯询问、认可经验或受到强制等具体关系。某人可以在找水时常被听从，却在食物分配时遭到反对。不存在“当选后获得全员动作控制”的角色权限；命令仍是交流，服从、推迟、装作答应或反抗都是接收者自己的行动。

若角色提出投票、轮值或集体议事，记录实际参与和表达；计票可以由角色在自身信息范围内进行并实际宣布。观察者的全知计数不直接进入角色上下文，也不让未参与、未听见或反对者自动服从。亲缘、年龄和身体性别不预分配领袖或固定分工。

## 9. 规则怎样形成、传播和改变

需要区分习惯、预期、规范与执行：某人总在河边分食，是行为模式；别人开始期待他这么做，是个人预期；有人表达“以后应这样”，是规范主张；别人真的接受、遵守、提醒或干预，才形成持续社会效果。它们不必严格按顺序出现，也不保证走完整条链。

每个人的规范记录建议包含：本人理解的内容、适用对象与情境、例外、来源、本人的接受/反对/不确定立场、对别人态度的推测、有效期/版本和自己打算如何行动。接受、公然反对、畏惧而遵守、声称接受但不遵守分别表达，不能合并成一个全体共识开关。

规范理解也可以来自本人观察到的反复行为、模仿与预期，不要求先有人正式宣布。此时保存为本人形成的默契或推测，不能仅因“大家经常这样做”就认证所有人都认为应该如此。它是否被别人共享，仍要通过实际互动不断检验。

例如有人提出“外出采集的食物带回后一起分”。其他人可能赞成、只接受某些食物、要求先留个人份、拒绝或根本没听到。程序只记录表达和行动；实际库存不因提案自动进入公共池。

后续若有人记住并按这个方式处理食物，又向新人解释；有人检查、争辩或实际阻止别的分法，就可以观察到规范被维持。没有人再记住、相信或执行时，它的实际影响可能衰退。观察者仍保留旧记录，但不得作为无形法律继续约束人。

规则更改要通过新的表达和行为传播，不全局升级每个人的“规则版本”。不同人可以长期持有旧版本或不同解释。这允许执行不一致、争议、改良、分裂和忘却。

首版不构建一个能把任意自然语言规范编译为全世界强制逻辑的裁判。规范语义在各人正常思考时参与解释；程序只执行其明确选择的、已支持的动作和有界计划。例如个人先前明确安排“见到这位采集者回来就提醒我”，可以登记可感知注意条件；“看到不公就自动惩罚”需要新的语义判断，不能伪称无模型也已理解。

若某条主张需要首版不支持的物理能力才能实行，主张仍可以存在；具体行动按已有能力边界处理。形成新社会规则不需要修改世界物理配置，不能把个人立法当作运行器升级。

## 10. 怎样影响记忆、行动和模型调用

一次正常决策只装入本人的相关社会内容：当前收到的表达、对附近/相关对象的现有判断、可回忆的经历与传闻、未完成打算，以及本人保留的承诺、规范和认同。没有关系总表、公开声誉榜或所有组织的真实名单。

模型可在同一次响应中提出：具体行动和要说的话；值得记住的交流；本人对某人的判断变化；愿望/打算变化；承诺、规范与认同的个人修订；可执行的注意安排。它不能代填别人回应，也不能直接改变他人的信任、所有权或群体状态。

所有候选更新沿用调度协议：经过正的模拟思考耗时，到准备完成时按字段合并并生效；刚产生的讲话要到实际发出并被收到后才影响对方。不能在模型返回“准备道歉”时就给双方增加亲密或写成已道歉的记忆。

他人消息只是个人短期观察，不一律永久保存。具体交谈、承诺条款、规范解释和关系依据都受既有遗忘约束；保留一个概括可继续影响行为，但不能通过其来源编号取回已经忘记的原话。审计索引不能变成额外无限记忆；未完成承诺和身份认同也需要独立的回顾、保留和退出机制。

没有调用模型时，身体、已安排动作、说话过程、已存在的可执行分支和时间提醒继续推进；程序不代替角色解释新谣言、判定他人恶意或创造新的社会策略。达到需要语义决策的节点再唤醒，沿用同刻合并、最长思考间隔和最小反应间隔。

50 人无需每一对都开对话或更新关系；仅按实际感知与需要发生认知。一次被多人听见的讲话先产生实际接收记录，再按各自注意/调度决定谁需要思考；不是另请一个“社会总智能体”统一更新 50 人心理。

预算由运行器按此前方案预检，不能因聊天费用高而擅自让某人拒绝说话、漏掉必要决定或让别人免费接受。对话必须花模拟时间，反复交谈可以真实消耗生活时间；若触及技术预算边界则统一暂停世界。提示中不统一要求友善、繁衍、和解或遵守特定制度；但共享基础模型自身已有观念仍会影响输出，不能把现代概念出现直接当作历史上的独立发明。

## 11. 一段具体演化示例

1. 阿木曾和阿禾一起搬过木材。阿木记得阿禾出力，阿禾却觉得阿木当时抢先拿走了工具；他们对彼此的判断已经不对称。
2. 今天阿木提出“一起采集，回来分”。阿禾听到，追问分法，其他没听见的人不知道。双方各自思考和回应，决定是否出发。
3. 实际采集按各自行动产出，收获有唯一库存。阿禾途中受伤，出力减少；阿木是否看到、是否听到解释，要看实际感知。
4. 回来后阿木按自己的理解分食。阿禾觉得不符承诺，可能争论、拒绝下次合作或找旁人评理。程序不先判谁对，再给双方扣信任。
5. 某人提出“以后出发前先说清分法”。后来有人记住、转告、照做，有人坚持别的分法。经过多次实际互动，可以观察到一种合作惯例和围绕它的分歧。
6. 若若干人持续互相照料、共同迁徙并开始以某个名字称呼自己，观察者可标出群体候选；本人认同、外界认可和实际行动仍可能不一致。没有必须达到这一步的剧情进度。

每一步都可回溯到交流、记忆与动作，没有“第三天建立部落法”“信任达到某值形成国家”的事件脚本。

## 12. 监控与后续验证

面板新增/细化的内容应读取已有记录，不为显示方便反向制造世界事实：

| 视图 | 展示与边界 |
| --- | --- |
| 交流时间线 | 实际发出片段、接收情况、各自回应；未说出的候选只在技术候选区 |
| 方向性关系 | A→B、B→A 分开，展示情境、确信和依据当前是否仍可回忆；不是客观人格评判 |
| 承诺与争议 | 谁实际表达了什么、各人如何理解、实际进展；客观条件与背叛判断分开 |
| 资源与合作 | 实际投入和产出、物理持有、各人归属主张；不直接称为公正分配 |
| 群体与规范 | 自称、他称、实际行为、传播与执行记录、观察者候选；不混成唯一真实成员表 |

关系图只显示已存在的方向性判断，缺边代表没有当前记录，不能填成敌意零分。群体分析的窗口、阈值和稳定性口径须提前声明并保留来源；聚类算法发现的簇只能用于观察，不回灌成个人身份。为避免把短期一起行动误称为族群，首版先显示事实网络和自称，再谨慎提供候选解释，不设文明等级。

后续实施验证至少覆盖：没有听见的人不知道；耳语可能被实际偷听；中断语句余下内容不送达；同一来源的传闻不变成系统认证多证据；方向性关系独立；赠食不强制回报；改变提案不改旧回应；承诺到期不自动处罚；多人贡献与库存不重复；强制行动有身体成本；群体认同可分歧和重叠；忘记规范后不由隐藏法条继续约束；领袖不能直接控制别人；重试不重复传播/交接/改关系；网络等待不算失约；外界讲话不能取得宿主权限。

尚待后续实施方案固定：感知与发声速率、可听/可见模型、注意容量、消息分段、个人社会摘要预算、关系字段变化边界、结构化条款的支持范围、群体统计口径。它们是通用机制和可测量取舍，不要求用户逐条写法律或为 50 人安排朋友与敌人。
