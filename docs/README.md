# 西部世界设计文档

本目录保留 14 份世界、人物与文明模拟的目标设计。迁移时移除了旧实现的技术选型、服务器部署和旧实现验收记录。设计中的运行纪律、信息隔离、事实结算和验收要求继续作为参考。

当前游戏基线为 SCAPI 1.9.5.1。球面地表、身体与繁衍、自由制造、跨代传承等设计需要重新确认游戏支持范围。保留设计不等于这些功能已经实现，旧实验结果也不作为本版 AI 人群的运行证据。
