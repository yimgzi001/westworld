## 维护位置

- 开发文档描述当前代码与可执行步骤；设计专题描述目标与验收要求。新增模块时补代码导航，实现或验证范围变化时更新当前状态。
- 构建命令、输出位置和检查步骤统一在开发与验证文档维护；索引只提供入口。
- `game/docs/` 为随源码保留的上游资料，项目接入说明放在 `docs/`，引用上游专题，不复制整套教程。
- 旧 Go 实现与旧实验记录保存在本机忽略目录 `archive-local/`，仅供追溯，不作为当前实现依据。当前游戏的本地证据位置见当前状态，新克隆仓库不会自动带上这些文件。
- 常规变更就地更新已有说明；只有需要追溯的退役方案才归档，并保留指向当前替代说明的入口。凭证、运行存档和模型原始账本不进入文档或版本库。
