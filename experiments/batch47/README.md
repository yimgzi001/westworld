# 第47批冻结与资源测量

仅使用已有本地构建、资源。stage只冻结，不构建不启动。

- `python3 experiments/batch47/stage.py --label <新标签> --assets <已有资源目录> --group baseline`：scale2/10串行，隔离无争用基线。
- `--group stress`：scale20/50/recovery三路并行，各自新目录、新世界；execution-group标记并发组，不能当无争用基线。
- 生成批脚本由协调者审阅后运行；每场140秒硬截止，零模型API。

scale预热10墙秒+稳态30墙秒，真实每角色原生移动/转向持续循环。宿主steady_start/end UTC与游戏时间对齐监控器100ms目标采样。最近采样边界偏移>0.5秒则拒绝可靠稳态资源结果。CPU为独立进程树累计观测差，RSS为同一采样活跃进程RSS之和（共享页可能重复计数），退出短子进程可能漏采。记录实际偏移，不能称逐时刻覆盖。

整场rusage CPU/maxRSS单独列；maxRSS不是同一时刻子树RSS和，不能与稳态平均或单角色增量混用。资源样本和原始游戏日志只留本地，仅提交摘要、代码与测试。重建验证同进程两个周期，旁角色持续Wait，不冒称旁角色移动。未运行结果不得推测成功。

宿主仍配置预热10秒、稳态30秒；汇总允许事件记录边界0.1秒容差（预热≥9.9、稳态≥29.9），用于健康页检查和日志发布时间偏移，不缩短宿主测试。报告保留实测事件时长，不四舍五入声称精确10/30秒；9.8秒预热/29.8秒稳态负控必须失败。
