# 阶段29：原生直行预取失败证据

此归档只保留 `direct29-early` 和 `direct29-early2` 两场失败。两场均为云端人工夹具、确定性文件控制器，不是模型实测，也不是自然觅食或长期自主生存。后续修复不在本包验收范围。

- 第一场：驱动使用 timeout=8，超出真实菜单上限4，触发 `fixture_number_not_offered`，动作启动0次。宿主60.027秒预算结束，host/driver均exit1。`direct-driver-result.json` 从未产生，不能补造。
- 第一场 checkpoint 仍为 running，finishedUtc为null；归档保留原始记录，使用已存在的宿主终态、exit和driver traceback证明失败。归档完成不等于补写checkpoint。
- 第二场：timeout修正为4，原生MoveTo于2.114秒被观察到成功，累计路径约3.946米。但deferred菜单仍要求旧host导航running状态，导致220次预取setup失败；预取0、运动/推理重叠0。宿主60.035秒预算结束且exit1，独立验收fail。driver exit0只表示已送出两条确定性回复，并非场景通过。
