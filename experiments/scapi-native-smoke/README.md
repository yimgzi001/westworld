# SCAPI 原生单角色 smoke（2026-11-09）

本工具引用当前仓库的 SCAPI 源码构建游戏，使用真实窗口、真实世界和原生玩家/物理更新。它是**固定脚本验证器，不是AI、不调用模型、不接收动态代码**，也不是可用于日常世界的模组。

## 已实测
最终源码在 `work/native-smoke-05`：
- 新隔离生存世界，自然生成，固定种子 westworld-native-20261109。
- 标准初始玩家构造，唯一角色 PlayerIndex=2（模板计数从1开始，不代表两个人）。
- 读取真实坐标、生命、速度、26个本人背包槽。
- 在输入(-10)与玩家(0)之间，order=-5注入0.25前进输入，最多0.4游戏秒，额外1秒墙钟截止。
- 水平位移 **0.36911616** 格；停止后惯性漂移 **0.09964635** 格。垂直位置未改变，生命1，背包未变化。
- 约2游戏秒停止观察后，在游戏帧/物理更新后再次检查零输入与速度小于0.1，结果通过。
- 同步保存并读回Project.xml验证唯一角色；完整实验doc快照9文件逐一SHA256核对后进行重载。
- 重载匹配原PlayerIndex、生命、全部背包及位置（0.1格容差），不新增角色、不发送非零移动，观察2.4游戏秒位移0、速度0；再次保存验证通过。
- 最终新世界测试约12.03秒，重载约9.43秒；不是长时稳定性/资源基准。
- 非法参数和对已有目录重新新建均在游戏启动前拒绝，退出码2。

前几次迭代记录也保留在work中：早期版本只有位移断言、没有等待存档；后续补全水平位移、生命/背包、物理后观察、存档读回和重载。不要拿早期completed字段当最终验收。最终以result及save_verified共同通过为准。

## 构建与显式运行
要求Windows、.NET10 SDK。使用新的、尚不存在的输出目录：
```powershell
dotnet build experiments/scapi-native-smoke/NativeSmoke.csproj -c Release -o work/native-run-NEW
# 以下会启动真实游戏窗口并创建新实验世界，不要放进日常游戏目录
dotnet work/native-run-NEW/Westworld.NativeSmoke.dll --new-disposable-world
```
需游戏窗口保持活动。测试会自动保存关闭；无进展约180秒墙钟终止（依赖游戏Frame仍运行，不是进程级死锁看门狗）。
重载前确认进程退出，先完整复制该目录下doc并逐文件校验，保存快照；然后：
```powershell
dotnet work/native-run-NEW/Westworld.NativeSmoke.dll --reload-observe
```
无显式参数不会启动。拒绝新建时覆盖已有doc/Mods；重载须有本实验标记、唯一既有角色且Mods为空。该工具不是面向不可信本地文件的安全沙箱。

## 隔离与限制
- app:相对entry assembly目录，不是cwd；因此输出必须在独立work子目录。data:按独立程序集名隔离。
- 不触碰用户既有世界、Minecraft、main分支，不修改game/源码，不直接改地形、背包或生命。
- 调用原生EntryPoint；它不经过原Main的IME及单实例mutex。只用于隔离实验，运行前确认同目录没有另一实例。
- 原生初始化仍会执行上游通常的资源/设置初始化；不会把整个游戏包装成无外部副作用环境。
- 运行/构建输出、世界、备份、原始逐帧信息仅在忽略的work目录，不能提交。
- 构建0错误；ImageSharp3.1.12仍有NU1902/NU1903警告，未禁用告警。原生OpenXR无VR runtime警告未阻断桌面测试。
- 尚未验证局部方块感知、输入请求去重/会话协议、两角色隔离、挖掘/放置、云模型闭环、失焦恢复和长时生存。
- 下一步应把只读局部感知与带ID的异步动作队列接到同一线程边界，再验证2角色，不能把本轮称作AI自主生存完成。
