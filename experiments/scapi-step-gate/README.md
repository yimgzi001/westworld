# 真实观察台阶准入实验

只在 dot 云电脑新建隔离夹具，不使用用户世界。无模型、无补发物品；夹具明确铺地/台阶并设置起点，不能当自然探索成功。

构建到 `work/` 新目录后，从正常桌面终端运行 `dotnet StepGate.dll up` 或 `down`。每个模式使用单独输出目录；已有 `doc/` 拒绝覆盖。原生完整 Player，无 AI GameWidget，独立活动中心。

Windows 构建时传 `-p:WestworldWindows=true`。`continuous` 验证侧面有平路时仍能朝目标自动跳上一格并继续走，`forage` 验证 48 格内容刷新范围内的同帧全向观察、墙后遮挡与平视取蛋，`coast` 验证站在船壳到踩稳岸边的过程，`shelter` 验证挖坑、封顶、从黄昏睡到天亮并离开。`shelter-retry` 在挖掘中切一次手持槽，核对中断后能否继续完成同一流程。夹具会准备地形，真实生存场的自然资源和结果另行统计。

`coast` 让角色背对近岸，验证直接使用全向快照里的目标。`coast-boat` 把岸移远，验证对准船座后重新上船。

`shelter-wet` 先搭建土坑，拆顶后原地重新封顶，再把夹具湿度设为 100%。等待原生晾干、睡到天亮，并把出坑时的起跳速度降至 95% 验证连续垫土。

`navigate` 用一个 18 格目标验证接续走路和途中自动跳。`navigate-turn` 在路中放置障碍，验证走动中变更方向。`navigate-drop` 检查角色在缺少可验证落脚的三格落差前停下或沿安全旁路移动。`navigate-edge` 从脚底仍着地、身体略微悬出格边的位置开始，验证向同格中心收步后立即接回长路线。`navigate-inset` 复现距离格中心约 0.056 格时的原生挪步，要求进入 0.04 格范围。`navigate-natural-stall` 用自然种子的原始地形复现被树叶堵住的方向，核对已观察的旁路和实际位移。`shelter-predator` 用原生黑熊验证开顶见敌后重封，夹具把熊的移动速度设为零以固定观察时机。

`food-safety` 使用原生食物属性、饱食和疾病状态验证进食筛选。`shelter-illness` 先比较原生睡眠检查和实体封闭检查，再搭建土坑并用夹具设置的低血量和疾病状态触发白天原生睡眠。

`production-kit` 从两个实际木块和一个花岗岩块开始，验证采集、工作台、营火制作和放置。`production-kitchen` 另放 7 块圆石、两份生肉和木板作为世界拾取物，再挖出一块圆石，验证工作台、熔炉、装燃料和同一任务取回两份熟肉。`threat-range` 固定一只原生黑熊的移动，验证 18 格外提前预警及墙体遮挡。

`production-hunt` 用固定移动能力的原生鸭和七块可拾取圆石，验证采木、工作台造木矛、近战掉落、安全靠近、实际拾取、补足圆石、做熔炉以及取回熟鸟肉。生鸟肉来自真实猎获。

`production-hunt-ranged` 把同类原生鸭放在近战距离之外，核对自制木矛投掷、原生伤害归属和该猎物生肉的实际拾取。

`predator-cliff` 在一处七格落差旁使用实际会追逐的原生棕熊。先验证沿威胁反方向的第一条直路会到崖边，再验证角色能沿确认的侧路连续逃开，检查生命值、落脚、原生熊位移和接续次数。

`predator-edge-return` 让角色中心略悬出崖边，脚底搭在旁边有支撑的地块，再由原生郊狼追击。先核对短步收回，随后检查实际侧向逃离、接续和生命值。

`predator-edge-tip` 加大悬出和侧向偏移，验证斜着回到中心超出短步范围时，先收回同一支撑格内的近处，再沿安全路线撤离。

`predator-memory` 先看到原生黑熊，再用墙体遮挡。验证原路线朝它最后出现的位置时改走安全旁路，以及短期记忆到时失效。

`predator-clearance` 验证走完最短撤离路程后，若仍靠近原生棕熊，角色继续走到最低安全距离。`shelter-late-predator` 在最后一跳才放入原生棕熊，验证落回坑内、撤下垫土和重封。

`shelter-middle-predator` 在第二跳约一格外放入原生棕熊，将角色刚看到的威胁交给出坑动作，验证当跳中断、回到坑底和重封。普通出坑夹具关闭随机动物生成，遇熊行为由独立夹具覆盖。

`shelter-lower-predator` 将棕熊放在低一格的地面、距坑口约 18.6 格。验证第二跳仍由出坑动作控制，看到熊后回落和重封。

`shelter-night-hungry` 在日落前 30 游戏秒以 9% 饱食开始，检查夜间庇护条件，完成原生搭建、睡到天亮和出坑。

`predator-coast-turn` 使用 `natural34-b` 的真实窄岸地形。原生下船后从卡点开始，约 20 格外放置固定移动能力的灰狼。验证直接退路受阻时，能沿可见干地绕到一格高的出口，并在近处出现威胁时拒绝开始向其靠近。

`navigate-vegetation` 在长路线和台阶上铺设无碰撞的草和花。`shelter-shallow` 从背包无土的一格浅坑跳出。`shelter-camp` 在没有随机生成生物的夹具中验证过夜、出坑、走开、沿原生路线返回以及重建实体遮蔽。

`navigate-natural-cotton` 从 `natural34-b` 的真实岸边卡点出发，保留相邻野棉花原始证据，验证一格自动跳和连续移动。`forage-far` 验证同一帧在 48 格范围内看到约 38 格外的蛋，实际用一条通过试玩菜单校验的导航任务接近并取食。

`predator-pumpkin-corner` 从第十五场身体边角擦过南瓜格的同种子、同坐标开始。使用该场最初记录的棕熊方向，验证普通整格净空判断会拒绝路线，随后按已观察南瓜的原生碰撞范围收脚，再连续撤离至少 11.5 格。夹具关闭随机动物生成，检验实际导航和生命值，动态追击另由自然场确认。

`production-hunt-approach` 将食用鸭放在投矛射程外。验证木矛就绪后，角色可沿已观察干地接近，再用原生投矛和拾取取得同一只鸭的生肉。

`forage-pumpkin` 将成熟南瓜放在一格落差后。先确认站在原处挖掘受阻，再沿干地换位，通过原生挖掘命中外露部分，最后沿确认的台阶下去并核对实际入包、落脚和生命值。

`forage-target` 让角色按快照编号锁定沟对面的鸟蛋。沿途先拾起另一枚同值鸟蛋时仍继续原任务，绕沟后用原生拾取和进食完成目标。`navigate-cold` 把可见积雪放在直行路线旁，验证保温不足时沿干地绕开并到达原目标，也核对了雪边能向外撤离。

`production-project` 只选一次备熟食任务。角色沿安全地面接近木材，制作工作台和木矛，测试在第一次狩猎前暂停并从同一库存恢复，接着实际取肉、补石料、制作熔炉和取出熟肉。夹具固定鸭的移动能力，提供七块作为起始储备的原生石料拾取物。

`food-origin` 以开局零食物启动验收记录，通过原生拾取、存放老化和进食确认来源；加入一份未经拾取的同类食物后，核对来源不明的进食被排除。

`shelter-site-choice` 从边缘只有一个出口的土台出发。确认选址考虑多向地面退路和原生睡眠的九列顶，角色到达选定的软土后完成原生挖坑与封顶。`production-project` 也放置一段缺乏合适站位的高处木材，验证这种木材不会进入靠近阶段。

- `ObservedStepRoutes` 仅投影真实当前/≤3 秒历史观察的基底、身体、净空与落脚格。只支持一格、轴向、固定实心地面；不可见、未知、过高、空落点拒绝。
- `StepTo` 是低层原生动作，不携带证据，**不能直接作为模型入口**。这里由 runner 强制校验逐帧包络与证据期限。未来集成必须保留这些约束。
- 上台阶允许已观察落脚实心格的原生 SmoothRise 接触：仅开启原生功能，且脚高度差不超过 `min(MaxSmoothRiseHeight, 0.5)`。日志 `knownSupportContactUsed` 明示，不称全空气穿越。
- 成功只表示进入目标附近并获得地面支撑、竖直速度收敛，不证明水平完全停稳或长时驻留。
- 原生台阶已作为候选接入自然 `Survey`，共用 `ObservedStepGuard`；天然场景是否实际选中和成功通过要单独统计，不由本夹具通过推断。
- `NativeActorSession` 可显式设 `observationAbove=3` 观察上方净空，默认仍为 1；范围、120 度视锥、加载区与遮挡均不变，不暴露全知地形。

初轮失败、时序修复和本批结果见 `docs/development/探索覆盖与台阶准入批测-2026-11-09.md`。

下降还允许已观察**原支撑格**的脚底数值接触（不超过 0.02m），应对原生离开边缘时的浮点/缩小碰撞箱差异；不是允许下降到未知格。两种已知支撑接触统一记为 `knownSupportContactUsed`。

注意：下阶 2 厘米是本实验明确选择的工程容差，真实首次触发的交叠约为 0.00005 米，二者不能混称。未知支撑和其它层不适用。
