# 真实观察台阶准入实验

只在 dot 云电脑新建隔离夹具，不使用用户世界。无模型、无补发物品；夹具明确铺地/台阶并设置起点，不能当自然探索成功。

构建到 `work/` 新目录后，从正常桌面终端运行 `dotnet StepGate.dll up` 或 `down`。每个模式使用单独输出目录；已有 `doc/` 拒绝覆盖。原生完整 Player，无 AI GameWidget，独立活动中心。

Windows 构建时传 `-p:WestworldWindows=true`。`continuous` 验证侧面有平路时仍能朝目标自动跳上一格并继续走，`forage` 验证 48 格内容刷新范围内的同帧全向观察、墙后遮挡与平视取蛋，`coast` 验证站在船壳到踩稳岸边的过程，`shelter` 验证挖坑、封顶、从黄昏睡到天亮并离开。`shelter-retry` 在挖掘中切一次手持槽，核对中断后能否继续完成同一流程。夹具会准备地形，真实生存场的自然资源和结果另行统计。

`coast` 让角色背对近岸，验证直接使用全向快照里的目标。`coast-boat` 把岸移远，验证对准船座后重新上船。

- `ObservedStepRoutes` 仅投影真实当前/≤3 秒历史观察的基底、身体、净空与落脚格。只支持一格、轴向、固定实心地面；不可见、未知、过高、空落点拒绝。
- `StepTo` 是低层原生动作，不携带证据，**不能直接作为模型入口**。这里由 runner 强制校验逐帧包络与证据期限。未来集成必须保留这些约束。
- 上台阶允许已观察落脚实心格的原生 SmoothRise 接触：仅开启原生功能，且脚高度差不超过 `min(MaxSmoothRiseHeight, 0.5)`。日志 `knownSupportContactUsed` 明示，不称全空气穿越。
- 成功只表示进入目标附近并获得地面支撑、竖直速度收敛，不证明水平完全停稳或长时驻留。
- 原生台阶已作为候选接入自然 `Survey`，共用 `ObservedStepGuard`；天然场景是否实际选中和成功通过要单独统计，不由本夹具通过推断。
- `NativeActorSession` 可显式设 `observationAbove=3` 观察上方净空，默认仍为 1；范围、120 度视锥、加载区与遮挡均不变，不暴露全知地形。

初轮失败、时序修复和本批结果见 `docs/development/探索覆盖与台阶准入批测-2026-11-09.md`。

下降还允许已观察**原支撑格**的脚底数值接触（不超过 0.02m），应对原生离开边缘时的浮点/缩小碰撞箱差异；不是允许下降到未知格。两种已知支撑接触统一记为 `knownSupportContactUsed`。

注意：下阶 2 厘米是本实验明确选择的工程容差，真实首次触发的交叠约为 0.00005 米，二者不能混称。未知支撑和其它层不适用。
