## 本轮验收意图

同一世界的2或4个不同actor/session，经各自当前公开菜单提交持续动作。必须记录所有角色动作同时running的真实状态，不以“命令先后发出”冒充并发；两角色实际位移不能用目标距离替代。

取消A时绑定A的动作ID，确认A取消终态与停止。B仍归自己的控制器、没有被连带取消，并继续产生实际位移直到自己的正常终态。再用新runId让A重新移动恢复；最后全部控制器与任务均空闲。若动作自然提前完成、身份不符、没有真实重叠或独立增量效果，汇总应失败而非补造成功。

资源只报告整个游戏子进程树含启动的墙钟/CPU/峰值内存；不是单AI稳态成本。无模型调用，不代表云端推理成本或自主生存。

只发布源码、可复用测试及精简结果，不上传原始大日志、游戏本体、存档或凭据。

默认同批冻结2人、4人两场，串行运行避免资源互扰。可用compare.py读取已完成的两场summary/resources进行整体成本对比；10人/长期恢复仅设计，未运行不报告通过。汇总对全角色共同running样本要求至少3个、游戏时间跨度至少1秒且最大采样间隙不超过1秒，明确不是逐帧连续证明。
