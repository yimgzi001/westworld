# 原生局部导航批测设计与离线聚合

本目录仅分析 JSONL，不启动游戏、模型或用户电脑。`runner_passed` 是原 runner 的断言结果，不等于自然生存成功。聚合器刻意保留 `food_chain_verified: null`：在统一的采集、入包、食用关联证据契约落地前，不根据日志文案或发现食物推断成功。

## 运行

```sh
cd experiments/scapi-navigation-batch
python3 -m unittest -v
python3 summarize.py ../../work/search3-seed-{a,b,c}/integration.jsonl > summary.json
```

仅标准库，输出为 JSON 数组。空日志、损坏行、多次/缺少最终 result 返回状态码 2；正常完成但场景失败返回 0，这是“分析成功”而非“游戏通过”。丢失字段显示 null 或 warning，不填零冒充已测。重复 route result 单独报警，计数仍是日志事件数，不当唯一动作数。

## 已有失败约束

旧 `search3` A、B 各走两步，末尾九个视角各自无候选；只读合并实际已见格后几何上分别能支持 7、3 个平路线。这说明丢弃前视角证据是主要瓶颈，但旧日志无逐格时间，不能将事后全并集作为执行授权。新 3 秒有源窗口必须单独测试。

C (`westworld-search-03`) 连续九帧相同 31 个已知格，脚 Y≈64.8634，与整数差约 .1366 超过旧 .05 阈值，投影在几何判断之前退出；附近可见水和海胆，但证据不足以断言角色处于水中。必须记录脚下支持、浸水、竖直速度和转向实际结果，不能只松阈值。

## 验收矩阵

所有自然模式不得插资源、全图查询或用真实世界数据替代演员观测。人工场景的预置地形仅供独立测试夹具，明确 fixture=true；不能计入自然发现率。

| 场景 | 输入/预算 | 必须证明 | 不算成功 |
|---|---|---|---|
| 平地短时记忆回归 | A/B 原种子，最多 32 次短步，同版本同预算 | 多视角逐格来源与年龄；实际到达数；过期停止独立计数；未知不成为路线 | 扫视次数多或模型口头说找到路 |
| C 原生非整数高度 | C 原种子，不改出生地形 | 记录支持/浸水/竖速与拒绝类别；支持合法地形才行动，不支持则明确终止 | 随意把整数高度阈值放宽后移动 |
| 单级上台阶 | 明示人工夹具，高度差由原生可跨越能力决定 | 当前可见踏面/净空和整段支持证据；实际脚高进入目标层；输入结束后停稳 | 直接改位置、瞬移、穿透或只有动作 accepted |
| 单级下台阶 | 明示人工夹具，一级已见落脚点 | 落脚支持与净空；受控下降；落地实测；不跌出边界 | 将未知深坑当低层地面 |
| 危险台阶反例 | 缺落脚支持、低顶、过大高差、浸水各一例 | 对应拒绝/安全停止且无越界；逐项独立断言 | 因日志缺失或超时退出就判通过 |
| 闭墙 | 明示封闭墙夹具 | 0 路线启动、无逃出、0 更新异常 | 只说未发现食物 |
| 动态障碍 | 路线接受后测试夹具插入墙 | 非过期停止、具体原因，随后另一短步实际到达 | 把 TTL 取消叫障碍命中；任意偏移叫准确识别插入墙 |
| 新地图泛化 | 预先固定 3 个未调参种子，保留失败样本 | 相同预算报告到达率/停止原因，不挑成功种子 | 替换难地图或隐式平整地形 |
| 自然食物目标 | 同一自然世界，当前局部感知发现资源 | 资源观测→模型目标→主动作采集→实际入包→实际吃掉→饱食变化，全链 ID 对齐 | 只有食物图块消失、库存增加或 Food 增加单项 |

建议先交付“平地继续探索 + C 拒绝原因可解释 + 一种真实合法台阶”，不同时扩张水中、复杂跳跃与全局寻路。台阶参数以原生组件可支持的动作实测为准，不预设一定能跨一整格。

## 最小日志契约

- `start`：mode、seed、fixture、运行标识、代码版本、预算；真实 worldResourcesPlaced 单独记录。
- `local_route_observed`：ObservationId、observedAt、origin、known、safeCandidates、拒绝类别/缺失证据格；当前身体支持、竖速、浸水、眼姿态。若未提供则 null。
- `local_route_started`：choiceId、routeKind(flat/step_up/step_down)、origin/target、逐格 provenance（坐标、值、SourceObservationId、ObservedAt、Age、IsCurrent）。历史证据仍是历史。
- `route_safety_stop`：choiceId、expired、原因枚举、位置/高度/浸水/证据边界偏差；可选注入障碍的空间关系，夹具信息不注入角色认知。
- `local_route_result`：choiceId、outcome、原生 status/failure、actualPosition、elapsed。Arrived 必须真实距离验收，不能只读命令返回。
- 食物链：同一 taskId/target、原始资源观察、采集前后、入包数量/值、吃之前后槽数量与 FoodItemsEaten/Food；资源采集与物品所有权不能仅凭时间邻近断言。
- `result`：passed、reason、seconds、updateFailures；正常失败也必须输出。

## 当前脚本边界

聚合已有原生日志和新 provenance；不运行物理重放、不独立证明碰撞或成功食用，不读取游戏存档/全图。`nonexpiry_safety_stops` 只是“非过期安全停止事件”，不命名为障碍命中。后续稳定日志 schema 后才增加按 task/choice 的完整链验证，避免把验收推理藏在统计脚本里。
