# 阶段 36：助手同接口自然食物单场对照

本场通过原生验收，**不是 Terra 运行、模型自主改善、公平 A/B 或长期生存证明**。协调助手有相同种子的先前经验，读取本次公开请求后手工选择工具，写入相同文件控制接口。外部 API 调用为 0；助手决策 token 未单独计量，不能写成零 token 或零总成本。

## 已核验结果

- 种子 `natural34-b`，新建自然世界；宿主退出 0，58.7638437 秒，更新异常 0，健康 1。
- 三次请求完整保留：① 下船 → 接近本次可见海胆 → 挖掘；② 运动期间预取返回空计划，不假设未来库存，不替换旧 Dig 尾；③ 新快照已显示海胆 `226×1`、新来源 verified，随后 Eat。
- 原生实际动作只有 `Dismount → MoveTo → Dig → Eat`。海胆由原生自动拾取，未执行显式 PickUp。原始来源、库存转移、食用事件、终态收据及独立 `validate_food` 均通过。
- 路程 5.377729583797191 米，净位移 2.22846 米。进食瞬时饱食度 0.5350019 → 0.5850019，食用统计 0 → 1；代谢后最终饱食度 0.584996。不是把初始熟鱼计作新来源。
- 空计划预取 handoff 1；宿主报告运动重叠 1.8644390639965422 秒，不等于外部模型推理时间。三次响应等待约 14.761 / 15.728 / 22.492 秒，不能称无停顿。
