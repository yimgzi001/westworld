# 原生零视口周期生态验收（准备）

此程序不直接调用 SpawnRandomCreature，不修改周期、随机、种群上限、地形或生境。创建新的 Living 生存世界与完整外部 Player，使用独立活动中心，无 AI GameWidget。等待绑定后超过 63 个游戏秒；冬季超过 123 秒。

参数 `centers` 使用正常模拟中心；`empty` 显式空生成中心作为反例，地形与完整玩家仍存在。Harmony 前缀/终结钩子只统计原生周期入口及其调用栈内的地形候选试验/生成函数调用，不改返回值。诊断只输出计数、时钟和中心数量，不输出动物坐标，不送给任何模型。

通过标准：至少一个绑定后的周期入口，正常中心至少一次真实 ProcessSpawnPoint 候选尝试；空中心候选尝试为零。SpawnFunction 被调用不等于最终生成成功或演员看见动物，日志明确区分。若原生种群上限或区域饱和阻止试验，正常中心场景将失败，不改参数强行通过，需用入口日志诊断。

先构建 `FaunaGate.csproj`，然后由协调线程将输出及运行资源复制到新的 `work/` 子目录并独占启动。程序拒绝已有 doc 世界目录。最长墙钟 240 秒，游戏时钟不加速。此目录最初仅准备源码，实际运行结果应由协调线程另行记录，不得用编译通过冒充周期实测。
